# ♞ Шахматы на Python

Полноценные шахматы **одним файлом** — `chess.py`. Никаких сторонних библиотек:
только стандартная библиотека Python 3.

```
chess/
├── chess.py           ← сама игра (и движок, и интерфейс)
├── start_chess.bat    ← запуск на Windows (резервный способ)
└── README.md          ← этот файл
```

## Запуск

| Что | Как |
|---|---|
| 🪟 Красивое окно (tkinter) | `python chess.py` или `python chess.py --gui` |
| ⌨️ Консоль (работает всегда) | `python chess.py --console` |
| 🖱️ Windows, двойной клик | `start.vbs` в корне репозитория |
| 🧪 Проверка правил (perft-тесты) | `python chess.py --perft` |
| 🎚️ Сразу задать уровень | `python chess.py --level=4` |

Если tkinter не установлен, игра сама переключится в консольный режим —
падения не будет.

## Что умеет

**Правила (всё честно, проверено perft-тестами):**

* все ходы фигур, включая двойной ход пешки;
* взятие на проходе (en passant);
* рокировка — короткая и длинная, с проверкой прав и «битых» полей;
* превращение пешки (по умолчанию ферзь, можно выбрать фигуру);
* шах, мат, пат;
* ничья: правило 50 ходов, троекратное повторение позиции, недостаточно материала.

**Компьютерный соперник:**

* минимакс с альфа-бета отсечением, итеративное углубление;
* оценка позиции: материал + таблицы «полезности поля» (piece-square tables) + пара слонов;
* поиск «шумных» ходов (quiescence) — компьютер не зевает фигуры;
* кэш позиций (transposition table) и упорядочивание ходов — думает быстрее.

**5 уровней сложности:**

| № | Название | Как играет |
|---|---|---|
| 1 | Новичок | случайные ходы (взятия — охотнее) |
| 2 | Легко | глубина 1 |
| 3 | Средне | глубина 2, до 1.2 с на ход |
| 4 | Сложно | глубина 3, до 2.5 с на ход |
| 5 | Мастер | глубина 4, до 5 с на ход |

**Возможности интерфейса:**

* подсветка выбранной фигуры и точек возможных ходов;
* подсветка последнего хода;
* кнопка «Подсказка» — покажет хороший ход;
* отмена хода (своего и ответа компьютера);
* переворот доски;
* новая партия без перезапуска программы.

## Проверка корректности (perft)

`perft` — это рекурсивный подсчёт всех возможных позиций на заданной глубине.
Если значения совпадают с эталонными — значит генератор ходов реализует правила верно.

```
$ python chess.py --perft
  perft(1) =       20  ожидалось       20  OK
  perft(2) =      400  ожидалось      400  OK
  perft(3) =     8902  ожидалось     8902  OK
  perft(4) =   197281  ожидалось   197281  OK
  perft(3) =    97862  ожидалось    97862  OK      (позиция «Kiwipete»)
  perft(3) =     2812  ожидалось     2812  OK
  Итог: все тесты пройдены ✔
```

Те же тесты прогоняются автоматически в GitHub Actions (`.github/workflows/chess-tests.yml`).

## Консольные команды

```
e2e4          — сделать ход (откуда-куда), превращение: e7e8q
подсказка     — показать хороший ход
отмена        — отменить свой ход и ход компьютера
уровень 3     — сменить сложность (1..5)
доска         — перерисовать доску
выход         — закончить игру
```

## Идеи, как развить проект

* троекратное повторение — реализовано, а «правило 75 ходов» — нет (можно добавить);
* открывающая книга (book) и таблицы эндшпиля;
* запись партии в PNG/PDF или в формате PGN;
* игра на двоих за одной доской;
* сетевой режим через сокеты.
