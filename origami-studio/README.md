# Origami Studio

Отдельный специализированный прототип для пошаговых инструкций оригами. Это не режим Forma: у приложения собственные интерфейс, модель проекта, библиотека техник и экспорт.

## Запуск

```bash
cd origami-studio
npm run dev
# http://localhost:3000
```

Нужен только Node.js 18+. Сборка и npm-зависимости не требуются. Three.js и OrbitControls находятся в `vendor/`; лицензия сохранена рядом.

## Что работает

- классический журавлик из одного квадратного листа, 10 шагов;
- интерактивная 3D-модель с ключевыми состояниями и управлением камерой;
- отдельная SVG-схема каждого шага и учебная карта основных складок;
- проигрывание, перемотка, скорость, навигация клавишами;
- справочная библиотека Golden Venture, Sonobe, PHiZZ, кусудамы и прикладных выкроек;
- обозначения «гора», «долина», reverse, повтор, вспомогательный сгиб, рез и клей;
- экспорт полного листа инструкций в PNG;
- печатная A4-версия / сохранение в PDF через диалог браузера;
- запись 16-секундной WebM-анимации средствами браузера;
- адаптивный интерфейс.

Готовые результаты экспорта лежат в `examples/`:

- `crane-instructions.png` — полный лист из 10 шагов;
- `crane-animation.webm` — 16-секундная 3D-анимация без звука.

## Граница достоверности

3D-анимация журавлика — **учебная интерполяция ключевых состояний**, а не симуляция непрерывного складывания листа. Схемы описывают традиционную последовательность, но низкополигональная 3D-геометрия не является solver-подтверждённым состоянием всех слоёв. Карта складок показывает основные направляющие и не претендует на полное формальное CP-представление. Справочные карточки модульных техник не являются уже готовыми физически проверенными конструкторами.

## Задуманный рабочий процесс

1. **Модель или изделие:** выбрать проверенный шаблон, модульную систему либо прикладную выкройку.
2. **Материал:** размер, толщина, сторона цвета, допустимость реза и клея.
3. **Конструкция:** для классики — слои и складки; для модульных — ряды и соединения; для прикладных — выкройка, надрезы и клеевые клапаны.
4. **Проверка:** замкнутость слоёв, self-collision, доступность операции, совместимость tabs/pockets и последовательность сборки.
5. **Инструкция:** автоматические диаграммы, номера шагов, повторяющиеся операции, ракурсы и предупреждения.
6. **Экспорт:** лист PNG/PDF, анимация WebM/GIF и машиночитаемый файл проекта.

Важно отдельно хранить операции «сложить и оставить» и «создать направляющую складку, затем раскрыть». Для реза нужна линия и сторона отхода; для клея — конкретная грань, зона нанесения и момент прижатия.

## Структура

- `index.html` — приложение и диалоги;
- `styles.css` — интерфейс, SVG-нотация и печатная вёрстка;
- `js/data.js` — шаги, проекты, шаблоны и обозначения;
- `js/diagrams.js` — векторные схемы;
- `js/scene.js` — Three.js-сцена и ключевые состояния;
- `js/app.js` — взаимодействие, проигрыватель и экспорт;
- `server.mjs` — локальный статический сервер;
- `tests/model.test.mjs` — проверки данных и схем.
