# Объём — 3D-сканер небольших предметов на телефоне

Снимаешь предмет на печатном коврике — телефон сам строит 3D-модель:

* **Полигоны** (сетка с цветом) — для 3D-печати, игр, Blender, анимации, карточек товара;
* **Сплэты** (гауссовы капли) — фотореалистичный вид для показа;
* **Оба** сразу из одной съёмки.

Всё считается на телефоне, без интернета и **без нейросетей**: позы камеры — по меткам коврика,
форма — вырезанием объёма по силуэтам, сплэты — честная подгонка градиентным спуском под снятые кадры.

APK собирается GitHub Actions (`.github/workflows/build-obyom-android.yml`) и выкладывается в релизы
с тегом `obyom-apk-N-M`, файл `Obyom.apk`.

## Коврик

В приложении: «🖨 Коврик для печати» → PDF A4 (предметы до ~12 см в ширину), A3 (до ~17 см) или A2 (до ~24 см),
а также **«Круг для вертушки»** (A4/A3) — без угловых меток. Печатать **в масштабе 100 %** («Фактический размер»).

* **16 меток по кругу** (+4 по углам листа) — телефон по ним узнаёт, откуда смотрит камера, фокус объектива и масштаб.
  Хватает 2–3 видимых меток, предмет может закрывать остальные. На вертушке угловые метки не используются.
* **Серые крапинки** в центре — чтобы отличать тень от предмета: в тени крапинки остаются видны (просто темнее),
  а предмет их закрывает.
* **Градусная шкала и стрелка** — только для человека (видно, на сколько повернул). Телефон на неё не смотрит.
* **Пунктир r = 100 мм** — линия отреза, если нужен круг. Вырезать не обязательно: лист должен просто лежать ровно.
* Сероватая печать допустима: распознавание меток адаптивное. При съёмке внизу видно «печать: чёрный отлично / норм / бледная».

**Калибровка печати** («📏 Калибровка печати»). Принтеры часто уменьшают лист на 1–3 %. Измерь от внешнего края
верхней метки до внешнего края нижней и так же слева–справа: должно быть 190 мм (A4), 269 мм (A3), 380 мм (A2).
Введённые числа сохраняются; модель масштабируется по X и Y отдельно (высота — по среднему). Учитывается и при пересчёте старых сканов.

## Два способа съёмки

**С рук.** Коврик на столе, предмет в центре. Обходишь вокруг 2–3 раза: низко (~30°), выше (~55°), почти сверху (~75°).
Кадры снимаются сами (короткий писк), когда телефон в новом ракурсе, движется медленнее 16°/с и кадр резкий.
Купол справа показывает, какие ракурсы уже есть.

**Держатель + вертушка.** Телефон неподвижен в держателе, 25–35 см до предмета, смотрит сверху-сбоку. На вертушке —
вырезанный круг или целый лист, если лежит ровно (столик меньше круга — подложи картон). Крутишь плавно, оборот за 15–20 с:
кадр берётся, когда поворот медленнее 30°/с и кадр резкий. После оборота поднимаешь держатель выше и делаешь ещё один.

Строка **«Не снимаю: …»** объясняет, почему кадр не взят (быстро, смазано, мало меток, этот угол уже снят…).
Кнопка 📷 снимает кадр вручную.

**Высота предмета**: до 6 / 9 / 14 / 20 / 30 см — всё выше выбранного обрезается.

**Форма предмета**: «Обычная»; «Тело вращения» (бутылки, дезодоранты, вазы — каждое сечение кругом вокруг найденной оси,
бока ровные даже при бликах); «Гладкая» (сильнее сглаживание). Меняется и потом: ⋯ → Пересчитать.

## Что получается и ограничения

* Размер модели — настоящий (мм), экспорт: GLB, OBJ (с цветами вершин), PLY, STL (мм), сплэты — PLY формата 3DGS
  (SuperSplat, Brush, аддоны Blender).
* Форма строится по силуэтам: **впадины не видны** (внутренность чашки, глубокие щели закроются «крышкой»).
* **Дно** не снимается — модель снизу ровно срезана по столу.
* Не годятся прозрачные и зеркальные предметы; блестящие — лучше с формой «Тело вращения».
* На вертушке свет «едет» вместе с предметом — блики могут размазаться по цвету.

### Как маска отделяет предмет (v1.1)
* узор коврика проверяется корреляцией окна 7×7, у края силуэта — сдвинутыми окнами (край больше не «дрожит» в такт крапинкам);
* фон за листом (стол, стена) заливается от заведомо внешней области по плавности цвета — верх модели больше не «колпак»;
* мелкие островки и волоски «не фона» убираются, кромка силуэта снимается на 1 пиксель (смешанные пиксели);
* «фон», со всех сторон окружённый предметом (блик), считается «неизвестным»;
* воксель вырезается, если фоном его видят ≥ 8 % кадров (не меньше 2) — отдельные ложные «дыры» не прорезают модель.

## Устройство

| Файл | Что делает |
|---|---|
| `web/js/mat.js` | раскладка коврика, словарь меток, растр для сравнения, рисование для печати |
| `web/js/detect.js` | поиск квадратных меток и чтение их кода |
| `web/js/pose.js` | гомография, фокус по многим кадрам, поза камеры (Левенберг–Марквардт) |
| `web/js/recon.js` | маски «предмет / коврик» (сравнение с рисунком коврика, корреляция крапинок, тени), вырезание объёма, surface nets, сглаживание Таубина, цвет вершин |
| `web/js/splat.js` | растеризатор гауссовых сплэтов на процессоре с обратным проходом, Adam, деление/клонирование/чистка капель, экспорт PLY |
| `web/js/pipeline.js`, `worker.js`, `procclient.js` | конвейер обработки в фоновом потоке |
| `web/js/capture.js` | камера, слежение за ковриком, автокадры, купол покрытия, AR-рамка |
| `web/js/viewer.js` | просмотр сетки и сплэтов (WebGL2) |
| `web/js/export.js`, `matprint.js`, `store.js` | экспорт моделей, PDF коврика, хранение в IndexedDB |
| `android/` | обёртка WebView `com.example.obyom` (камера, сохранение больших файлов в «Загрузки → Объём») |
| `tests/` | синтетические сцены и проверки точности (см. `tests/README.md`) |
