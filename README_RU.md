# Shadow Morse AR — PWA prototype

Прототип PWA-игры с камерой: монстры находятся в угловом 360°-пространстве вокруг игрока, видимая зона — примерно 160° по горизонтали и 90° по вертикали. Игрок стоит на месте и вращается. Камера — фон.

## Оружие

- **Фонарные тени**: нужно светить внешним фонариком включениями/выключениями. Каждая новая вспышка рядом с монстром снимает 1 HP.
- **Лазерные пауки**: нужно провести яркой красной/зелёной лазерной точкой сквозь монстра. Каждое пересечение линией снимает 1 HP.

## Запуск локально на ПК

Дважды нажми `start_server.vbs`. Он запустит простой сервер Python:

```bash
python -m http.server 8080
```

и откроет `http://localhost:8080`.

## Важно про телефон

Для доступа к камере в браузере обычно нужен **HTTPS**. `localhost` считается безопасным, а вот `http://192.168.x.x:8080` на телефоне часто НЕ считается безопасным, и камера может не запуститься.

Для теста на телефоне лучше выложить папку на **GitHub Pages / Cloudflare Pages / Netlify**, тогда будет HTTPS и PWA сможет нормально просить камеру.

## Без Python

Само приложение не использует Python. Это чистые HTML/CSS/JS/PWA файлы. Python нужен только как удобный локальный статический сервер на ПК. На GitHub Pages Python не нужен.

## Управление

- На телефоне: после разрешения датчиков поворачивайся вокруг себя.
- На ПК без датчиков: можно перетаскивать мышью по экрану для симуляции поворота.

## Запуск через трей на Windows

1. Один раз установи зависимости:

```bat
install_tray_deps.bat
```

2. Потом запускай:

```text
start_tray_server.vbs
```

Появится иконка в системном трее. Через неё можно:

- открыть сайт на этом ПК;
- открыть Wi‑Fi адрес;
- остановить сервер и выйти.

Если иконка не появилась, запусти `start_tray_server_console.bat`, чтобы увидеть ошибку.

## Как остановить старые серверы

Файл `stop_ar_servers.bat` или `stop_ar_servers.vbs` останавливает только:

- `python -m http.server 8080`;
- `tray_server.py`.

Он не должен закрывать все Python-приложения подряд.

## ФОРМА 3D — параметрический 3D-редактор (папка `forma/`)

Приложение для Windows на Python: модели задаются текстовым сценарием, строятся
надёжным геометрическим ядром (замкнутые тела, булевы операции), показываются
в 3D, **проверяются словами** (габариты, объём, масса, толщина стенок,
симметрия, герметичность) и экспортируются в Blender-совместимые форматы.

В версии 0.2 добавлены материалы и процедурные текстуры, студийный свет и
экспозиция, анимация (вращение, формирование, разлёт) прямо внутри GLB,
анатомическая фигура человека (`human`) и открытие чужих файлов — GLB, OBJ,
STL, PLY, 3MF и `.blend` через установленный Blender.

```forma
корпус = lathe points=[[0,0],[42,0],[42,95],[0,95]] segments=144 thickness=4 open=top
ручка  = sweep path=[[40,0,28],[58,0,28],[67,0,42],[67,0,62],[58,0,76],[40,0,76]] width=9 height=13 smooth=10
кружка = union [корпус, ручка]
check кружка watertight
check кружка wall 3..5
```

* Исходники и справка: [`forma/README.md`](forma/README.md)
* EXE и ZIP собираются в GitHub Actions: **Actions → «Собрать Windows EXE — Форма 3D»**,
  файлы появляются в **Releases** (`Forma3D-<версия>-windows.zip` и `Forma3D.exe`).
* Запуск из исходников: `cd forma && pip install -r requirements.txt && python run_forma.py`
