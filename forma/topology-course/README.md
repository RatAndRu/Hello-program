# Топология тел — учебный сайт

Одностраничный курс по топологии 3D-сеток: правила, 14 пар схем «плохо → лечение»,
каталог 30 случаев, чек-листы, квиз и цифры аудита собственного экспорта.

## Как открыть

`index.html` — один самодостаточный файл: CSS, скрипты и все 31 схема зашиты внутрь
(схемы как `data:image/svg+xml;base64,…`). Ничего не нужно собирать, ставить или
подключать к сети — двойной клик по файлу, и всё работает, включая тёмную тему,
слайдеры сравнения, чек-листы (`localStorage`) и квиз.

Если хочется через сервер:

```bash
cd forma/topology-course
python3 -m http.server 8000
# http://localhost:8000/
```

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | **собранный** сайт, единственный файл, который нужен читателю |
| `src/template.html` | разметка-источник (правки вносить сюда) |
| `styles.css` | тема, светлая и тёмная (`data-theme`), стили всех блоков |
| `app.js` | данные (галерея, каталог, мифы, чек-листы, квиз, аудит) и весь интерактив |
| `assets/fig/*.svg` | 31 схема: 14 пар `<key>-bad.svg` / `<key>-good.svg` + 3 концептуальные |
| `build.py` | собирает `index.html` из шаблона и ассетов |

## Пересборка

```bash
python3 forma/topology-course/build.py          # перезаписать index.html
python3 forma/topology-course/build.py --check  # только проверить, что сборка чистая
```

`build.py` заодно проверяет целостность: существуют ли все схемы, на которые
ссылаются шаблон и `app.js`, нет ли неиспользуемых файлов и не осталось ли на
странице внешних загрузок (шрифтов, CDN, картинок с диска). Ненулевой код возврата —
значит, что-то рассинхронизировалось.

## Схемы

Рисуются кодом, без графических редакторов:

```bash
python3 forma/tools/make_topology_figures.py                      # перегенерировать SVG
python3 forma/tools/make_topology_figures.py --sheet --sheet-out /tmp/sheet.png
```

Режим `--sheet` собирает контактный лист в PNG — для глазной проверки (нужен
`resvg-py` в виртуальном окружении). После правок схем:


```bash
python3 forma/tools/make_topology_figures.py && python3 forma/topology-course/build.py
```

## Источники содержания

Текст — сокращённая и переработанная версия `forma/docs/topology_guide.md`
(11 разделов, 30 дефектов, 4 чек-листа, аннотированные источники).
Цифры в разделе «Наши цифры» получены `forma/tools/topology_audit.py` на файле
`forma/exports/living_room/living_room_diorama.glb`.
