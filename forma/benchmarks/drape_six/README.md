# Шесть диагностических проверок драпировки

**Это контрольные сценарии, а не готовые изделия и не новая версия
инструмента.** На текущем решателе часть результатов пересекает опору или
сильно меняет длины рёбер; не используйте их как безопасные модели для
экспорта. Полные измерения и ограничения проверки — в
[`docs/drape_six_results.md`](../../docs/drape_six_results.md).

| № | Файл | Проверка |
|---|---|---|
| 1 | `01_sheet_over_ball.forma` | Лист на площадку с неподвижным шаром, выступающим из неё. |
| 2 | `02_sheet_over_sheet.forma` | Лист на большую горизонтальную площадку. |
| 3 | `03_soft_sphere.forma` | Деформируемый шар на площадку: `rigid=0`. |
| 4 | `../../examples/drape_tablecloth_fast_076.forma` | Исходная скатерть 120×120 мм на столе 80×80 мм; края не обязаны доставать до пола. |
| 5 | `05_sleeve.forma` | Полый горизонтальный рукав на площадку. |
| 6 | `06_sleeve_around_rod.forma` | Рукав вокруг меньшей горизонтальной капсулы; капсула повёрнута командой `rotate`. |

В шестом случае капсула изначально соосна рукаву, целиком находится между
его торцами и не касается его стенки. Обе детали оставлены отдельными
объектами. Сценарии собираются существующей версией 0.76.1; параметрические
исходники `.forma` остаются единственным источником геометрии.

Из корня репозитория (FCL и IPC Toolkit нужны только для независимого аудита):

```sh
python -m pip install numpy manifold3d trimesh python-fcl ipctk
OPENBLAS_NUM_THREADS=1 PYTHONPATH=forma python forma/tools/drape_six_probe.py --fcl --ccd --glb --output current.json
OPENBLAS_NUM_THREADS=1 PYTHONPATH=forma python forma/tools/drape_six_probe.py --mode stop-xy --fcl --ccd --glb --output stop-xy.json
```

`--mode stop-xy` — отдельная исследовательская копия решателя, а не параметр
команды `drape` и не изменение приложения. Доступны также исследовательские
`--mode surface` и `--mode stop-xy-surface`. Итоговый JSON учитывает длины
всех рёбер, длины найденных пар стенки, объём, самопересечения, контакт с
каждой опорой, движение и GLB. Непрерывная проверка рассматривает только
линейные отрезки между концами шагов **после предварительного размещения**;
она не проверяет внутренние проекции и соседние примитивы. Малое движение не
является проверкой баланса сил, а сохранение объёма не доказывает толщину.
