# ФОРМА 3D — 3D-редактор, которым управляют словами

Параметрический редактор твёрдых тел для Windows. Модель описывается **текстовым
сценарием** (одна команда на строку), приложение строит настоящую геометрию
(замкнутые тела, булевы операции), показывает её в 3D, **словами проверяет**
результат и отдаёт готовый отчёт для следующей правки — человеку или нейросети.

```
корпус = lathe points=[[0,0],[42,0],[42,95],[0,95]] segments=144 thickness=4 open=top
ручка  = sweep path=[[40,0,28],[58,0,28],[67,0,42],[67,0,62],[58,0,76],[40,0,76]] width=9 height=13 smooth=10
кружка = union [корпус, ручка]
color кружка material=ceramic

check кружка watertight
check кружка height 90..100
check кружка wall 3..5
check кружка symmetric y
```

Такой сценарий строит ровную керамическую кружку с полостью стенкой 4 мм,
проверяет герметичность, высоту, толщину стенок и симметрию — и пишет отчёт
с фактическими числами.

## Что нового в 0.22 — настоящее яйцо, капля, крупа в тарелке и горка

![наполнение, горка, массив по кругу, яйцо и капля](docs/fill_022.png)

* **Яйцо переделано.** Старый профиль давал шип на остром конце и «клюв» —
  теперь низ яйца это четверть эллипса, а верх — кривая Безье с вертикальной
  касательной на стыке. Самая широкая точка лежит ниже середины (45 % высоты,
  у настоящего куриного яйца — 42–45 %), отношение высоты к диаметру 1.43,
  тупой и острый концы различимы на глаз. `proportion=0` — симметричный овоид,
  0.55 — куриное яйцо (по умолчанию), 1 — сильно вытянутое; `sharp=верх|низ`
  переворачивает яйцо.
* **Новый примитив «капля»** (`drop`): полушарие снизу и плавно сходящий на нет
  хвост сверху, один и тот же радиус и высота. `tip=0` — почти сфера,
  `tip=1` — длинная острая капля; стык гладкий, без «юбки».
* **Наполнение полости** (`fill`): крупа, галька, конфеты в тарелке, кружке,
  ящике или корпусе. Ядро пускает лучи сверху вниз, находит дно полости,
  проверяет лучами в стороны, что колонка внутри, и укладывает зёрна слоями до
  уровня. Параметры: `grain` (шар, горох, зерно, капля, куб, галька), `size`,
  `level` (полная тарелка или половина), `density`, `rotate`, `inset`, `seed`,
  `dome` (горка к центру) и `as=отдельные` (зёрна отдельными объектами);
  одинаковый `seed` всегда даёт одну и ту же раскладку. Зёрна садятся дном на
  дно, поэтому не висят в воздухе и не проваливаются в стенку.
* **Горка** (`pile`): насыпь из мелких деталей на плоскости — конус с округлым
  профилем. Дайте готовый предмет (`pile [капля] …`) — горка сложится из его
  копий, верхние лягут по нормали склона. `count`, `size`, `seed`.
* **Массив по кругу** (`array mode=radial`): `radius` ставит копии на
  окружность, `angle` задаёт полный круг или сектор, `spin=да/нет` —
  поворачивать ли каждую копию вокруг своей оси. Без `radius` работает
  прежнее вращение копий вокруг оси.
* **Атлас выбирается по материалу.** Для мелкого рисунка — металл, ткань, кожа,
  клетка, шум и «своя» текстура с точками/сеткой — развёртка `атлас`
  включается сама; для дерева, мрамора, камня и кирпича остаётся `auto`,
  чтобы рисунок не рвался на гранях. Явный `uv=` в команде всегда главнее.
* **Приёмов стало 20**: «Наполнение», «Горка» и «Массив по кругу» добавлены к
  17 прошлым; у всех поля с живым предпросмотром сценария.
* **Новый пример `examples/snack.forma`** — тарелка каши, горка гальки, яйцо,
  капля и кольцо из колонн; 10 проверок, все проходят.
* **316 автотестов** (27 новых), `--uistest`, `--selftest` — зелёные.

## Что нового в 0.21 — приёмы с настройками и быстрая фаска

![bevel: скругление и быстрая фаска](docs/bevel_021.png)



* **У приёмов появились поля, как у фигур.** Меняете число в карточке — под ней
  сразу пересчитывается сценарий, кнопка «Вставить» добавляет уже готовый текст
  с вашими числами. У кружки это ⌀, высота, стенка и ручка (да/нет), у накатки —
  число канавок и глубина, у отверстий — сетка, шаг и **сдвиг сетки по детали**.
* **«Сечение, проба и паспорт» разведены на три карточки**: `section` — контур
  разреза, `probe` — есть ли материал в точке, `passport` — габарит, объём,
  масса, герметичность. Одна карточка на три разных вопроса путала.
* **«Отверстия сеткой» получили сдвиг**: `holes … offset=[12,-8]` двигает всю
  сетку внутри детали, а не только центрирует её.
* **«Резьба: болт» убрана** — это был однострочник-дубль команды `thread`;
  карточка самой команды с параметрами осталась в «Все команды».
* **Новые приёмы:** «Корпус с полостью» (`shell`), «Зеркальная пара»
  (`mirror_copy`), «Сечение», «Проба материала», «Паспорт детали», «Надпись».
  Всего 17 приёмов, и все 17 собираются со значениями по умолчанию.
* **`bevel` стал быстрым.** Тело без острых рёбер пропускается сразу: сфера
  0.00 с, тор 0.01 с (было 17.7 и 71.4 с). На деталях с сотнями кромок каждая
  выпуклая кромка снимается клином и всё вычитается одним пакетом: панель с
  12 отверстиями 0.22 с (было 80.6 с), шестерня 0.11 с (было 14.7 с), тарелка
  со стенкой 4 мм 0.14 с (было 49.5 с и отказ по объёму).
* **Режимы `bevel`:** `mode=авто` (простое — скругление радиусом, сложное —
  фаска 45°), `mode=скругление`, `mode=фаска`. В логе сборки видно, что
  применилось.

## Что нового в 0.20 — чистый старт, кисть без следов и новые фигуры

* **Выделение кликом работает и во время анимации.** Раньше движение клипа
  перебивало выбор; теперь клик по детали выделяет её на любом кадре, а
  подсветка строки сценария по-прежнему только у сборки по шагам.
* **Пустой сценарий даёт чистую сцену.** Ни модели, ни подсветки, ни кисти,
  ни остатков прошлой сборки — просто пустая сцена и надпись «сцена пуста».
* **Ластик стирает только рисунок кистью** и не трогает материал детали и
  регионы `paint`; то же самое делает команда `ластик`.
* **Атласная развёртка `uv=атлас`.** Каждый треугольник получает собственное
  место на текстуре: без наложений, без растяжек и без «швов» на составных
  деталях.
* **Заготовок анимаций — сколько угодно.** `заготовка names=[дверь, ящик]`,
  затем `animate … scene=дверь`; каждая анимация живёт своей жизнью.
* **Шкаф доделан:** колёсики крутятся, крепёж — нет; полки на саморезах, задняя
  стенка из ХДФ на гвоздях; крепёж у обеих дверей; остриё смотрит внутрь,
  шляпки утоплены в доску.
* **Крепёж стал настоящим:** `screw` с крестовым шлицем и остриём,
  `nail` с плоской шляпкой и `drive` — сажает саморез в доску по нормали
  и проверяет, что остриё не вышло с другой стороны.
* **Инструменты пересмотрены:** `worm_shaft` вместо «червяка», `leg` с пятой
  и регулировкой, `gusset` с вырезом `дуга/ступени/прямо`, `profile2020`
  без центрального отверстия и с закрытым T-пазом.
* **Удалены `drawer`, `panel` и `cup`** — ящик и панель собираются булевыми
  командами, кружка есть готовым рецептом в «Инструментах».
* **Новые примитивы:** пирамида, икосфера, алмаз, призма с `r2`, тор
  `inner/outer/thickness`, цилиндр с `r2`, яйцо, арка, полусфера/миска, облако.
* **Пример «Полигоны»:** знак с окнами из контуров, восьмиугольная рамка,
  кристалл оболочкой, косынка и рисунок кистью; две готовые анимации.
* **289 автотестов**, `--uistest`, `--selftest` — зелёные.

## Что нового в 0.19 — сопряжения, мастер зазоров и карточки команд

* **Сопряжения — деталь ставится на место отношением, а не координатами:**
  `сопряжение колесо рейка type=паз axis=y`, `сопряжение дверь корпус type=петля
  point=[-70,80,100] angle=-28`, `type=плоскость|ось|зазор|точка`. Программа сама
  сдвигает или поворачивает деталь, запоминает связь в сцене и показывает её в
  отчёте (`payload.mates`); `check имя связь` пересчитывает остаток и краснеет,
  если деталь разъехалась. Это ограничение сборки, как mates в CAD, а не
  деформация поверхности — геометрия детали не меняется;
* **Мастер зазоров** — вкладка «Связи»: считает точные расстояния между телами
  (`min_gap`) и показывает, что с чем соединено, какая деталь висит и на сколько,
  где щель; у висящей детали есть кнопка «связать», которая дописывает
  `сопряжение` в сценарий;
* **Карточка на каждую команду** в «Инструментах»: 103 карточки по категориям
  с параметрами и примером; «Вставить пример» дописывает строки с уникальными
  именами объектов, ничего не затирая;
* **Импорт своего GLB обратно** работает без `repair`: швы свариваются,
  оси возвращаются в Z-вверх (`импорт = import file=кружка.glb`);
* 17 новых тестов на сопряжения, правило `связь`, мастер зазоров и импорт —
  всего 288 тестов, `--uistest`, `--selftest` и стенд интерфейса зелёные.

## Что нового в 0.18 — регионная покраска, собранные часы и мотоцикл

* новая команда `paint` — красит часть предмета, а не полигон за полигоном:
  `paint кружка #2f6fb0 side=верх`, `paint кружка #d94f3d height=18..34`,
  `paint кружка #ffffff radius=0..18`, `paint кружка #22aa55 box=[x0,y0,z0,x1,y1,z1]`.
  Регион задаётся словами и числами: сторона по нормалям, полоса по высоте,
  кольцо по радиусу или область. Краска ложится и на снимок PNG, и в GLB
  (`COLOR_0` на вершинах), а кисть в браузере её не стирает;
* кисть в браузере: включается только у выделенного видимого предмета, можно
  вести мазок с зажатой кнопкой, ПКМ не рисует и не выделяет;
* часы переделаны: механизм собран «хаотично», но по-настоящему —
  межосевые расстояния считаются как `a = m·(z1+z2)/2`, колёса не наезжают
  друг на друга, а зубья входят в зацепление. 60 деталей, 36 проверок,
  30 клипов анимации: мотор, барабан, храповик, минутное, промежуточное,
  секундное, анкерное, вилка, баланс с волоском, стрелки;
* мотоцикл переделан целиком: колёсная база 1400, вилка 30,3° сходится
  с осью колеса, маятник и амортизатор держат заднее колесо, крылья на
  стойках, тормозной диск и суппорт, проводка рамы. Все 50 деталей
  соединены — это теперь проверяет автотест;
* при анимации предметы больше не выделяются: подсветка и слежение за
  сценарием остались только у сборки по шагам; ПКМ не возвращает камеру
  в режиме «вокруг предмета»; телепорт к предмету — только при первом
  выделении и плавно;
* починен винт с полукруглой головкой (`screw … head=полукруг`);
* 10 новых тестов: регионы покраски, `COLOR_0` в GLB, связность сборок,
  зацепление колёс часов — всего 271 тест.

## Что нового в 0.17 — корпуса, часы и мотоцикл, экспорт анимации

* **Удаление клавишей.** Delete (и Backspace) убирает выделенный предмет или
  выделенный сектор пространства; в редакторе текста клавиша работает как
  обычно. То же действие есть в контекстном меню правой кнопкой.
* **«Инструменты» стали полнее и разборчивее.** 44 карточки в пяти группах:
  примитивы (куб, сфера, цилиндр, конус, тор, призма, капсула), корпуса и посуда
  (корпус кружки, панель с бортиком, выдвижной ящик, коробка), механика
  (рейка, муфта, вал, колесо, шестерня, пружина, профиль 2020, направляющая,
  косынка, ножка, люверс, червяк, радиатор), крепёж (болт, гайка, винт, шайба,
  петля, уголок, подшипник, ролик, шкив) и природа (камень, лист, ветка, рог).
  «Скрутка» и «Изгиб», «Болт» и «Гайка», «Фаска» и «Облегчение» — отдельными
  карточками, каждая вставляет только свою команду.
* **Корпус кружки и коробка** — отдельные инструменты: `cup` с `handle=нет`
  даёт вогнутый цилиндр со стенкой и дном, `box_body` — коробку с полостью,
  `drawer` — целый ящик с фасадом, ручкой и направляющими.
  *В 0.20 `cup`, `panel` и `drawer` удалены: корпус кружки собирается
  цилиндрами и `difference`, ящик и панель — булевыми командами.*
* **Десять новых команд:** `panel`, `drawer`, `rail`, `profile2020`, `gusset`,
  `leg`, `grommet`, `worm`, `horn`, `knurl`. Всего в реестре 101 команда;
  у каждой — подсказка, пример и проверка герметичности.
* **Пример «Мотоцикл».** База 1400 мм, колёса Ø600, вилка 31°, рама из труб,
  бак-оболочка, седло, крылья, двигатель с рёбрами, выпуск, цепь, амортизаторы,
  зеркала и фара. Ничего не висит в воздухе: крылья посажены на вилку и
  маятник, номер — на хвост. Сцена «езда»: колёса катятся, подвеска покачивается,
  руль поворачивает; «прыжок» — упругий прыжок с приземлением.
* **Пример «Скелетон-часы».** Корпус Ø420, механизм с модулем m = 2:
  барабан 48 → минутное 30 → промежуточное 36 → секундное 30 → анкерное 30,
  анкер, баланс с волоском и мотор завода. Стрелки стоят на 10:10:35.
  Сцена «ход»: баланс качается ±200° (2 Гц), анкер ±14°, анкерное колесо шагает
  по 6° каждые 0,25 с, секундная стрелка идёт по 6°, минутная и часовая ползут
  медленно. Все клипы параллельны — механизм работает как один.
* **Витрина разрослась до 44 предметов:** массив по кругу (турбина), сеткой
  (плитки), линейный (штифты), разброс листвы, оболочка, отверстия, протяжка,
  тела вращения и все новые детали.
* **Колесо исправлено:** спицы строятся в плоскости колеса, ось — Y, катится
  вдоль X; в шкафу колёсики повёрнуты по рейкам и стоят в задней половине ящика,
  поэтому при выезде они действительно катятся, а не вертятся на месте.
* **Экспорт анимации в файл.** В меню «Экспорт» и на панели анимации —
  «GIF» и «WebM»: GIF пишется своим кодеком (медианное квантование, до 240
  кадров, 12 кадр/с, ширина до 560), WebM — через MediaRecorder браузера
  (30 кадр/с, до 600 кадров). Файл скачивается в «Загрузки» и открывается
  в любом мессенджере; GIF можно вставлять в чат, WebM — прикреплять файлом.
* **Кубы обхватывают предмет при любой ячейке.** Раньше объём ограничивался
  32 секторами на ось и при мелком кубе сжимался внутрь модели. Теперь число
  клеток ограничено общим бюджетом (48 000), а не осью: объём честно окружает
  модель, а если выбранный предмет — ещё и сужается до него. Когда куб мельче,
  чем влезает, подпись пишет: «5 мм → клетки по 13,7 мм (мельче не влезает)».
* **Строка сценария подсвечивается во время анимации.** В номерах строк видно,
  какая команда играет сейчас (параллельные движения — бледнее), полоса
  подсветки ползёт по тексту, текст сам подкручивается за анимацией. Видно
  и для клипов, и для кадров сборки.
* **Шаги сборки пропускают служебное.** `check`, `color`, `probe`, `passport`,
  `light`, `scene`, `param`, `note` не меняют форму — в кадрах сборки их нет,
  поэтому анимация не «стоит» на проверках (у часов 109 кадров из 195 команд).
* **Заслонки — прозрачным каркасом.** Выделили деталь — всё, что закрывает её
  от камеры, показывается сеткой на 16 % прозрачности; клик по каркасу
  проваливается к детали за ним. Кнопка «заслонки» отключает режим, при
  повороте камеры каркас пересчитывается.
* **Вращение вокруг выделенного.** Кнопка «вокруг» ставит центр вращения и
  приближения в центр выбранного предмета, ⌖ наводит камеру на него; при
  снятии выбора камера возвращается к центру сцены. То же — в контекстном меню.
* **Статистика выбранного, а не всей сцены.** В подписи над окном — габариты,
  объём, масса, треугольники, число частей, площадь и строка сценария именно
  выбранной детали; в статусе и в сводке справа тоже она. Сняли выбор — снова
  цифры сцены.
* **Анимация не запускается сама.** При открытии примера или проекта видно
  готовую статичную модель, а подпись говорит: «анимация готова (36 движений) —
  нажмите ▶». Движение начинается только по кнопке.

## Что нового в 0.16 — несколько сцен, кисть по граням и крепёж

* **Заготовленные сцены в одном файле.** У каждой строки `animate` можно указать
  `scene=дверь` или `scene=ящик`; в плеере появляется переключатель сцен, у каждой
  своя длительность, а сценарий при переключении не меняется. «Все сцены» играет
  их одновременно. Пример «Шкаф» показывает дверь и ящик по отдельности,
  «Механика» — вентилятор, прыжок и падение.
* **Новые виды анимации.** `jump height=120 elastic=да` — прыжок с упругим
  сжатием при отталкивании и приземлении, `fall height=180 elastic=нет` —
  падение без деформации, `fan rpm=900` — раскрутка вентилятора с разгоном.
  `roll` теперь крутит колесо вокруг собственной оси: точка поворота каждого
  узла считается в его системе координат, поэтому колёса катятся по рейкам,
  а не летают вокруг центра модели.
* **Контекстное меню правой кнопкой.** На выбранном предмете: выделить,
  скрыть/показать, показать полигонами (или вернуть сплошной вид), выделить все
  кубы пространства, где он находится, удалить.
* **Кисть по полигонам.** Кнопка «кисть» и цвет в панели материала: клик красит
  одну грань, «сброс» возвращает материал. Покраска не сбивается анимацией.
* **Бесшовная текстура.** Развёртка `auto` — трипланарная по мировым осям:
  у составных деталей нет швов, растяжения и перпендикулярных стыков на
  переходах.
* **Крепёж и фурнитура — восемь новых фигур:** `nut`, `bolt`, `screw`, `hinge`,
  `bracket`, `bearing`, `caster`, `pulley` (всего в «Инструментах» 16 фигур).
  Гайки с резьбой, болты, саморезы, мебельные петли, уголки, подшипники,
  ролики и шкивы — настоящие замкнутые тела с проверкой `watertight`.
* **Шкаф стал честнее:** ручка ящика входит в группу ящика, петли — в группу
  двери, стенки и рейки не пропадают ни в одном кадре.
* **Примеров теперь двенадцать** — добавилась «Механика».

## Что нового в 0.15 — фигуры, кубы пространства и конец анимации

* **Готовые фигуры — одна команда вместо десятка операций.** Восемь тел
  в категории «Примитивы»: звезда, кружка, тарелка, пружина, шестерня, шайба,
  кубик с отверстием и кольцо. Все — настоящие замкнутые тела: их можно резать,
  склеивать и проверять обычными `check`.
  `звезда = star points=5 outer=60 inner=25 depth=12 bevel=2`,
  `тарелка = plate diameter=220 depth=26 wall=4`,
  `шестерня = gear teeth=20 module=2 thickness=8 bore=8`.
* **«Инструменты» в шапке — библиотека с параметрами.** У каждой фигуры поля
  (лучи, глубина впадин, сглаживание, бевел, стенка, витки, модуль…), кнопка
  «Добавить» пишет строку в конец сценария с уникальным именем. Рядом — приёмы:
  надпись, резьба, уклон, сечение/проба/паспорт, скрутка и изгиб, фаска и
  облегчение сетки.
* **Конец анимации без повтора.** В плеере появился переключатель
  «повтор: авто / всегда / стоп». «Стоп» — дойти до последнего кадра и
  остановиться; настройка запоминается и не сбрасывается пересборкой.
  В сценарии то же самое делает `loop=нет` у `animate`.
* **Пустое пространство — кубическими секторами.** Кнопка «кубы» делит место
  вокруг модели на кубы с настраиваемым размером. Клик выбирает сектор,
  Shift — добавить, Ctrl — убрать, рамка — сразу много. К выделенному объёму
  прикрепляется приписка: «поставить здесь полку». В замечании сохраняются
  число кубов, их индексы (`i 0…1, j 0…0, k 0…1`), центр и объём, а в сценарий
  добавляется комментарий с теми же координатами.
* **Примеры стали короче.** Убраны банан, гриб, кубик с отверстием, кружка со
  студией, «надпись, резьба и сечение», кружка с пошаговой сборкой и витрина
  инструментов. Их место — «Инструменты» и одиннадцать примеров, которые
  действительно показывают разные возможности.

## Что нового в 0.14 — у каждого объекта своя анимация

* **Группы — `дверь = group [фасад, ручка]`.** Группа двигается одним клипом,
  а её объекты могут анимироваться сами: ящик едет, колёсики под ним крутятся.
  `color`, `show`, `hide`, `delete` понимают имя группы.
* **Анимация привязана к объекту.** `animate дверь turn angle=-95 axis=z
  pivot=[-481, -216, 0]` — поворот вокруг петли; `animate дверь move dy=-250` —
  выдвижение; `animate ящик scale from=1 to=1.1` — только этот объект.
  У каждого объекта своя очередь клипов, поэтому дверь, ящик и колёсики
  двигаются одновременно, а `track=1..8` нужен лишь для нескольких
  независимых движений одного и того же объекта.
* **Ось вращения — `pivot=[x, y, z]`.** Дверь открывается вокруг петли,
  колесо — вокруг своей оси, а не вокруг центра модели.
* **Качение — `roll`.** `animate колесо roll distance=250 radius=13 axis=x`:
  угол поворота = путь / радиус, знак оси задаёт направление; колесо
  одновременно едет и крутится. `spin turns=2` — точное число оборотов.
* **Видно, что происходит.** Под таймлайном подпись «движется: …» перечисляет
  активные объекты, а в просмотре кадров сборки подсвечивается тот объект,
  который появился или сейчас деформируется.
* **Пример «Шкаф» — `examples/wardrobe.forma`.** Витрина 1000 × 450 × 1200:
  накладные двери с филёнками и ручками, ящик на телескопических
  направляющих, рейки и колёсики. Один клип открывает дверь на 100°,
  выдвигает ящик на 250 мм и катит колёсики (9 проверок, все ✓).

## Что нового в 0.13 — деталь можно измерить, разрезать и подписать

* **Сечение в 2D — `section z=40`.** Плоскость режет деталь, приложение строит
  контуры (внешние и внутренние), показывает их в панели «Отчёт» и пишет
  **DXF** и **SVG** — форму можно проверять не по отчёту, а по чертежу.
  `section плоскость=x at=0` режет по вертикали; `show=true` кладёт тонкий
  срез в сцену.
* **Проба материала — `probe x=0 y=0 z=40`.** Отвечает «материал есть / пусто» и
  показывает расстояние до стенки: так проверяют полости, тонкие стенки и то,
  что внутри детали нет лишнего.
* **Паспорт детали.** В отчёте появился блок **ПАСПОРТ ДЕТАЛИ**: габариты,
  центр, масса, минимальная стенка, найденные вертикальные отверстия
  (ø, координаты, сквозное/глухое) и полость. Команда `passport деталь`
  печатает то же в журнал.
* **Честный контроль формы — расстояние Хаусдорфа.** У `simplify` появился
  параметр `deviation=0.2`: упрощение повторяется, пока двустороннее
  отклонение от исходника не уложится в допуск. Проверка
  `check деталь deviation "эталон.stl" 0.3` сравнивает модель с эталоном
  (STL/OBJ/GLB/…) и говорит макс/среднее отклонение в миллиметрах.
* **Надписи и логотипы — `text` и `emboss`.** Свой векторный шрифт (латиница,
  кириллица, цифры), без внешних файлов: `надпись = text "ФОРМА 3D" size=20
  depth=3`. `emboss [деталь] text="ФОРМА" size=14 depth=1` выдавливает надпись
  на плоской грани или **обёртывает вокруг цилиндра** (кружка, бутылка, крышка);
  `mode=engrave` гравирует, `mode=relief` делает рельеф.
* **Резьба и технологические уклоны.** `thread diameter=10 length=24 pitch=1.5`
  строит настоящую винтовую резьбу (болт), `internal=true` — гайку с внутренней
  резьбой. `draft [деталь] angle=2` даёт уклон стенок для формы и печати.
* **Экспорт сечений.** В меню «Экспорт» добавлены `DXF` и `SVG`; рядом с
  панелью сечения — те же две кнопки. Файлы по-прежнему попадают в «Загрузки».

## Что нового в 0.12 — несколько дорожек, свои клипы и ключевые кадры

* **Клипы играют параллельно.** У каждой строки `animate` есть дорожка
  `track=1…8`: клипы одной дорожки идут друг за другом, разных — одновременно.
  Пример «Анимация по дорожкам и ключи» показывает четыре дорожки в одной сцене.
* **Свои клипы, а не только заготовки.** Новые виды: `move` (перемещение на
  `dx/dy/dz` или в точку `to=`), `scale` (`from=… to=…`), `turn` (доворот на
  `angle=`), `wait` (пауза) и `morph` (изменение геометрии во времени).
  У `move`, `scale`, `turn` можно указать `object=имя` — тогда движется только
  эта деталь, вокруг собственного центра.
* **Ключевые кадры.** `keyframe имя at=2 pos=[0,0,30] rot=[0,0,90] scale=1.2` —
  между ключами поза, поворот и масштаб интерполируются плавно. Ключи
  отмечаются ромбиками на таймлайне и играют вместе с клипами.
* **Изменение формы (`morph`).** `animate kind=morph param=R from=25 to=55
  samples=12` перестраивает модель с другим значением параметра сценария —
  так можно показать «вырастание» ручки, изменение радиуса, толщины стенки.
  Кадры строятся на сервере и кешируются, чтобы проигрывание не спотыкалось.
* **Оси — однозначно.** В редакторе и в подсказке прямо написано: `x` —
  влево/вправо, `y` — глубина, `z` — вверх; `-z`, `-x`, `-y` — обратное
  направление. Для `turn` можно задать и `axis=x` с `angle=-45`.
* **Таймлайн не вылезает за окно.** Строки дорожек прокручиваются внутри панели
  (`max-height`), шаги сборки — в отдельной горизонтальной прокрутке, ключи
  имеют свою полосу. Сотни клипов и ключей больше не ломают интерфейс.
* **«Сборка по шагам» работает внутри клипов.** Если `assembly` стоит на
  дорожке среди других клипов, при прокрутке в её время показываются
  настоящие кадры сценария, а после — возвращается итоговая модель.
* **Измерения и крепление без координат.** `h = height(крышка)`,
  `w = width(корпус)`, `top/bottom/left/right`, `cx/cy/cz`, `volume` прямо в
  формулах; `place [деталь] on=корпус side=top offset=2` ставит деталь на
  поверхность другой — это заметно упрощает сценарии для нейросети.
* **GLB стал полнее.** В файл пишутся все клипы (`FormaSpin`, `FormaMove`,
  `FormaScale`, `FormaTurn`, …) и ключевые кадры (`FormaKeys_<имя>`) — Blender
  видит их действиями. Для объектных клипов создаются узлы
  `FormaPivot_<имя>`, чтобы вращение шло вокруг центра детали.

## Что нового в 0.11 — анимация играет, история пишется сама

* **Анимация больше не молчит.** Найдена и исправлена ошибка загрузки
  (`this.applyShading is not a function`): она обрывала `load()` сразу после
  появления модели, поэтому тайм-лайн не настраивался и ни один клип не играл.
  Теперь `animate` реально воспроизводится — у кружки, человека, любой модели.
  У кружки в примере `mug.forma` вращение включено по умолчанию.
* **Предпросмотр без сценария.** Если строк `animate` нет, кнопка «▶ играть»
  всё равно показывает вращение (6 секунд), не записывая его в сценарий, —
  воспроизведение доступно для любого объекта.
* **Ось вращения — по центру.** Ручка кружки больше не сдвигает ось: вращение
  идёт вокруг вертикали через центр модели, а не по орбите.
* **Сбой оформления — не ошибка загрузки.** Модель добавляется в сцену первой,
  и только потом применяются свет, тени и анимация: если что-то в оформлении
  не сложилось, вы не увидите ложное «не удалось показать модель».
* **История пишется автоматически.** Правка в редакторе, команда, материал,
  текстура, удаление объекта — каждый шаг попадает в историю (с паузой набора
  0,65 с). Откат и возврат работают кнопками ↶/↷ и кликом по шагу в списке.
* **Удаление конкретных объектов.** 🗑 в строке списка убирает объект из
  сценария вместе с его `color`, `texture`, `hide`, `show`; Ctrl+Z возвращает.
  В сценарии появляется команда `удалить имя` (и `удалить all` для очистки).
* **Кисти человека больше не отрываются.** В SDF-сборке добавлено запястье:
  тело, голова, кисти и стопы — одна замкнутая оболочка, `--selftest` проходит
  полностью (раньше было «число частей: 3»).

## Что нового в 0.10 — подсветка выбора, спайка и песочница текстур

* **Выбранный объект видно в окне.** Клик по детали в правом меню подсвечивает
  её в 3D (свечение и голубая рамка), двойной клик наводит камеру на деталь.
  Выделение мышью в окне, наоборот, подсвечивает строку в списке.
* **Скрытые детали не теряются.** Объекты, вошедшие в `union`/`weld`
  (например, цилиндр и ручка кружки), остаются в списке скрытыми и
  открываются одним кликом по глазку — в том числе после пересборки.
* **`weld` и `trim` — спайка без скрытой геометрии.** `trim [ручка, корпус]`
  отсекает лишнее, `weld [корпус, ручка] tolerance=0.05` спаивает стык и
  сваривает вершины: внутри не остаётся деталей «одна в другой», шов ровный.
  В журнале — сколько треугольников было и стало.
* **Меньше лишних граней на ровных участках.** Число сегментов тел вращения и
  примитивов ограничивается допуском 0,06 мм: `segments=400` у кружки больше
  не раздувает модель, а `optimize all tolerance=0.15` (синоним `simplify`)
  облегчает сразу все объекты. Кнопка **«облегчить»** в списке объектов
  делает это одной командой.
* **Песочница генеративных текстур.** В панели материала — «Песочница…»:
  восемь узоров, два цвета, масштаб, вариация и **рельеф 0…1**. Рельеф
  запекается в цвет и в **карту нормалей**, которая уходит и в GLB (Blender
  видит `normalTexture`), и в окно приложения. Готовый рецепт показан строкой
  `texture … kind=своя pattern=… scale=… relief=…` — её можно скопировать,
  сохранить в сценарий или отдать нейросети.
* **Многострочный сценарий — в командной строке.** Поле ввода стало
  многострочным (Enter — выполнить, Shift+Enter — новая строка), поэтому
  большой сценарий вроде «яблока» вставляется и собирается целиком.
* **Яблоко без «переворота».** Пример `apple` построен телом вращения с
  настоящей верхней чашечкой (из неё растёт черешок) и нижней ямкой;
  профиль — сглаженная сфера с гауссовыми впадинами, 9/9 проверок.
* **Манекен — только в T-позе.** Из примеров убран «человек-манекен»,
  остались витринный манекен в T-позе, анатомическая фигура и остальные
  модели.

## Что нового в 0.9 — анимация как в редакторе

* **Данные рядом с EXE.** `projects`, `exports`, `renders`, `prompts`, `textures`,
  `imports` создаются в той же папке, что и `Forma3D.exe`. Папки
  `%APPDATA%\Forma3D` и `~/.forma3d` больше не используются: при первом запуске
  старые файлы переносятся в новые папки, а пустые старые удаляются.
  Готовые модели по-прежнему копируются в «Загрузки».
* **Тайм-лайн и редактор анимации.** Под окном модели — дорожка клипов,
  прокрутка времени, шаг по кадрам (◀ / ▶|), play/pause, скорость и счётчик
  «кадр N из M». Кнопка «✎ редактор» пишет команды `animate` в сценарий:
  вид, ось, секунды, старт, зацикливание. Клипы можно удалять по одному.
* **Несколько клипов.** Строк `animate` может быть сколько угодно; они играют
  друг за другом (или с явным `start=`). Каждый клип уходит в GLB отдельным
  действием — в Blender это `FormaSpin`, `FormaFormation`, `FormaExplode`.
* **Анимация сборки.** `animate kind=assembly hold=0.8` показывает, **как**
  собирается модель: каждая операция сценария — настоящий кадр, то есть
  промежуточная геометрия, а не имитация. Шаги можно листать по одному.
* **Исправлен баг «В сценарии нет анимации».** Состояние кнопки и дорожки
  считается по сценарию (`payload.timeline`), а не по внутренним объектам окна;
  если анимации действительно нет, приложение так и говорит и открывает редактор.
  Разлёт и формирование теперь гарантированно двигают модель.
* **Многострочная вставка.** Сценарий, вставленный в командную строку,
  разбирается построчно и заменяет текущий (откат — Ctrl+Z).

## Что было в 0.8 — приложение стало в разы легче и быстрее

* **EXE похудел примерно втрое (80 МБ → около 25 МБ).** Из сборки убраны
  библиотеки, которые приложению не нужны: scikit-image и scipy (≈130 МБ
  распакованных) и Pillow (≈22 МБ). Поверхность из поля расстояний теперь
  извлекает свой мешер `forma/mesher.py` (surface nets на numpy), а PNG
  пишет и читает свой кодек. Функции остались те же: капли, SDF-формулы,
  фигура человека, свои текстуры, экспорт GLB с текстурами и анимацией.
* **Быстрее запуск.** Однофайловый EXE при старте распаковывается во временную
  папку; объём распаковки уменьшился втрое — окно появляется заметно раньше.
* **Свой мешер вместо marching cubes.** На гладких полях он даёт более гладкую
  поверхность и меньше треугольников: у пришельца 17 890 вместо 47 504,
  у капли — 16 974 вместо 67 768 при том же объёме (расхождение 0,3 %).
* **Симметрия не считается «на всякий случай».** Это самая дорогая метрика
  (две булевы операции): теперь она считается по тем осям, которые просят
  проверки (`check имя symmetric x`) или по всем трём, если сетка небольшая.
  Кузов 2,16 → 0,83 с, манекен 1,74 → 1,07 с, человек 2,55 → 1,90 с.
* **Не считаем одно и то же дважды.** Толщина стенки и симметрия кэшируются
  по объекту, поэтому проверка не повторяет работу анализа.
* Итог по 15 примерам: 29,3 с (0.6) → 17,3 с (0.7) → **12,4 с (0.8)**.

## Что было в 0.7

* **Скругление рёбер по-настоящему.** `fillet` теперь умеет выбирать кромки:
  `edges=convex` (наружные), `edges=concave` (внутренние стыки) или `all` (по
  умолчанию). Новый `chamfer` снимает кромку плоской фаской 45°:
  `плита = chamfer [плита] width=2 edges=convex`. Размер детали не меняется,
  объём меняется только там, где сняли/добавили материал.
* **Математические поверхности быстрее в 3–4 раза.** Поле SDF считается
  массивами numpy, поверхность извлекает свой мешер (surface nets):
  «капля» 5,8 → 1,4 с, `blob` 3,9 → 0,6 с. Формула проверяется один раз,
  «плохие» точки не роняют процесс, поверхность на границе области
  закрывается крышкой, а не остаётся дырой.
* **Меньше лишних треугольников без потери формы.** Результат SDF
  упрощается на 0,06 шага сетки с контролем объёма (±3 %): у пришельца
  47 504 → 17 432 треугольника, у капли 67 768 → 18 838 при том же объёме.
* **Метрики дешевле.** Толщина стенки считается по упрощённой копии
  (допуск 0,05–0,2 мм) и не считается дважды для одного объекта: сборка
  кружки 1,45 → 0,36 с, человека 5,70 → 1,9 с, все 15 примеров 29,3 → 12,3 с.
* **`tri_quality` честнее.** «Иглой» считается треугольник с углом меньше 3°
  (веерные торцы цилиндров больше не считаются браком): цилиндр и сфера — 0 %,
  плита с фаской — 28 % (это правда про minkowski, см. «Что не сделано»).
* **Шестерня и пробка.** У шестерни настоящий зубчатый венец из 20 зубьев
  (было почти гладкое кольцо), у пробки бутылки — 32 глубокие ложбины и
  поясок; 22 регрессионных теста.

## Что было в 0.6

* **Мышь как в 3D-редакторе.** Левая кнопка — вращение, колесо — масштаб,
  **правая кнопка — перемещение по сцене**. В режиме «выбор» левая кнопка
  **тянет рамку**: всё, что попало внутрь, подсвечивается и описывается
  (площадь, число треугольников, координаты). Shift добавляет область,
  Ctrl+клик убирает.
* **Файлы — в «Загрузки».** Экспорт GLB/STL/OBJ/PLY/3MF/BLEND/ZIP, снимки и
  сохранение проекта кладут файл в `Downloads` и показывают полный путь.
* **Свои текстуры.** Кроме готовых (дерево, мрамор, металл, ткань, кожа,
  керамика, клетка, кирпич, шум) появились пользовательские:
  `texture кружка kind=своя pattern=волны color1=#1f6f8b color2=#d7e6ea`.
  Узоры: полосы, клетка, волны, градиент, шум, камень, точки, сетка.
* **Швов нет.** Рисунок генерируется бесшовным по построению, а UV-развёртка
  по-треугольно сшивает край цилиндра — полоса на стыке исчезла.
* **Экономия треугольников.** Число сегментов примитивов и тел вращения
  считается по размеру и допуску: куб — 12 треугольников, сфера Ø400 —
  меньше 20 тысяч, объём держится в пределах 0,6 %.
* **Свет без провалов.** Добавлена минимальная освещённость: внутренние
  полости и нижние грани видны, чёрных «дыр» нет.
* **Честные инструменты.** `bevel` теперь настоящая фаска с радиусом в мм
  (размер детали не меняется), `bend`/`twist` дробят сетку по длине ребра,
  `box round=` разрешает скругление в половину толщины, `simplify` проверяет
  отклонение, `from_sdf` не падает на плохих точках формулы.
* **Импорт без сюрпризов.** `unit=auto` больше не угадывает масштаб,
  `repair` по умолчанию выключен и предупреждает, если починка меняет объём.
* **Понятные ошибки.** Повторное имя объекта, деление на ноль, `fillet [нет]` —
  вместо молчаливой замены и «неизвестной команды» объяснение и подсказка.
* **Новые проверки.** `sharp_edge`, `tri_quality`, `wall_min` (с координатой
  самого тонкого места), `clearance` как синоним `gap`.
* **Консоль.** `forma diff a.forma b.forma`, `forma doctor`,
  `forma build --strict` (код 3 при невыполненной проверке), `--json`,
  `--digest`, `--trace`, экспорт `--format 3mf`.
* **Запрос к нейросети** теперь содержит таблицу метрик прошлой сборки:
  габариты, объём, массу, треугольники, стенку, список невыполненных проверок.

## Что нового в 0.3

* **Командная строка.** Внизу окна — строка, куда пишется команда сценария.
  Enter дописывает её в сценарий и сразу собирает модель; ошибки показываются тут же.
  Работают и быстрые действия: `/снимки`, `/отчёт`, `/справка`, `/очистить`.
* **Режим «выбор».** Кнопка «выбор» включает выделение областей: клик по модели
  подсвечивает треугольники вокруг точки и показывает координаты центра, размер
  области, площадь и число треугольников. Ползунок меняет радиус выделения.
* **Замечания к областям.** В карточке выделения можно словами сказать, что не так
  («здесь тонко», «слишком остро»). Замечание вместе с координатами попадает
  в отчёт, в журнал и в запрос для нейросети.
* **Вырезать выделенное.** Кнопка дописывает в сценарий сферу и `difference`,
  то есть правка остаётся параметрической и повторяемой.
* **Журнал действий.** Приложение помнит, что собрано, что снято, что не выполнено
  из-за ошибок команд, — и включает это в отчёт («сделано / не сделано»).
* **Координаты без тонн текста.** В отчёте есть центр и границы каждого объекта;
  для выделенной области — её собственные координаты и площадь.
* **Справочник один раз.** Подробные правила команд прикладываются к запросу
  по галочке (первый раз), дальше идут только конкретные отчёты по модели.
* **Человек ближе.** Переработаны голова, веки, брови, нос и губы, стопа и торс.

### Человек

```
человек = human height=1780 sex=м build=спортивный pose=a detail=средний hair=да eyes=да
color человек #e2b79b rough=0.58
texture человек kind=кожа scale=0.8
animate kind=spin seconds=12
check человек height 1770..1790
check человек watertight
```

`sex` — `м`/`ж`, `build` — `худой`, `обычный`, `спортивный`, `плотный`, `полный`
или число `0.82…1.45`, `pose` — `a`, `t`, `relaxed`, `detail` — `низкий`,
`средний`, `высокий`. Рост и все ориентиры — в миллиметрах, фигура стоит на `z = 0`.

### Свет, текстуры и анимация

```
scene bg=#10151c env=studio exposure=1.05 shadows=да
light preset=портрет strength=1.1
texture кружка kind=мрамор scale=1.3
animate kind=spin axis=z seconds=10 loop=да
animate kind=assembly start=10 hold=0.8
```

Пресеты света: `студия`, `солнце`, `ночь`, `мягкий`, `контражур`, `портрет`.
Текстуры: `дерево`, `мрамор`, `металл`, `ткань`, `кожа`, `клетка`, `шум`,
`кирпич`, `керамика`. Развёртка (`uv`) — `cylinder`, `planar` или `box`.

Анимации (`animate`, можно несколько строк подряд):

| вид | что делает | параметры |
|---|---|---|
| `spin` | вращение модели или объекта | `axis=x\|y\|z`, `turns`, `seconds` |
| `turn` | доворот на угол вокруг `pivot` | `angle`, `axis`, `pivot=[x,y,z]` |
| `roll` | качение: угол = путь / радиус | `distance`, `radius`, `axis` |
| `move` | перемещение на `dx/dy/dz` | `delta` или `dx`, `dy`, `dz` |
| `scale` | масштаб объекта | `from`, `to` |
| `jump` | прыжок с упругим сжатием | `height`, `elastic=да\|нет` |
| `fall` | падение на пол | `height`, `elastic=да\|нет` |
| `fan` | раскрутка вентилятора | `rpm`, `axis` |
| `formation` | рост/формирование из нуля | `seconds`, `start`, `loop` |
| `explode` | разлёт на части | `amount`, `seconds`, `start` |
| `assembly` | сборка по шагам сценария | `hold` (секунд на шаг), `start`, `loop` |

`loop=нет` (или переключатель «повтор: стоп» в плеере) останавливает анимацию
на последнем кадре — удобно для сборки и «доворота» двери.

`scene=имя` кладёт клип в заготовленную сцену: в плеере их можно переключать,
не меняя сценарий; `scene=все` — общий клип для любой сцены.
`start=` задаёт начало клипа в секундах; без него клип идёт сразу за предыдущим.
`fps=` — сколько кадров в секунду показывает покадровый просмотр (по умолчанию 24).
Анимация клипов встраивается в GLB (Blender видит отдельные действия);
анимация сборки живёт в окне: её кадры — настоящие промежуточные модели.

### Открытие и обмен с Blender

* `import скульптура file=модель.glb unit=auto` — открыть чужой файл объектом сцены.
* Поддерживаются GLB, GLTF, OBJ, STL, PLY, 3MF, DAE. Файл можно перетащить в окно.
* `.blend` открывается и сохраняется, если на компьютере установлен Blender
  (приложение находит его само и конвертирует через командную строку).
* Экспорт: GLB (материалы + анимация), BLEND, OBJ, STL, PLY, PNG, ZIP.
  GLB открывается в Blender, Maya, 3ds Max, Unity, Unreal, Godot — без конвертеров.

Где хранятся файлы: рядом с `Forma3D.exe` — `projects/` (сценарии `.forma`),
`exports/` (GLB, STL, OBJ, PLY, 3MF, BLEND), `renders/` (PNG четырёх видов),
`prompts/` (запросы для нейросети), `textures/` (свои процедурные текстуры),
`imports/` (открытые чужие файлы). Готовые файлы дополнительно копируются
в «Загрузки».

Полный справочник с параметрами и примерами — кнопка «Справка» в приложении,
либо `python -m forma reference`.

### Правила проверок `check`

```
check имя watertight        # оболочка замкнута
check имя parts 1           # одно связное тело
check имя genus 1           # одно сквозное отверстие (ручка)
check имя height 90..110    # высота
check имя size 80..100 80..100 90..110   # X, Y, Z
check имя volume 300..500   # объём, см³
check имя mass 200..400     # масса, г (по плотности материала)

check имя overhang ..20     # доля нависаний, %
check имя symmetric y 1     # допуск симметрии, %
check имя gap другой 0.5..2 # зазор между объектами
check имя inside другой     # целиком внутри
check имя tris ..200000     # число треугольников
```

## Отчёт

После построения приложение возвращает:

* габариты, объём материала, массу, площадь поверхности;
* число частей и сквозных отверстий (род);
* медиану и разброс толщины стенок;
* долю плоского дна и нависаний, оценку симметрии по осям;
* результаты всех проверок ✓/✗ с фактическими значениями;
* замечания (тонкие стенки, отдельные части, модель ниже пола, перегруз сетки);
* сравнение с предыдущей версией (объём, масса, габариты).

Плюс PNG четырёх видов (изометрия, спереди, справа, сверху) — их можно
посмотреть глазами, не полагаясь только на числа.

## Работа с нейросетью

Вкладка «Помощник» собирает запрос: текущий сценарий + отчёт + справочник
команд + правила ответа (сначала словами, что не так, затем полный новый
сценарий и новые проверки). Это замыкает цикл:

```
описание словами → сценарий → построение → отчёт и снимки → правка → …
```

## Куда развиваемся

Форма, материалы, свет, анимация и обмен файлами работают. Дальше:

1. **Трассировка и мягкий свет** — глубина резкости, HDRI-окружение, тени
   от нескольких источников (сейчас — PBR в окне и растровый рендер отчёта).
2. **Кинематика** — связи «шестерня—шестерня», «колесо—рейка», «ползун—шарнир»
   с автоматическим расчётом передаточного числа; сейчас скорости задаются
   длительностью клипов вручную.
3. **Сборка из библиотеки** — сохранение готовых узлов (ящик, петля, часы)
   в личную библиотеку и вставка одной строкой.
4. **Анатомия** — больше ориентиров (лопатки, ключицы, фасции), мимика,
   скелет и позы из команд.

## Разработка

```bash
cd forma
python -m unittest discover -s tests -v   # 261 тест ядра
python -m forma selftest                  # мини-сценарии с проверками
```

Тесты покрывают примитивы, булевы операции, вращение с толщиной стенки,
лофт, массивы, деформации, SDF, все виды проверок, ошибки и подсказки,
экспорт GLB/STL/OBJ, а также сборку всех примеров с прохождением проверок.
