# ml — маленькая своя нейросеть, которая «понимает» примитивы

Это не библиотека глубокого обучения и не конкурент PyTorch. Это шесть файлов,
которые показывают главное: **нейросеть — это числа в файле плюс код, который
их умножает**. Всё остальное (форматы, размеры, бюджет обучения) — следствие.

```
forma/ml/
  synth.py       генератор данных: случайные сцены → DSL-текст + метрики из build()
  tokenizer.py   словарь языка DSL и превращение текста в числа (и обратно)
  mlp.py         сеть на numpy: прямой проход, обратный, Adam, сохранение в safetensors
  train.py       признаки, обучение головы «DSL → метрики», MAE/R², инференс по тексту
  rule.py        то же без сети: разбор строки и школьная формула — для сравнения
  demo.py        сквозной прогон: данные → обучение → файл весов → инференс → байты
```

## Как это запускать

```bash
cd forma
python -m venv /tmp/fv && /tmp/fv/bin/pip install numpy manifold3d
PYTHONPATH=. /tmp/fv/bin/python ml/demo.py                  # 400 сцен, ~30 с
PYTHONPATH=. /tmp/fv/bin/python ml/demo.py --scenes 800 --epochs 400
PYTHONPATH=. /tmp/fv/bin/python ml/demo.py --scenes 2000 --epochs 800   # дольше, точнее
```

Прогон с `--scenes 800 --epochs 400` на 2 ядрах: данные 36 с, обучение 6 с.

## Что получается на выходе

| Файл | Что внутри | Размер |
|---|---|---|
| `ml/data/scenes.jsonl` | по строке на сцену: DSL-текст и 7 чисел-ответов | 83 КБ на 800 сцен |
| `ml/weights/vocab.json` | словарь языка: 43 токена | 0,5 КБ |
| `ml/weights/head.safetensors` | только веса, 144 135 float32 | 563 КБ |
| `ml/weights/head.json` | конфигурация: размеры слоёв, нормировки, версия | 0,7 КБ |
| `ml/weights/report.json` | отчёт: ошибки по целям, R², время, размеры | ~1 КБ |

Все пять файлов лежат в репозитории — сеть можно взять и запустить, не обучая.

## Чему она учится и что из этого вышло

Голова «сценарий → 7 метрик»: `log10` объёма, род, число деталей,
`log10` треугольников, габариты X/Y/Z. На 160 сценах, которых сеть не видела:

| Величина | Сеть | Правило (`rule.py`) |
|---|---|---|
| log объёма | 0,27 | **0,00** |
| род (отверстия) | **0,32** | 0,84 |
| частей | 0,30 | **0,19** |
| log треугольников | **0,31** | 2,69 |
| габарит X | 14,22 | **3,13** |
| габарит Y | 14,38 | **3,05** |
| габарит Z | 7,58 | **0,19** |

Вывод, ради которого всё и сделано: где есть формула — сеть не нужна
(объём и габариты правило считает точно). Сеть нужна там, где формулы нет:
по картинке понять форму, придумать сцену, выбрать приём.

## Чего здесь нет и почему

* нет свёрток и внимания — для демонстрации механики хватает MLP на мешке
  токенов с хешем пар; свёрточная сеть для масок описана бюджетом в
  `docs/neural_network_explained.md`, §5;
* нет обучения на картинках — маска → форма требует свёрточной сети;
* нет PyTorch — специально: чтобы было видно, что «нейросеть» это не магия,
  а умножение матриц, которое можно написать за 200 строк.

Подробный разбор «где живёт сеть, что внутри .safetensors, почему не exe»
и честная граница применимости — в `docs/neural_network_explained.md`.
