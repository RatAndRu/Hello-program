# OpenSCAD: пример и сравнение с ФОРМОЙ

Здесь лежит всё, что нужно, чтобы **не устанавливать OpenSCAD на свой
компьютер**: модели собираются на раннере GitHub Actions, а результат
(снимки, STL и отчёт с числами) раннер сам коммитит в `result/`.

| Файл | Что это |
|---|---|
| `bracket.scad` | кронштейн: модули, `for`, скругление углов через `offset` |
| `vase.scad` | ваза: двумерный профиль + `rotate_extrude` |
| `compare.py` | строит ту же деталь на DSL ФОРМЫ и печатает сравнение |
| `result/` | то, что вернул CI: `bracket.stl`, снимки PNG, `summary.md` |
| `.github/workflows/openscad-probe.yml` | сам прогон: установка, рендер, метрики, коммит |

## Как запустить

1. Открыть вкладку **Actions** → «Проверка OpenSCAD на раннере GitHub».
2. Нажать **Run workflow** (или просто изменить любой файл в этой папке —
   прогон стартует сам при push).
3. Через 2–3 минуты в `result/` появятся снимки и `summary.md`.
4. Готовый STL можно скачать и открыть в любом слайсере или в самой ФОРМЕ.

Локально (если OpenSCAD всё-таки установлен):

```bash
cd forma/docs/openscad
openscad -o bracket.stl bracket.scad
openscad -o vase.stl vase.scad
PYTHONPATH=../.. python3 compare.py bracket.stl
```

## Что показывает сравнение

OpenSCAD **рисует** и **экспортирует**, но не сообщает ничего о результате:
ни объёма, ни массы, ни толщины стенок, ни числа частей. Чтобы узнать объём,
модель надо отрендерить в STL и посчитать сторонней программой (`trimesh`).
ФОРМА считает это сама — за 20 мс и вместе с проверками.

Это и есть главный вывод прогона: языки похожи (текст, примитивы, CSG), а
вот «обратная связь» у них разная. OpenSCAD отвечает «вот файл», ФОРМА
отвечает «вот файл, 27,4 см³, 34 г, замкнуто, два отверстия, не пересекается».
