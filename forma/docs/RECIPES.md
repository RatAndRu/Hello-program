## 0.1 Мышь, «Загрузки» и свои текстуры (новое в 0.6)

**Мышь в окне модели**

* левая кнопка — вращать, колесо — приблизить, **правая кнопка — двигать сцену**;
* двойной клик — вернуть общий вид;
* режим «выбор»: **левая кнопка тянет рамку**, средняя вращает, правая двигает;
  Shift добавляет область к уже выбранным, Ctrl+клик по области — убрать её.

**Куда сохраняются файлы.**
Кнопки экспорта и «сохранить» пишут готовые файлы в папку **«Загрузки»**
(Windows: `C:\Users\<имя>\Downloads`). Адрес показан во всплывающем сообщении.
Внутренние копии для окна лежат в `%APPDATA%\Forma3D\exports`.

**Своя текстура** — узор и два цвета прямо в сценарии:

```
texture кружка kind=своя pattern=полосы color1=#c0504d color2=#f2e6d9 scale=1.2
texture ваза kind=своя pattern=камень color1=#6b7f8c color2=#e9e2d4 scale=2
texture кузов kind=своя pattern=волны color1=#1f6f8b color2=#d7e6ea
```

Узоры: `полосы`, `клетка`, `волны`, `градиент`, `шум`, `камень`, `точки`, `сетка`.
В панели материала выберите «своя…» и нажмите «Создать свою текстуру» —
та же строка появится в сценарии.

**Новые проверки и инструменты**

```
# готовые детали для примеров ниже
корпус = cylinder radius=34 height=95 r2=40
полость = cylinder radius=30 height=89 r2=36
полость = translate [полость] offset=[0,0,6]

сфера = sphere radius=30 segments=48

check кружка wall_min 3..5          # самая тонкая стенка + её координата
check шестерня sharp_edge 95        # самое острое ребро, в градусах
check сфера tri_quality 1           # доля «игольчатых» треугольников, %

# сварить вершины и убрать мусор у готовой детали

```

Из консоли: `forma diff старый.forma новый.forma`, `forma doctor`,
`forma build модель.forma --strict` (код 3, если проверка не выполнена),
`--json`, `--digest`, `--trace журнал.jsonl`. Экспорт: `--format 3mf`.

## 0.4 Кромки: скругление и фаска (новое в 0.7)

**Скруглить наружные рёбра (радиус 3 мм, габарит не меняется):**

```
плита = box size=[150,75,10]
плита = fillet [плита] radius=3 edges=convex
check плита size 149.7..150.3 74.7..75.3 9.7..10.3
```

**Скруглить внутренний стык** (например, дно полости или угол буквы «Г»):

```
а = box size=[90,30,30] at=[-30,0,0]
б = box size=[30,30,80] at=[15,0,0]
угол = union [а, б]
угол = fillet [угол] radius=6 edges=concave
```

**Скруглить всё сразу** (сначала вогнутые, потом выпуклые — так считает быстрее):

```
корпус = box size=[120,60,20]
корпус = fillet [корпус] radius=5 edges=all
```

**Плоская фаска 45°** (ширина 2 мм, снимает кромку без радиуса):

```
плита = box size=[150,75,10]
плита = chamfer [плита] width=2 edges=convex
```

Параметры: `radius` / `width` — в миллиметрах, `edges` — `convex`, `concave`
или `all`, `segments` у `fillet` — качество (12 по умолчанию: без тонких
треугольников; 24–40 — глаже, но появляются вытянутые треугольники).
Если объект тяжелее 12 000 треугольников, сначала `simplify [объект] tolerance=0.2`.

**Математическая поверхность** (поле считается массивами, поэтому быстро):

```
капля = from_sdf expression="smin(sd_sphere(x,y,z-40,30), sd_sphere(x,y,z-95,20), 12)" bounds=[-40,-40,-5,40,40,120] resolution=1.5
```

## 8. Лофт: плавный переход между контурами

```
# sections — контуры [[x,y], …], positions — где каждый контур стоит по оси X
корпус = loft sections=[[[-60,-40],[-70,20],[-40,60],[40,60],[70,20],[60,-40]],[[-40,-30],[-50,15],[-25,45],[25,45],[50,15],[40,-30]]] positions=[-160,160] axis=x smooth=3
check корпус watertight
check корпус size 310..330 130..150 110..130
```

Контуров может быть сколько угодно: `loft` соединяет их по порядку, `positions`
задаёт места по оси, `smooth` — плавность перехода, `profile_smooth` — сглаживание
самих контуров. Тот же приём, но на четырёх контурах и с арками, собран в примере
«Кузов машины»: там лофт — только первая строка, остальное — вычитание арок,
пересечение с зонами стёкол и `scale` на 0,3 % для зазора.

> Целиком — пример «Кузов машины»: 72 000 треугольников, 4 колеса, стёкла, швы дверей.

```

```

Красить можно и кистью в окне: выделите деталь, нажмите «Кисть» и ведите
мышью с зажатой кнопкой — за один мазок красится целая область, а не один
полигон. При отпускании в сценарий дописывается одна команда `paint`.

```
check кружка watertight              # покраска не ломает тело
screw d=5 length=9 head=полукруг     # три вида головки: потай, полукруг, шестигранник
```

Проверки сборки (0.18): `check деталь gap другая_деталь 0` — детали должны
касаться, а не висеть; `check деталь parts 1` — тело не распалось на куски.

## 13. Сопряжения: деталь на место отношением

Сопряжение — это ограничение сборки, как mates в SolidWorks/Fusion. Геометрия
детали не меняется: программа только переносит её (или поворачивает) так, чтобы
выполнилось условие, и запоминает связь.

```
# плоскость к плоскости: низ детали встаёт на верх основания (+ отступ)
плитка = box size=[60, 60, 10] at=[0, 0, 200]
сопряжение плитка основание type=плоскость axis=z offset=0

# ось: деталь центруется по другой в двух поперечных осях
шайба = cylinder radius=20 height=4 at=[300, 90, 200]
сопряжение шайба втулка type=ось axis=z

# паз-рейка: центруется по рейке и садится на её верхнюю грань
каретка = box size=[90, 70, 40] at=[250, 0, 300]
сопряжение каретка рейка type=паз axis=y

# зазор: ровно 3 мм между деталями (по кратчайшему расстоянию)
сопряжение шайба плита type=зазор offset=3

# точка: точка детали попадает в заданное место
шильдик = box size=[84, 3, 30] at=[0, 0, 600]
сопряжение шильдик основание type=точка point=[0, 0, 600] to=[-80, -78, 14]

# петля: поворот вокруг оси через точку (дверная петля)
сопряжение дверь корпус type=петля axis=z point=[-70, 80, 100] angle=-28
```

Что запоминается и проверяется:

```
check рейка связь          # остаток 0 мм — связь держится
check дверь связь 5        # для петли допуск можно задать: 5 мм
```

Остаток (residual) — на сколько деталь ушла от условия. После `translate`,
`rotate` или правки размеров `check … связь` пересчитывает его заново и
краснеет, если связь разъехалась.

Где смотреть в окне: вкладка **«Связи»** — мастер зазоров. Он считает точные
расстояния между телами и показывает сборки, висящие детали и щели; кнопка
«связать» дописывает `сопряжение` в сценарий.

> После построения сместите одну деталь и повторите `check … связь`:
> отчёт обязан показать нарушенное отношение.

## 14. Приёмы 0.21: настройки, принцип отбора и что осталось за кадром

**Что изменилось в «Инструментах»**

* у каждого приёма появились **поля**, как у фигур: меняете число — предпросмотр
  сценария под карточкой пересчитывается сразу, вставляется уже готовый текст;
* **«Сечение, проба и паспорт» разведены на три карточки.** Это три разных
  вопроса к детали (`section` — контур разреза, `probe` — есть ли материал в
  точке, `passport` — габарит, объём, масса, герметичность), и одна карточка
  на три команды только путала;
* **«Отверстия сеткой»** получили поле **сдвиг**: сетка смещается по детали
  (`holes … offset=[12,-8]`), а не только стоит по центру;
* **«Накатка»** получила число канавок и глубину (было жёстко `count=24 depth=1`);
* **«Резьба: болт» убрана.** Это был однострочник, дублирующий команду
  `thread`; карточка самой команды с параметрами есть в разделе «Все команды»;
* добавлены приёмы, которых не хватало: **«Корпус с полостью»** (`shell`),
  **«Зеркальная пара»** (`mirror_copy`), **«Сечение»**, **«Проба материала»**,
  **«Паспорт детали»**, **«Надпись»**.

**Принцип отбора: почему приёмов 17, а команд 111**

1. **Приём — это сценарий, а не команда.** Он решает задачу целиком: делает
   заготовку, обрабатывает её и красит. Если для задачи хватает одной команды,
   приём не нужен — за это отвечает карточка команды в «Все команды».
2. **У приёма должны быть осмысленные поля.** Если параметр нечего менять
   (или он всегда один и тот же), это не приём, а демонстрация.
3. **Приём обязан собираться.** Все 17 проверены сборкой со значениями по
   умолчанию и с изменёнными полями (сдвиг сетки, снятая ручка кружки,
   другая плоскость зеркала, открытый низ корпуса).
4. **Дубли не держим.** Однострочники-дубли команд (`thread`, «Резьба: болт»)
   из приёмов убраны.
5. **Остальные 94 команды не потеряны**: они все в разделе «Все команды» —
   с описанием, параметрами и примером, который вставляется одной кнопкой.

**17 приёмов и их поля**

| Приём | Поля | Что делает |
|---|---|---|
| Кружка | ⌀, высота, стенка, ручка (да/нет) | корпус, полость, ручка, повторное вычитание полости |
| Накатка | ⌀, высота, канавок, глубина | цилиндр + `knurl` |
| Скрутка | ширина, высота, угол | брусок + `twist` |
| Изгиб | ширина, длина, размах, угол | брусок + `bend` |
| Надпись | текст, высота, толщина | `text` + цвет |
| Резьба: гайка | ⌀, высота, шаг | `thread internal=true` |
| Фаска | размер, фаска, режим | брусок + `bevel` (авто/скругление/фаска) |
| Облегчение | размер, допуск | брусок + `simplify` |
| Уклон | размер, угол | брусок + `draft` |
| Отверстия сеткой | размер, сетка, ⌀, шаг, **сдвиг** | панель + `holes` |
| Разброс деталей | штук, площадь, масштаб, seed | `rock` + `scatter` |
| Выпуклая оболочка | радиус, высота, верх | призма + сфера + `hull` |
| Корпус с полостью | размер, стенка, что открыто | брусок + `shell` |
| Зеркальная пара | размер, плоскость, зазор | половинка + `mirror_copy` |
| Сечение | высота Z | деталь + `section` |
| Проба материала | X, Y, Z | деталь + `probe` |
| Паспорт детали | — | деталь + `passport` |

**Что не стало приёмами и почему**

* сопряжения (`сопряжение`) и массивы (`array`) — это приёмы *сборки*: им нужен
  уже готовый объект в сцене, поэтому они живут в справочнике и в мастере
  зазоров;
* анимация (`кадр`, `движение`, `заготовка`) — это касается сцены, а не детали;
* проверки (`check`) и служебные команды (`clean`, `import`, `export`) —
  не «приёмы», а инструменты.

**Что стоит добавить дальше**

* «Рёбра жёсткости» — пластина + массив рёбер + объединение;
* «Крепёж по месту» — отверстия + саморезы с крестом из одной карточки;
* «Массив по кругу» — `array mode=radial` с полем «сколько»;
* «Петля» — ось + зазор + `check связь` (когда сопряжения выйдут в панель).

## 15. Наполнение, горка, капля и массив по кругу (0.22)

### 15.1. Крупа в тарелке: `fill`

```forma
тарелка = plate diameter=180 depth=55 wall=4
каша = fill [тарелка] grain=зерно size=8 level=0.8 density=0.75 seed=7
color каша #b98a4a
```

Как это работает:

1. по габариту посуды строится сетка XY с шагом `size · (0.82 + 0.3 · (1 − density))`;
2. в каждой колонке пускается луч сверху вниз — первое попадание с нормалью
   вверх считается дном полости;
3. восемь боковых лучей проверяют, что колонка внутри, а не снаружи (иначе
   зерно повисло бы над ручкой кружки); зазор до стенки — `inset`;
4. колонка заполняется снизу вверх: каждое зерно садится **дном** на пол или на
   предыдущий слой, с джиттером, случайным поворотом (`rotate`) и разбросом
   размера; предел — уровень `level · (высота борта − дно)`;
5. всё объединяется одним `batch_boolean(OpType.Add)`.

| параметр | смысл | по умолчанию |
|---|---|---|
| `grain` | шар, горох, зерно, капля, куб, галька | капля |
| `size` | характерный размер зерна, мм | 6 |
| `level` | 0.5 — половина, 1 — по край борта | 0.8 |
| `density` | плотность укладки 0…1 | 0.7 |
| `seed` | повтор раскладки | 1 |
| `rotate` | доля случайного поворота | 0.6 |
| `inset` | зазор до стенки, мм | 0.4 |
| `count` | предел числа зёрен (≤ 1600) | по месту |
| `dome` | горб к центру 0…1: 0 — ровно, 1 — с горкой | 0 |
| `as` | `одно` тело или `отдельные` объекты (≤ 150) | одно |

Одинаковый `seed` даёт ту же раскладку до треугольника — это и есть проверяемость.
Если зёрен выходит больше предела, ядро **укрупняет** их и пишет об этом в лог,
а не молча обрезает: каша остаётся кашей. Закрытый шар или купол наполнить
нельзя — команда честно скажет, что полости, открытой вверх, нет.

### 15.2. Горка: `pile`

```forma
горка = pile radius=105 height=46 grain=галька size=15 seed=5
```

Профиль — округлый конус `h · (1 − (r/R)^1.7)`. Зёрна укладываются колонками
от пола до поверхности; верхние слои ложатся по нормали склона.

Горка из **готовых предметов** — дайте объект позиционным аргументом:

```forma
конфета = drop radius=9 height=26 tip=0.6
куча = pile [конфета] radius=90 height=42 size=18 count=40 seed=4
```

Предмет приводится к единичному габариту, копии ставятся на склон с наклоном по
нормали и случайным поворотом. Исходник после сборки гасится (как после
`union`), но остаётся в сцене.

Подложка — необязательный круглый диск под насыпью: `base=8` добавит плиту
толщиной 8 мм, и горка уже не «висит» на нулевой плоскости.

### 15.3. Яйцо: новый профиль

```forma
яйцо = egg height=60 diameter=42 proportion=0.55
перепелиное = egg height=32 diameter=26 proportion=0.6 sharp=низ
```

Профиль собран из двух кусков: низ — четверть эллипса (круглое дно, без шипа
в полюсе), верх — кубическая кривая Безье от экватора к острому концу, с
вертикальной касательной на стыке. Самая широкая точка — на 45 % высоты
(у куриного яйца 42–45 %), `H/⌀ = 1.43`. `proportion`: 0 — симметричный овоид,
0.55 — куриное яйцо, 1 — сильно вытянутое. `sharp=верх|низ` переворачивает.

### 15.4. Капля: `drop`

```forma
капля = drop radius=14 height=40 tip=0.5
стекло = drop radius=9 height=52 tip=0.85
```

Полушарие снизу, хвост Безье сверху: вертикальная касательная на экваторе
(гладкий стык) и точка на конце. `tip=0` — почти сфера, `tip=1` — длинная
острая капля. Высота должна быть хотя бы 1.15 радиуса.

### 15.5. Массив по кругу: `array mode=radial`

```forma
стойка = cylinder radius=6 height=60
кольцо = array [стойка] count=8 mode=radial radius=60
веер   = array [стойка] count=5 mode=radial radius=80 angle=180 spin=да
```

* `radius` — окружность, по которой встают копии (по умолчанию вокруг центра
  самого предмета);
* `angle` — 360 (полный круг) или сектор; для сектора копии распределяются
  вместе с концами;
* `spin=да` — каждая копия поворачивается вокруг своей оси (деталь смотрит
  наружу), `spin=нет` — копии переносятся без поворота;
* `radius=0` — прежнее поведение: копии вращаются вокруг оси, оставаясь на месте;
* `center` — центр вращения, `at` — сдвиг готового массива.

### 15.6. Атлас по материалу

Команда `texture` сама выбирает развёртку, если `uv` не указан:

| материал / рисунок | развёртка | почему |
|---|---|---|
| металл, ткань, кожа, клетка, шум | `атлас` | рисунок мелкий, швы не видны, зато нет растяжений |
| «своя» текстура с точками, сеткой, клеткой, шумом | `атлас` | то же |
| дерево, мрамор, кирпич, керамика, камень, полосы, волны, градиент | `auto` | крупный узор должен оставаться целым |

Явный `uv=атлас` или `uv=auto` в команде всегда перебивает выбор по материалу.
Причина выбора пишется в лог сборки.

## 16. Сварка объёмов, свечение и новые фигуры (0.23)

### 16.1. `fuse` — одно тело вместо набора примитивов

`union` просто склеивает детали: на стыке остаётся резкое ребро, и модель
читается как «кубик, к которому приставили цилиндр». `fuse` сваривает и
скругляет **вогнутые** рёбра радиусом `radius`.

```
стойка = box size=[200,62,34] round=8 at=[0,0,0]
блок   = box size=[210,52,96] round=12 at=[0,0,20]
скос   = box size=[188,20,26] round=6 at=[0,-14,8]
корпус = fuse [стойка, блок, скос] radius=9 edges=все
```

* `radius` — ширина видимого перехода. Правило: **10–20 %** от меньшей
  стороны детали. Для стыка «шея–голова» 8–15 мм, для ручки кружки 3–5 мм.
* `edges=вогнутые` (по умолчанию) — трогает только стыки, внешние рёбра
  остаются острыми (так делают корпус прибора).
* `edges=все` — скругляет и наружные рёбра: получается «литая» мягкая форма.
* `angle` — порог, ниже которого ребро считается плоским (34°); увеличивайте,
  если между деталями остался barely-заметный шов.
* `detail` — шаг сетки (авто ≈ radius/4). Меньше = глаже и дороже.

Чего `fuse` не делает: не меняет топологию и не сливает детали, которые
**не пересекаются** (сначала `union`, потом `fuse`), и не заменяет `fillet`
на одной детали. Детали должны реально входить друг в друга на радиус.

### 16.2. Свечение

```
color цифры #2bff72 emissive=#2bff72 emissive_strength=4.5
color лампа material=lamp
```

| preset | что это |
|---|---|
| `led` | зелёный светодиод, яркость 4 |
| `neon` | розовый неон, яркость 6 |
| `lamp` | тёплая лампа, яркость 5 |
| `screen` | тёмное полупрозрачное стекло экрана |

В окне bloom включается автоматически, если в модели есть эмиссия.
В GLB уходит `KHR_materials_emissive_strength` — Blender видит яркость.

### 16.3. Стекло

```
стекло = box size=[186,1.4,76] round=0.7 at=[0,-27,28]
color стекло #7fd6e8 transmission=0.72 rough=0.04 metal=0
```

В GLB — `KHR_materials_transmission` + `KHR_materials_ior` (1.45).
В PNG-снимках прозрачные тела рисуются последними со смешиванием, поэтому
сквозь стекло видны цифры. В окне — `MeshPhysicalMaterial` с `thickness`.
Если нужен простой эффект «дымчатого» стекла без преломления — ставьте
`transmission=0.2…0.35`.

### 16.4. Светодиодные цифры

```
цифры = seven_seg text="21:38" height=54 width=26 thick=8.2 gap=11 depth=2.2
цифры = rotate [цифры] angle=90 axis=x
цифры = place [цифры] at=[0,-25.4,66] align=center
color цифры #2bff72 emissive=#2bff72 emissive_strength=4.5
```

`seven_seg` строит **плоскую** панель в XY (толщина по Z), поэтому для
вертикального экрана её надо повернуть на 90° вокруг X. Понимает `0-9`,
`A-F`, `:`, `.`, `-`, пробел.

### 16.5. Сердце, плюс, сектор, спираль, верёвка

```
сердце = heart width=60 depth=18 round=3
плюс   = plus arm=60 thick=18 depth=14 round=2
долька = sector radius=50 angle=90              # четвертинка шара
купол  = sector radius=80 angle=180 thickness=6 # полусфера-стенка
завиток = spiral radius=60 turns=3 wire=6 height=6
канат  = rope length=300 diameter=24 strands=3 twist=60
```

* `heart` — настоящая кривая сердца (16sin³t …), не два круга. `height`
  переопределяет высоту, `round` скругляет кромки.
* `plus` — два бруса в одно тело, `round` скругляет внутренние углы.
* `sector` — `angle` любой от 1 до 360, `start` — откуда отсчёт, `up` — какая
  половина шара, `thickness` — стенка.
* `spiral` — архимедова спираль; если витки налезают друг на друга, команда
  честно скажет, какой шаг и какая нить.
* `rope` — каждая нить это настоящая винтовая линия с круглым сечением;
  толщина нити подбирается автоматически так, чтобы нити касались, а наружный
  диаметр совпадал с `diameter`. Торцы подрезаны ровно.

### 16.6. Часы целиком

Готовый пример — `examples/clock_led.forma`: сварной корпус, ниша, экран,
стекло, LED-цифры, индикатор. 6 проверок, все проходят. Собирается за 0.7 с.

### 16.7. Примитив или ручная сборка: что выгоднее

Примитив — это **не другая геометрия**, а тот же `manifold3d`, собранный тем же
ядром: экструзия контура, `revolve`, `sweep`, булевы операции. Разница только
в том, кто пишет координаты — вы или проверенная функция. Замеры (лист
`docs/primitive_vs_script_023.png`, скрипт `docs/make_primitive_vs_script.py`):

| фигура | вызов примитива | добросовестная ручная сборка |
|---|---|---|
| сердце 72×65×20 | `heart width=72 depth=20 round=3` — 1 стр., 40 симв., 1.1 с, **1 тело**, 3 366 трис | 8 стр., 278 симв., 2 шара + призма + `fuse`, 99 590 трис, силуэт совпал на **87 %** |
| верёвка ⌀26×150 | `rope length=150 diameter=26 strands=3` — 1 стр., 45 симв., 0.07 с, **1 тело, род 1** | 3 `sweep` по 150 точек — 8 683 симв., **3 отдельных тела**, концы не сведены |
| индикатор «21:38» | `seven_seg text="21:38" height=54` — 1 стр., 48 симв., 754 трис, концы штрихов скруглены | 21 стр., 943 симв., 380 трис коробок с острыми углами, силуэт совпал на **88 %** |

Вывод: примитив выигрывает **всегда, когда форма уже есть в наборе** — он
короче в 5–200 раз, даёт одну проверенную топологию и одинаковый результат у
всех. Ручная сборка нужна, когда формы в наборе нет или когда деталь — часть
сцены с собственными размерами (тогда берите простые примитивы и `fuse`).

Слитность даёт **не примитив, а `union`/`fuse`**: `seven_seg` честно отдаёт
каждый знак отдельным телом, потому что цифры в приборе и должны быть
отдельными. Если нужен один объём — сваривайте.

## 17. Знаки и фигуры (0.24)

Семь новых примитивов категории «Примитивы». У всех плоские фигуры лежат
в плоскости XY (толщина по Z), стоят центром на полу, а `stand=да`
разворачивает их вертикально, как табличку.

```
стрелка = arrow length=120 width=26 head=42 head_width=68 depth=12 round=2
тавр    = tee arm=90 bar=20 stem=22 leg=60 depth=14 round=2
луна    = crescent radius=50 thickness=18 depth=12 round=1.5
куча    = swirl radius=42 height=70 coils=3
молния  = lightning height=90 width=44 depth=10 round=1.5
банан   = banana length=120 bend=110 thick=28 flat=0.75
рогатка = yoke height=110 spread=64 arm=16 fork=0.38 depth=14 round=2
```

| команда | что это | главные параметры |
|---|---|---|
| `arrow` | указатель остриём вправо, без перьев | `length`, `width`, `head`, `head_width=width` — узкий наконечник, `tail` — V-вырез |
| `tee` | буква Т, тавр | `arm` (ширина), `bar` (толщина перекладины), `stem`, `leg` |
| `crescent` | полумесяц | `radius`, `thickness`, `bite` — радиус выкуса в долях радиуса |
| `swirl` | непрерывная спиральная труба | `radius`, `height`, `coils`, `wire`, `taper` |
| `lightning` | молния | `height`, `width`, `depth` |
| `banana` | банан / бровь / стручок | `length` (по дуге), `bend`°, `thick`, `flat`, `taper` |
| `yoke` | буква Y, рогатка | `height`, `spread` (между концами), `arm`, `fork` |

### 17.1. Почему габарит совпадает с параметром

Скругление кромок (`round`) сжимает контур на радиус — острия при этом
срезаются, и деталь стала бы меньше заданной. Поэтому после скругления
`_flat()` возвращает точный габарит масштабом. Проверено тестами:
`arrow length=120 head_width=68 round=2` даёт ровно 120 × 68 мм,
`lightning height=90 width=44 round=1.5` — ровно 44 × 90 мм.

### 17.2. Знаки одной сценой

```
стойка = cylinder radius=5 height=118
пятка = cylinder radius=22 height=8 round=2 at=[0,0,-12]
табличка = arrow length=104 width=20 head=34 head_width=54 depth=9 stand=да
табличка = translate [табличка] offset=[26,0,74]
вторая = arrow length=76 width=15 head=26 head_width=40 depth=7 stand=да
вторая = rotate [вторая] angle=180 axis=z
вторая = translate [вторая] offset=[-20,0,44]
```

`stand=да` поворачивает знак на 90° вокруг X, поэтому `depth` становится
толщиной по Y, а высота фигуры — по Z. Это проверено тестом `TestStand`.

### 17.3. Вырезание фигурой (роспись примитивами)

Примитивы — тела, поэтому фигурой можно **резать**: «кубик с кружками на
всех гранях» из вашей идеи — это куб минус сфера радиусом чуть больше
полуребра:

```
куб = box size=[60,60,60] round=3
дырка = sphere radius=34 at=[0,0,30]
куб = вычесть [куб] дырка
```

Сфера больше куба по всем осям, поэтому вырезает по кружку на каждой из
шести граней, а внутри остаётся сфера-полость.

## 18. Поверхность, наращивание, зеркало и покраска

### 18.1. Деформация готового тела

| команда | что делает | главные параметры |
|---|---|---|
| `wrinkle` | волна, мятость, клетка или борозды на теле | `amp`, `freq`, `mode`, `surface`, `seed` |
| `crack` | удар, разлом или древесные ложбинки | `mode`, `count`, `width`, `depth`, `seed` |
| `relief` | карта высот PNG на поверхности | `image`, `depth`, `mode`, `invert` |
| `porous` | сферические ямы, цилиндры и пузыри | `size/width`, `depth`, `count`, `smooth`, `rough` |
| `scales` | наложенная чешуя | `rows`, `per_row`, `length`, `lift`, `overlap` |
| `lattice` | сетка прутьев сквозь тело | `cell`, `wire`, `mode`, `depth` |
| `bark` | ствол с нерегулярной корой | `height`, `radius`, `grooves`, `depth`, `taper` |
| `bricks` | кладка вперевязку | `width`, `height`, `thick`, `brick`, `joint` |
| `repair` | доводка скана до замкнутого тела | `smooth`, `simplify`, `drop` |

```forma
ваза = cylinder radius=40 height=90 segments=64
ваза = wrinkle [ваза] amp=2 freq=14 mode=радиус surface=наружная
ваза = porous [ваза] mode=поры size=3 depth=1.5 count=24 smooth=.3 seed=4
```

`wrinkle` выбирает ребро по длине волны: не меньше десяти–двенадцати отрезков
на волну, с общим бюджетом сетки. `detail=` задаёт ребро вручную. Для рукава
используйте `surface=наружная`, чтобы не деформировать внутреннюю стенку.

`relief` без `image` берёт встроенную `docs/pattern.png`. Свою карту указывайте
путём к PNG; белое — выступ, чёрное — впадина.

### 18.2. Трещины, стёсывание и заострение

```forma
плита = box size=[110,90,16]
плита = crack [плита] mode=удар count=8 radius=40 width=2 depth=1.2 seed=4

брусок = box size=[80,60,40]
брусок = shave [брусок] depth=8 groove=треугольная groove_width=5 groove_depth=2 groove_offset=4
карандаш = cylinder radius=8 height=100 segments=64
карандаш = point [карандаш] length=24 side=верх
```

У `shave` канавка строится по контуру именно нового плоского среза. Профили
`прямоугольная`, `овальная`, `треугольная` имеют разное дно и разный удалённый
объём. `point` сохраняет высоту вершины и не оставляет отдельных обрезков.

### 18.3. Волосы и мех на существующей поверхности

```forma
основа = box size=[80,60,16] round=4
волосы = hair [основа] style=волоски surface=верх count=60 length=20 thick=1.2 seed=4
ёж = sphere radius=35 segments=48
иголки = hair [ёж] style=иголки surface=вся count=90 length=22 thick=1.8 seed=7
```

`style`: `иголки`, `волоски`, `локоны`, `мех`. Корни заглублены в основу и
сварены с ней. `surface` выбирает сторону, `at+radius` — пятно, `count`,
`length`, `thick`, `spread`, `bend`, `turns` и `seed` управляют формой.

### 18.4. Клинок

```forma
катана = blade length=700 width=32 thick=7 kind=катана curve=24
стилет = blade length=280 width=14 thick=5 kind=стилет
серп = blade length=300 width=46 kind=серп curve=90
```

Клинок строится лофтом сечений по дуге. `curve` — стрелка прогиба,
`profile`, `section`, `tip` и `edges` реально меняют геометрию. У серпа длина
измеряется вдоль центральной дуги, а не по диагонали габарита.

### 18.5. Зеркало и светящиеся цифры

```forma
зеркало = mirror_plate width=600 height=900 frame=40
цифры = seven_seg text="21:38" height=56 depth=2.2
color цифры #2bff72 emissive=#2bff72 emissive_strength=4.5
```

`mirror_plate` даёт раму с задником и отражающую пластину. Готовая компоновка
корпуса, ниши, стекла и цифр находится в проекте `clock_led`.

### 18.6. Покраска узором — куб с кружками

```forma
куб = box size=[60,60,60]
pattern куб #d94f3d shape=круги size=12 step=24
кубик = box size=[50,50,50]
pattern кубик #2f6fb0 shape=клетка size=10 step=20 angle=45 offset=[5,5]
```

Это покраска, а не вычитание: объём и форма не меняются. Перед покраской сетка
автоматически разбивается под размер узора. `shape`: круги, кольца, полосы,
клетка, треугольники, ромбы, волны; `step ≥ size`; `angle`, `offset` и `side`
задают поворот, сдвиг и область.

### 18.7. Что чем делать

| задача | команда |
|---|---|
| мятая поверхность, кольца, клетка | `wrinkle` |
| удар, разлом, волокна | `crack` |
| логотип или узор рельефом | `relief` |
| пемза, губка, сыр | `porous` |
| плоский срез и канавка | `shave` |
| чешуя, шишка, дракон | `scales` |
| решётка, купол, окно | `lattice` |
| ствол дерева | `bark` |
| стена, камин | `bricks` |
| починить скан | `repair` |
| нож, меч, серп | `blade` |
| иголки, волосы, локоны, мех | `hair` |
| зеркало | `mirror_plate` |
| кружки и клетка цветом | `pattern` |
| кружки и клетка отверстиями | `porous`, `difference` |

## 19. 0.26: аниме и манга — контуры по форме

Стиль — это не текстура и не материал, а **подача кадра**. Он применяется
в окне модели (живой, без пересборки) и на PNG-снимках; в GLB уходит обычная
геометрия, а стиль остаётся в сценарии строкой `anime`.

### 19.1. Четыре пресета

```
ваза = lathe points=[[0,0],[26,0],[40,30],[30,62],[16,90],[0,92]]
шар = sphere radius=30 at=[70,0,30]
anime mode=аниме                # цвет + чёрный контур + ступени тона
```

| стиль | что делает | когда нужен |
|---|---|---|
| `аниме` | цвет, ступени тона, блик, чёрные контуры | кадр «как в аниме» |
| `манга` | бумага, серый тон точками, заливка в тени | чёрно-белая иллюстрация |
| `комикс` | цвет + толстый контур + точки в тенях | обложка, постер |
| `линия` | только контуры на бумаге, без тона | чертёж, Line Art |

```
anime mode=манга line=2.2 paper=#ffffff
anime mode=комикс line=3 crease=40
anime mode=линия line=1.4
```

### 19.2. Что именно попадает в контур

* **силуэт** — граница предмета с фоном;
* **излом** — ребро, фаска, складка: там, где нормали соседних пикселей
  расходятся сильнее, чем `crease` градусов (`crease=32` — обычный аниме-вид,
  `crease=15` — больше линий, `crease=55` — только жёсткие рёбра);
* **перепад глубины** — уступ, стык двух объёмов (`depth`, доля размера сцены);
* **стык деталей** — отдельная линия на границе объектов (`seams`).

Это те же три источника, что у Line Art в Blender (контур, излом, стык), —
поэтому линии идут по форме, а не обводят только абрис.

### 19.3. Настройки

```
anime mode=аниме line=2 color=#0b0b12 crease=26 depth=0.02 seams=да inner=да
anime mode=манга tone=0.8 paper=#fbfbf7 toon=3
anime mode=линия shade=нет
anime off=да
```

* `line` — толщина в пикселях снимка (1–3 обычно достаточно);
* `toon` — число ступеней тона, `0` — без ступеней;
* `tone` — сила растра (манга/комикс), `0` — чистые ступени серого;
* `paper` — цвет бумаги; `paper=сцена` — оставить фон сцены;
* `shade=нет` — не затенять поверхность, оставить чистый контур;
* `inner=нет` — не рисовать внутренние линии, только силуэт.

### 19.4. В окне

Панель «вид → Стиль»: чипы `обычный / аниме / манга / комикс / линия`,
ползунки контура и тона, цвет бумаги. Кнопка **«в сценарий»** вставляет
строку `anime …` — так стиль сохраняется в проекте и попадает на снимки.
Если нужен только быстрый взгляд — сценарий менять не нужно.

### 19.5. Что чем делать: выбор

| задача | способ |
|---|---|
| посмотреть модель «как рисунок» | чипы в окне |
| сохранить стиль в проекте и на снимках | `anime mode=…` + кнопка «в сценарий» |
| только силуэт, без рёбер | `anime inner=нет` |
| больше внутренних линий | `crease=18…24` |
| тонкие аккуратные линии | `line=1.2…1.6` |
| жирный комиксовый контур | `line=2.5…3.5`, `crease=38…45` |
| чистый чёрно-белый рисунок | `mode=манга tone=0.8` |
| обводка чертежа | `mode=линия`, `shade=нет` |

## 20. 0.27: превью, отражения, свечение и вид сцены

### 20.1. Превью в карточках «Инструментов»

В окне «Инструменты» у каждой карточки есть кнопка **«3D»**. Она собирает
модель по текущим полям карточки (с тем же разбором ошибок, что и обычная
сборка) и показывает её в отдельном окне — **в сцену деталь не попадает**.

| кнопка | что делает |
|---|---|
| «Обновить» | пересобрать по текущим значениям полей |
| «Вписать» | вернуть камеру к модели |
| «Каркас» | показать сетку треугольников |
| «Крутить» | автоматическое вращение |
| «Добавить в сценарий» | вставить готовую строку в текст (как раньше) |

Подпись под окном — габарит `Ш×В×Г мм` и число треугольников: сразу видно,
не слишком ли тяжёлая деталь. Esc или щелчок мимо окна — закрыть.

### 20.2. Зеркало, которое отражает соседей

```
зеркало = mirror_plate width=340 height=250 frame=24 at=[0,150,0]
зеркало = rotate [зеркало] angle=90 axis=x pivot=[0,150,125]
шар = sphere radius=42 at=[-50,60,42] color=#e05a3a
куб = box size=[66,66,66] at=[42,40,33] round=4 color=#3aa9e0
```

Пластина зеркала получает `metal=1 rough=0.02`. В окне у неё своя кубическая
карта и она обновляется при движении камеры; на PNG-снимке от каждого
видимого зеркального пикселя пускается луч и в отражении появляются соседние
детали. Промах луча (небо, пустота) остаётся отражением студии.

Важно: `rotate` двигает **всю сборку** — раму, пластину и задник. Составные
команды вроде `mirror_plate` состоят из нескольких деталей; поворот и личные
оси применяются ко всем деталям вместе.

### 20.3. Свечение LED без «просветов»

Откройте проект `clock_led` или соберите цифры отдельно:

```forma
цифры = seven_seg text="21:38" height=54 width=26 thick=8.2 gap=11 depth=2.2
цифры = place [цифры] at=[0,-25.4,66] align=center
color цифры #2bff72 emissive=#2bff72 emissive_strength=4.5
```

* панель и цифры ставятся **у стекла**, а не на дно глубокой ниши;
* ореол строится по маске видимости и не проходит сквозь корпус;
* сила ореола — `scene bloom=…` или ползунок **«Свечение»**;
* яркость самих цифр — `emissive_strength` в сценарии или панели материала.

### 20.4. Вид сцены живёт в сценарии

Всё, что настраивается в панели «вид», записывается строкой `scene …`:

```
scene bg=#0b0e13 env=studio exposure=1.05 shadows=да grid=да ground=да axes=да poly=нет bloom=0.60
```

| параметр | что задаёт |
|---|---|
| `bg` | цвет фона |
| `env` | окружение: студия, солнце, закат, ночь, мягкий, контражур, серый, белый |
| `exposure` | экспозиция |
| `shadows`, `grid`, `ground` | тени, сетка, пол |
| `axes` | оси координат |
| `poly` | полигонаж (каркас) |
| `bloom` | сила свечения светодиодов, 0…3 |

Камера при пересборке больше не сбрасывается в изометрию: вид сохраняется,
пока габарит модели не изменится заметно.

### 20.5. Уборка: две кнопки, а не одна

Под сценарием две кнопки:

* **«очистить сцену»** — убирает все предметы, но оставляет свет, фон и стиль
  (строку `scene`, `light`, `anime`) — удобно начать новую модель в той же
  обстановке;
* **«очистить сценарий»** — стирает текст целиком.

Обе операции отменяются кнопкой ↶ или Ctrl+Z — промах не страшен.

## 21. 0.28: живые превью, корона, инь-ян, линза, патрон и карандаш

### 21.1. Превью прямо в карточке, без кнопки «3D»

Окно «Инструменты» показывает миниатюру **сразу под описанием карточки**:
модель строится на сервере (`POST /api/preview`) и рисуется в общем WebGL-контексте,
а в карточку копируется готовый кадр.

| что делаешь | что происходит |
|---|---|
| меняешь ползунок или галочку | через 0.42 с миниатюра пересобирается сама |
| правишь текстовое поле | то же, но с задержкой 0.42 с (чтобы не дёргать сервер на каждую цифру) |
| тянешь мышью | модель в миниатюре **крутится**; ракурс запоминается и не сбрасывается при пересборке |
| колесо | приблизить / отдалить |
| двойной щелчок | вернуть исходный ракурс |
| галочка «живые превью» | выключить, если компьютер слабый |

Миниатюры строятся только для видимых карточек (IntersectionObserver,
`rootMargin 260px`) — список из 80 карточек не грузит сервер целиком.

### 21.2. Корона: зазубрины отдельно от кольца

```
корона = crown diameter=150 height=48 wall=4 teeth=12 tooth=30 tip=0.35 rim=3
тиара  = crown diameter=120 height=28 wall=3 teeth=9 tooth=45 shape=скруглённые
```

| параметр | что задаёт |
|---|---|
| `diameter` | наружный диаметр кольца |
| `height` | высота обода **без** зубьев |
| `wall` | толщина стенки (кольцо полое) |
| `teeth` | число зубьев по кругу |
| `tooth` | высота зубьев |
| `tip` | скругление вершин: 0 — острые, 1 — круглые |
| `shape` | `треугольные`, `скруглённые`, `волна` |
| `rim` | бортик по низу (выступ наружу), `rim_height` — его высота |
| `detail` | точек на зуб (14 — гладко, 40 — очень гладко) |

Корона — настоящее кольцо: у неё одно сквозное отверстие (род 1), её можно
резать, склеивать с головой или печатать. Зубья — часть того же тела, а не
приставленные детали.

### 21.3. Инь-ян: форма-«запятая», а не рисунок

```
инь = yin_yang diameter=110 thick=14 hole=12
ян  = yin_yang diameter=110 thick=14 side=правый hole=12 color=#2b6cb0
рамка = yin_yang diameter=110 thick=8 wall=4 at=[150,0,0]
```

* `side=левый` (по умолчанию) — половина знака, похожая на цифру шесть;
* `side=правый` — та же половина, повёрнутая на 180°, а не зеркальная копия;
* `round` — скругление кромки, `thick` — толщина; `hole` — отверстие в точке;
* `wall=0` — сплошная фигура, `wall>0` — контурная рамка; отдельного `mode` больше нет.

Начало координат — **центр самого знака**. При `round=0` две половины без
сдвига дополняют друг друга до полного круга и могут быть объединены в одно
тело. Скругление общей S-кромки намеренно создаёт небольшой зазор.

### 21.4. Линза: выпуклая и вогнутая

```
выпуклая = lens diameter=64 sag=14 edge=6 mode=выпуклая
вогнутая = lens diameter=64 sag=14 mode=вогнутая
```

| режим | форма |
|---|---|
| `выпуклая` | двояковыпуклая (увеличительная) |
| `вогнутая` | двояковогнутая (рассеивающая) |
| `плосковыпуклая` | одна сторона плоская, вторая выпуклая |
| `плосковогнутая` | одна сторона плоская, вторая вогнутая |
| `мениск` | обе поверхности в одну сторону, толщина по краю |

`sag` — глубина прогиба, `edge` — толщина по краю. У вогнутых линз край
толще середины, поэтому если `edge` не задан, он считается сам
(`2·sag + 4` для двояковогнутой, `sag + 4` для плосковогнутой): в центре
остаётся 4 мм тела. `rim` — плоская шлифованная кромка. Ось — Z.

### 21.5. Полукапсула

```
деталь = полукапсула diameter=20 length=50 rim=0
с_бортом = полукапсула diameter=20 length=50 rim=2 rim_height=3
```

Плоское основание, цилиндр и одна полусфера. Пистолетного и винтовочного
режимов больше нет; `cartridge` оставлен только как алиас. `rim` и
`rim_height` добавляют прямой бортик у основания. Полная длина всегда равна
`length`, включая полусферу и бортик.

### 21.6. Аниме-подача: штриховка, линии по группам, бумага

Новый режим **`скетч`** и три новых настройки у `anime`:

```
anime mode=скетч hatch=0.9 hatch_angle=50 hatch_step=6 paper_tex=0.65
```

| параметр | что задаёт |
|---|---|
| `hatch` | сила карандашной штриховки, 0…1 (в тени появляется второй слой поперёк) |
| `hatch_angle` | наклон штриха, градусы |
| `hatch_step` | расстояние между штрихами, пиксели (2…40) |
| `paper_tex` | зерно бумаги, 0…1 — мелкий шум и волокна |
| `lines` | где рисовать внутренние линии: `все` (по деталям), `группы`, `материалы` |

`lines=группы` убирает шов между деталями одной сборки (корпус + крышка +
кнопка рисуются как одна форма) и оставляет линию только там, где
встречаются разные сборки. `lines=материалы` рисует линию только на границе
разных материалов — удобно для разукрашенных моделей.

В окне те же настройки живут в панели «вид → Стиль»: чипы
`обычный / аниме / манга / комикс / скетч / линия`, ползунки контура, тона
и штриховки, список «Линии», галочка «зерно». Кнопка «в сценарий» вставляет
строку `anime …` — стиль сохраняется в проекте, на PNG-снимках и в zip.

### 21.7. Стрелки у параметров инструментов (0.28.1)

У каждого параметра карточки есть две маленькие кнопки: **▾** — меньше или
предыдущий вариант, **▴** — больше или следующий.

| поле | что делает стрелка |
|---|---|
| число (`diameter=70`, `tip=0.35`) | прибавляет/убавляет шаг поля, держится в `min…max` |
| пустая «кромка» линзы (авто) | шаг от нуля: ▴ даёт 1 мм, ▾ не уходит ниже 0.2 |
| вариант (`mode=выпуклая`) | листает список по кругу: вогнутая → плосковыпуклая → … |
| цвет (`color=#d94f3d`) | следующий оттенок палитры |
| время (`text=21:38`) | минута с переходом через час: 21:59 → 22:00 |
| путь к картинке, `path` | стрелок нет — значение свободное |

Текстовые списки есть у 25 параметров: вид линзы, сторона инь-яна, тип патрона,
форма зубьев короны, вид полусферы, головка самореза, ось кубического
отверстия, форма косынки и ножки, режим складок, вид пор, узор решётки, вид
клинка, стиль причёски, вид экрана, форма зеркала, узор `pattern`, стиль
`anime`, а в «Приёмах» — `grain`, `open`, `mode` фаски и плоскость зеркала.

Удержание стрелки повторяет шаг (через 420 мс, затем каждые 110 мс); в самом
поле работают клавиши **↑ / ↓**. Любой шаг поднимает событие `input`, поэтому
живая миниатюра карточки пересобирается сразу — как при ручном вводе.

## 22. Дисковая пила и порядок в окнах (0.29)

### 22.1. `saw` — пила с настоящими зубьями

```
пила = saw diameter=200 thickness=2.5 teeth=24 tooth=10 shape=трапеция rake=10 hole=22
```

Полотно плоское: контур с зубьями выдавливается на толщину, поэтому деталь
выглядит диском, а не «цветком». Вершина зуба попадает ровно на наружный
диаметр, посадка — настоящее сквозное отверстие под вал.

| параметр | смысл | по умолчанию |
|---|---|---|
| `diameter` | наружный диаметр по вершинам зубьев, мм | 200 |
| `thickness` | толщина полотна, мм | 2.5 |
| `teeth` | число зубьев по кругу | 24 |
| `tooth` | высота зуба над полотном, мм | 5 % диаметра |
| `shape` | `треугольные`, `трапеция`, `крюк`, `волна` | `трапеция` |
| `rake` | передний угол: + вершина вперёд, − назад | 10 |
| `gullet` | глубина пазухи между зубьями, мм | 2 % диаметра |
| `kerf` | ширина пропила по зубьям (шире полотна) | толщина × 1.4 |
| `hole` | посадочное отверстие под вал, мм | 11 % диаметра |
| `windows` | круглые компенсационные отверстия, 0…12 | 0 |
| `detail` | точек на один зуб, 4…40 | 16 |

Формы зубьев подбираются под материал и задачу:

```
острый  = saw diameter=180 teeth=40 shape=треугольные rake=15     # чистый рез
карбид  = saw diameter=160 teeth=30 shape=трапеция windows=5 kerf=3.2
крюк    = saw diameter=200 teeth=18 shape=крюк rake=-12 kerf=3.6  # быстрый рез
волна   = saw diameter=120 teeth=14 shape=волна tooth=8            # дешёвый диск
```

Ограничения проверяются с подсказкой: отверстие не оставляет полотна,
окна не помещаются между валом и пазухой, диск распадается на части —
на каждую ошибку есть текст «что сделать».

### 22.2. Как читать «нет модели» в превью

Карточка инструмента и окно 3D теперь объясняют причину:

* в миниатюре — строка с параметром и рамками: `параметр «teeth» = 900,
  а допустимо 4…200`;
* под полем карточки — подпись `допустимо 4…200`, само поле подсвечено;
* в окне 3D — блок «Почему нет модели» с сообщением и подсказкой.

Наведите мышью на миниатюру — всплывёт полный текст с параметрами команды.

### 22.3. Зеркало и свечение

* Зеркальная деталь (`material=зеркало` или `mirror_plate`) отражает соседей
  **в правильном масштабе**: кадр рисуется из отражённой камеры и натягивается
  на пластину по экранной проекции. Нормаль пластины выбирается в сторону
  наблюдателя, поэтому повёрнутое зеркало не строит отражение от изнанки.
* Свечение (`emissive` / `material=led`) даёт ореол **только** вокруг
  светящейся детали: остальные предметы в проходе свечения чёрные и
  закрывают ореол, но сами не светятся. Сила — ползунок «вид → Свечение».

### 22.4. Что изменилось в окнах

* шапка «Модели»: ракурс одной капсулой, «выбор» и «кубы», справа «вид» и
  снимок; переключатели автоповорота, «к предмету», «вокруг выделенного» и
  «заслонки» — в панели «вид → Показ» с подписями;
* «сетка» и «полигонаж» остались галочками в панели «вид» (в шапке они были
  дублем);
* карточки «Инструментов»: параметры — сеткой «инспектора» (подпись над
  значением, две колонки), описание в две строки, длинные подписи
  обрезаются с многоточием и раскрываются подсказкой; кнопки не сжимаются,
  шапки панелей растут по высоте вместо обрезки.

## 23. Плоскость, рулон, сгиб и гофрирование (0.30)

### 23.1. `sheet` — плоскость с объёмом

Плоскость в Форме — **тонкий параллелепипед**, а не висячий полигон: у неё
есть толщина, замкнутая поверхность и объём. Поэтому её видно с обеих
сторон, она печатается, склеивается и участвует в булевых операциях.

```
лист   = sheet width=120 length=200 thickness=1.2
фольга = sheet width=90  length=140 thickness=0.3
плита  = sheet width=600 length=900 thickness=18
```

| параметр | смысл | по умолчанию |
|---|---|---|
| `width` | ширина, мм | 120 |
| `length` | длина, мм | 200 |
| `thickness` | толщина, мм | 1.2 |
| `step` | шаг волны, мм; 0 — гладкий | 0 |
| `amp` | амплитуда волны, мм | 0 |
| `wave` | `вдоль`, `поперёк`, `крест` | `вдоль` |
| `roll` | оборотов рулона; 0 — плоский | 0 |
| `gap` | зазор между витками рулона | толщина × 1.4 |
| `segments` | плотность сетки (авто) | — |

Волнистость:

```
гофролист = sheet width=200 length=300 thickness=0.8 step=30 amp=8
вафля     = sheet width=180 length=180 thickness=1   step=24 amp=6 wave=крест
шифер     = sheet width=300 length=400 thickness=2   step=60 amp=18 wave=поперёк
```

Рулон:

```
бумага = sheet width=120 length=600 thickness=0.6 roll=6 gap=1.4
рулон  = sheet width=200 length=1200 thickness=0.4 roll=12 gap=0.9
```

Рулон наматывается архимедовой спиралью, длина листа сохраняется точно.
Проверяется три вещи: `gap` больше толщины, листа хватает на заданное число
витков, при свёртке не задана волна (сначала лист волнистый, потом рулон —
это два разных шага, и команда на это прямо указывает).

### 23.2. `fold` — складывание как у бумаги

```
лист  = sheet width=100 length=200 thickness=1
сложенный = fold лист parts=2 angle=180 gap=1
буквой_г  = fold лист parts=2 angle=90  gap=2 axis=y
втрое     = fold лист parts=3 angle=180 gap=1
гармошка  = fold лист parts=4 angle=120 gap=1
```

| параметр | смысл | по умолчанию |
|---|---|---|
| `parts` | на сколько частей | 2 |
| `angle` | угол каждого сгиба, 1…180° | 180 |
| `gap` | просвет между слоями, мм | толщина × 0.5 |
| `axis` | вдоль какой оси делить (`x` или `y`) | `x` |
| `offset` | где линия сгиба у `parts=2`, 0.1…0.9 | 0.5 |

Как это устроено и почему поверхность не рвётся: сгиб — изометрическое
отображение вдоль оси. Линия сгиба заменяется дугой радиуса
`толщина + gap/2`, прямые участки укорачиваются на длину дуги, полная длина
сохраняется. Внутренний радиус дуги равен `gap/2`, поэтому внутренняя
поверхность сгиба никогда не проваливается сквозь внешнюю — **поверхность
не пересекает себя**. Правило простое: чем больше `gap`, тем толще «пухлый»
сгиб и тем виднее, что слои лежат рядом, а не слиплись.

Ограничения с подсказками: одной части не хватает на дугу (уменьшить `gap`,
`angle` или `parts`), линии сгиба ближе, чем занимает сам сгиб.

### 23.3. `corrugate` — гофрирование любой детали

```
лист = sheet width=160 length=220 thickness=1
corrugate лист step=22 amp=5                 # гофра
corrugate лист step=20 amp=4 mode=вафля      # вафля
corrugate лист step=16 amp=3 mode=рифление angle=45   # рифлёный металл
corrugate лист step=12 amp=4 mode=зигзаг     # острая гофра
цилиндр = cylinder radius=40 height=120
corrugate цилиндр step=25 amp=3              # рёбра по круглому телу
```

Смещение идёт по одной оси как функция от двух других — это график
поверхности, поэтому самопересечения невозможны по построению.
`angle` поворачивает узор в плоскости, `axis` выбирает, по какой оси
поднимать волны. `amp=0` — безопасный «выключатель», деталь не меняется.

### 23.4. `cardboard` — гофрокартон

```
трёхслойный  = cardboard width=200 height=300 liner=0.4 flute=3.5 step=8
двухслойный  = cardboard width=150 height=200 layer=2 flute=2.5 step=6
```

| параметр | смысл | по умолчанию |
|---|---|---|
| `width` / `height` | размер листа в плане, мм | 200 / 300 |
| `liner` | толщина плоского слоя, мм | 0.4 |
| `flute` | высота гофры, мм | 3.5 |
| `step` | шаг гофры, мм | 8 |
| `layer` | `2` — линер + гофра, `3` — с двух сторон | 3 |

Гофра вплавляется в линеры булевой операцией: деталь одна, без «наложенных»
слоёв. Проверки: `flute` больше `liner`, `step` больше `flute` — иначе гофра
сложилась бы сама в себя.

## 24. Окно: меню, панели и куда сохраняются файлы (0.31)

### 24.1. Меню по правой кнопке

Щёлкните правой кнопкой по детали в окне модели — меню появится **у курсора**.

| пункт | что делает |
|---|---|
| выделить предмет | то же, что левый щелчок |
| скрыть / показать предмет | как глаз в списке объектов |
| показать полигонами | каркас этой детали (или вернуть сплошной вид) |
| приблизить и вращать вокруг | камера облетает выбранную деталь |
| выделить кубы этого предмета | кубические секторы вокруг детали |
| удалить предмет | убирает строку из сценария |

У правого и нижнего края окна меню разворачивается в другую сторону, чтобы
не обрезаться. Закрывается по Esc, щелчку мимо, прокрутке и смене размера окна.

### 24.2. Границы панелей

Между «Сценарием», «Моделью» и «Отчётом» — полосы-разделители.

| действие | результат |
|---|---|
| потянуть полосу | две соседние панели меняют ширину, третья не трогается |
| двойной щелчок по полосе | панель слева сворачивается в полоску с названием |
| кнопка **‹ / ›** на полосе | свернуть или вернуть панель справа |
| кнопка **⤢** в шапке панели | развернуть панель на всё окно и вернуть обратно |
| щелчок по полоске свёрнутой панели | вернуть панель |

Минимальные ширины: сценарий 250, модель 320, отчёт 250 пикселей. Ширины и
свёрнутые панели хранятся в браузере (`forma3d.panels`) — окно открывается
таким, каким его оставили.

### 24.3. Куда попадают готовые файлы

Всё, что сохраняется из окна, оказывается **в папке «Загрузки»** этого
компьютера (Windows умеет её переименовывать, поэтому путь спрашивается у
системы):

* экспорт из меню «Экспорт» (GLB, STL, OBJ, PLY, 3MF, BLEND, DXF, SVG,
  PNG, ZIP, `.forma`, запрос для нейросети);
* запись анимации — **GIF** и **WebM** (кнопки в панели анимации);
* снимок окна модели — кнопка **⤓**;
* сохранённый проект `.forma`.

Рядом остаётся копия в папке данных приложения (`exports/`, `projects/`).
После первого сохранения в строке состояния появляется кнопка
**«открыть Загрузки»** — она открывает папку в проводнике.

### 24.4. Если модель «не крутится»

1. Проверьте, сколько объектов и треугольников в строке состояния.
   Больше 150 000 — окно само снизит качество (плотность пикселей,
   обновление отражений), но модель останется подвижной.
2. Зеркало строит отражение только для деталей с явной меткой
   `color имя материал=зеркало`; обычный металл отражений не рисует.
3. Тени перерисовываются, когда что-то движется; статичная сцена их не
   пересчитывает.

## 25. Скульпт руками и детализация примитивов (0.32)

До этой версии поверхность можно было менять только целиком. Теперь есть
инструменты «как руками»: они двигают вершины по месту, но деталь остаётся
одним замкнутым объёмом — годятся и для печати, и для Blender.

### Вмятина от удара

```
кружка = cylinder radius=40 height=120 segments=64 round=4
кружка = dent [кружка] at=[0, -40, 74] depth=9 radius=24 soft=0.75 rim=0.35   # мягко, палец по глине
кружка = dent [кружка] at=[0, 40, 40] depth=5 radius=12 soft=0.05 rim=0.6     # жёстко, шарик по металлу
```

`soft` — это **мягкость материала**: 1 — широкая гладкая вмятина, 0 — узкая с
резким краем. `rim` — валик по краю: он только придерживает спуск и никогда не
поднимается выше исходной поверхности, поэтому край не рвётся.

### Выдувание и щипок

```
колба = sphere radius=26 segments=48
колба = blow [колба] height=12 soft=0.7        # растёт шаром
флакон = cylinder radius=16 height=64 segments=48
флакон = blow [флакон] height=14 soft=0.8      # растёт бочкой: бок уходит, торцы почти стоят

заготовка = sphere radius=32 segments=48
заготовка = pinch [заготовка] axis=z amount=0.35 bulge=0.6   # сжали сверху — вышло вбок
```

`blow` двигает поверхность вдоль её нормалей, а не от одной точки; `pinch`
сжимает сечение и возвращает объём — деталь не «толстеет».

### Разровнять и разгладить — разные вещи

```
плита = box size=[120, 80, 30] round=4
плита = flatten [плита] at=[0, 0, 30] radius=40 strength=1 soft=0.7   # участок лёг в плоскость
камень = sphere radius=30 segments=48
камень = wrinkle [камень] amp=0.8 freq=30 mode=шум
камень = polish [камень] passes=20 strength=1                          # рябь ушла, шар остался
```

`flatten` тянет пятно к плоскости `at` + `dir`, `polish` убирает только мелкую
шероховатость. Объём после `polish` возвращается тем же — можно сглаживать
сколько нужно.

### Стёсывание, заострение, сверление

```
брусок = box size=[54, 54, 88] round=3
брусок = shave [брусок] at=[0, 0, 88] dir=[0, 0.55, 1] depth=20 radius=0   # сняли слой фасеткой
карандаш = cylinder radius=9 height=88 segments=48
карандаш = point [карандаш] length=26                                       # точилка
плита = box size=[80, 70, 24] round=2
плита = bore [плита] at=[-19, 0, 24] diameter=18 depth=15 tip=конус countersink=6
плита = bore [плита] at=[21, 0, 24] diameter=18 depth=15 tip=сфера
```

`tip` у `bore`: `плоско`, `конус` (118°, как у сверла), `сфера`, `ступень`
(`step` — диаметр второй ступени). `countersink` расширяет вход конусом.

### Полигонаж

```
грубая = sphere radius=30 segments=12
мелкая = refine [грубая] length=2        # ребро не длиннее 2 мм
```

`refine` дробит сетку под нужное ребро (`length`) или в `levels` раз; выше
2.5 млн треугольников останавливается и пишет об этом.

### Детализация примитива вместо «сколько сегментов»

```
шар = sphere radius=50 detail=0      # 288 трис — черновик
шар = sphere radius=50 detail=3      # 2 312 трис — обычная (по умолчанию)
шар = sphere radius=50 detail=5      # 9 248 трис — гладко
куб = box size=[120, 80, 60] round=6 detail=4
тор = torus major=55 minor=12 detail=5
```

В карточке инструмента это ползунок, а число треугольников при текущих
настройках написано под миниатюрой — видно до добавления в сценарий.

### Аниме-портрет

```
# examples/anime_face.forma
```
С 0.34 — не плоская панель, а объёмный бюст: голова одним SDF, шея и плечи,
волосы массой с окном для лица. Подробности — §27.

## 26. Место в пространстве, меры и бюджет объёма (0.33)

### Проверить, что деталь стоит там, где задумано

```
осн = box size=[120, 90, 10]
а = cylinder radius=12 height=26 at=[-34, -22, 10]
check а положение -46 -34 10                 # угол габарита, мм
check а положение x=-47..-45 y=-35..-33 z=10..11 допуск=0.5
check а центр 0 0 0                          # центр габарита — тоже проверяется
```

`положение` сравнивает **угол габарита** (min x, min y, min z — левый-передний-
нижний), `центр` — середину габарита. Значения можно писать числом, диапазоном
`9..11` или по осям `x=… y=… z=…`; `допуск=` в миллиметрах (по умолчанию 0.5).
В отчёте сразу видно, по какой оси деталь уехала.

### Меры прямо в аргументах

```
кружка = cylinder radius=40 height=95 segments=64
крышка = cylinder radius=42 height=10 at=[0, 0, top(кружка) + 2]      # верх + 2 мм
ручка  = torus major=28 minor=6 at=[cx(кружка) + 44, 0, height(кружка) * 0.55]
```

Меры (`top`, `bottom`, `left`, `right`, `front`, `back`, `height`, `width`,
`depth`, `volume`, `cx`, `cy`, `cz`) раскрываются в **любой** команде — не
только в `let`. Значение считается по текущей геометрии детали, поэтому
`top(кружка)` после скульпта будет честным.

### Зазор, который действительно доходит до цели

```
плита = box size=[110, 110, 16]
деталь = box size=[28, 28, 28] at=[0, 0, 12]         # сидит в плите
сопряжение деталь плита type=зазор axis=z offset=5
check деталь связь                                    # остаток 0 мм
```

Сопряжение считает реальный зазор между телами (а не габаритными коробками):
выводит деталь из пересечения, подводит к контакту и уточняет положение
бисекцией. Работает для сфер, цилиндров и деталей после скульпта.

### Плоскость и паз по настоящей грани

```
плита = box size=[120, 120, 10]
плита = rotate [плита] angle=28 axis=x
шапка = box size=[40, 40, 30] round=2
сопряжение шапка плита type=плоскость axis=z        # ляжет на наклонную грань

рейка = box size=[36, 260, 12] center=да at=[0, 0, 30]
рейка = rotate [рейка] angle=18 axis=x
колесо = cylinder radius=16 height=14 center=да
сопряжение колесо рейка type=паз axis=y             # сядет на верхнюю грань рейки
```

Если деталь стоит сбоку и проекции не перекрываются, положение задаёт уровень
грани — именно этого ждут от «поставить на плоскость в стороне».

### Кубическая сетка как бюджет объёма

```
сетка cell=20 origin=[-60, -60, 0] size=[6, 4, 3]   # 6×4×3 куба по 20 мм = 576 см³
корпус = sphere radius=90 at=[0, 0, 40]
корпус = вписать корпус                              # лишнее срезано по кубам
check корпус в_сетке
```

Другие способы задать кубы:

```
сетка cell=20 cells=[[0,0,0], [1,0,0], [0,1,0]]       # по одному
сетка cell=20 ranges=[[0, 5, -1, 1, 0, 0]]            # блоки, как рамкой
сетка cell=20 around=да pad=2                          # всё вокруг модели
```

* `вписать имя` — обрезка `деталь ∩ кубы`; на детали остаётся приписка
  «обрезано по сетке 20 мм: снято N см³ (M%)»;
* `check имя в_сетке` — доля объёма внутри бюджета; если больше, в проверке и в
  замечаниях пишется «вне бюджета N см³» и совет — `вписать` или расширить сетку;
* в окне режима «кубы» кнопка **«Записать бюджет»** переводит выделение в
  команду `сетка` (координаты пересчитываются в сценарные, z — вверх), а карточка
  кубов подсвечивается красным, если модель вылезает из бюджета.

## 27. Объёмный аниме-бюст, волосы, оригами, складки и цепь (0.34)

### Голова одним SDF-полем

```
череп = from_sdf bounds=[-105,-120,150,105,120,370] resolution=1.9 expression="\
  smin(smin(smin(smin(sd_ellipsoid(x,y-2,z-282,70,72,72), \
  sd_ellipsoid(x,y-14,z-244,62,64,58),20), \
  sd_ellipsoid(x,y-20,z-218,52,56,42),15), \
  sd_ellipsoid(x,y-26,z-198,38,42,28),12), \
  sd_ellipsoid(x,y-30,z-184,22,26,18),10)"
нос = from_sdf bounds=[-24,-120,220,24,-20,265] resolution=1.2 expression="smin(sd_ellipsoid(x,y+54,z-242,5.5,9,11), sd_ellipsoid(x,y+57,z-236,3.6,5.5,5.5),7)"
голова = union [череп, нос, ухо_п, ухо_л]
```

Пять эллипсоидов от лба к подбородку, сваренных `smin`: без стыков и «ступенек».
Глаза садятся по таблице передней поверхности: при `x=30 z=254` перед лица —
`y=−57`, поэтому `глаз at=[32,-62,252]`.

### Волосы: локоны, волосинки, чёлка

```
чёлка = чёлка width=150 height=66 arc=36 teeth=9 thick=10 thin=3.5 at=[0,-56,336] dir=[0,-0.5,-1] jag=0.6 bend=0.55
локон = локон at=[82,-14,306] length=190 radius=15 turns=0.55 thick=17 thin=6 dir=[0,0.25,-1] side=[1,0,0]
пучок = волосинки from=[-52,-36,196] to=[52,-36,196] count=46 length=44 thick=1.6 bend=0.6 curl=0.4 dir=[0,-0.55,-1] base=да
```

У всех трёх `at` — **обычный сдвиг** (абсолютные координаты), а не «низ габарита
на z»: иначе чёлка уезжает вверх на свою высоту.

### Глаз с подводкой и глубиной

```
глаз_п = глаз width=46 height=30 at=[32,-62,252] iris=#8fa48f lash=2.4 depth=0.4 rim=да
бровь_п = бровь width=38 at=[32,-70,300] tilt=0.1 arch=5 thick=1.8
губы = губы width=28 at=[0,-40,208] smile=0.3 open=0.2 thick=2.6
```

`rim=да` — тёмный контур по всему глазу, `depth` — насколько глаз выступает:
0.2 — наклейка, 1.0 — выпуклый купол.

### Сгиб от угла и складки

```
лист = sheet width=120 length=160 thickness=1
с = сгиб лист at=[0,0,1] dir=45 angle=135        # диагональ, от угла
с2 = сгиб с at=[60,-80,1] dir=90 angle=60 side=-1

куртка = box size=[80,40,120] round=6
складка куртка from=[-30,-20,60] to=[30,-20,60] r=5 mode=канавка
складка куртка from=[-26,-20,30] to=[30,-20,40] r=4 bend=8 mode=гребень
```

`dir` — направление линии в градусах от +X (0 — вдоль X, 90 — вдоль Y,
45 — от угла); `side` — какая половина подвижная; объём при сгибе сохраняется.

### Цепь и соединение готовых деталей

```
цепь links=8 size=26 wire=3.4 at=[0,0,80] dir=[1,0,0]
крюк = torus major=20 minor=4 at=[0,0,200]
ведро = cylinder radius=30 height=60 at=[0,0,40]
соединить [крюк, ведро] size=16 wire=2.4 sag=0.15
```

Звено вытянутое, соседние повёрнуты на 90° и зацеплены. `соединить` сам находит
ближайшие точки деталей и подбирает число звеньев по длине.

### Инструкция для ИИ

В панели «Помощь ИИ»:

* **«Скопировать инструкцию для ИИ»** (`/api/instruction?kind=full`) — правила,
  оси, единицы, материалы, проверки, анимация и полный каталог команд;
* **«Скопировать все команды»** (`?kind=commands`) — только каталог: каждая
  команда с параметрами, умолчаниями и рабочим примером.

Каталог собирается из реестра команд, поэтому новая команда попадает туда сама.

## 28. Мерки соседа, размер по мерке и ряд с градацией (0.35)

### Относительное смещение: на полширины, на высоту, на длину

Мерки раскрываются в любом числовом параметре любой команды, поэтому
«правее на 0.5 длины» — это просто выражение:

```
ящик = box size=[80, 50, 30]
крышка = box size=[10, 10, 4]
крышка = translate [крышка] offset=[0.5*width(ящик), 0, height(ящик)]
```

Что доступно: `width`/`ширина`, `depth`/`глубина`, `height`/`высота`,
`length`/`длина` (наибольший габарит — удобно для «в 1.5 раза длиннее»),
`volume`/`объём`, `top`, `bottom`, `left`, `right`, `front`, `back`,
`cx`, `cy`, `cz`. Числа берутся по фактическому габариту готовой детали.

### Относительный размер: `размер`

Множитель считать вручную не нужно — команда сама делит мерку на текущий
габарит. Остальные оси остаются как были:

```
а = box size=[80, 50, 20]
б = box size=[10, 10, 10]
б = размер [б] width=1.5*width(а) depth=0.5*depth(а)
```

`width`, `depth`, `height` — какими станут габариты; `length` — наибольший
габарит; `factor` — просто множитель; `keep=да` сохранит пропорции;
масштаб идёт от центра детали.

### `ряд`: массив со ступенями изменения

```
кольцо = torus major=22 minor=4
кольцо = rotate [кольцо] angle=90 axis=x
волны = ряд [кольцо] count=3 grow=1.5
```

Каждая следующая копия: сдвиг `step`, рост `grow`, поворот `turn` вокруг
`axis`. Расстояние тоже можно задавать меркой:
`step=[0.35*width(плита),0,0]` — шаг равен 35% ширины плиты.

### Сила инструмента ступенями

```
шарик = sphere radius=16 segments=64
дырки = ряд [шарик] count=5 step=[42,0,0] инструмент=вмятина \
        сила=4 шаг_силы=1.3 radius=11
```

`инструмент`: `вмятина` (глубина в мм), `скрутка` (градусы на высоту),
`сужение` (доля 0…0.9), `сдвиг` (мм к верхушке), `надуть` (доля объёма).
`сила` — на первой копии, `шаг_силы` — во сколько раз она меняется от
копии к копии (1 — одинаково, <1 — слабеет). `soft` и `radius` настраивают
пятно вмятины.

### Значок Wi-Fi целиком

```
кольцо = torus major=22 minor=4 segments=96 detail=4
кольцо = rotate [кольцо] angle=90 axis=x
волны = ряд [кольцо] count=3 grow=1.5
низ = box size=[400,120,220] at=[0,0,-220]
дуги = difference [волны, низ]        # остались верхние половины
точка = sphere radius=8 at=[0,0,2]
```

Соберите ряд из колец или брусков командами `ряд` выше; множители применяются по ступеням.

## 29. Крюк, полуовал и посадка на границу (0.36)

### `крюк`: один непрерывный пруток без кольца

```
крюк = крюк wire=6 radius=22 length=70 open=240 tip=капсула
острый = крюк wire=6 radius=22 length=70 open=240 tip=острый taper=0.94
```

* `wire` — диаметр прутка; `radius` — радиус дуги; `length` — прямой хвост;
* `open=45…350` — угол загиба; `offset=[x,z]` смещает дугу, `aspect` делает
  её эллиптической, `curve` — боковой прогиб;
* `tip=капсула|острый`, `taper` — сила сужения острого кончика.

Ни ушка, ни отдельного кольца нет. Хвост, соединитель и дуга — один sweep и
один герметичный объём.

### `полуовал`: с отверстием или без

```
подвес = полуовал width=90 height=55 thickness=8 hole=16
накладка = полуовал width=140 height=60 thickness=5 hole=0
```

Снизу прямая кромка, сверху дуга эллипса. `hole` — диаметр отверстия:
`0` — сплошная пластина, число — сквозная дырка по центру. Если отверстие
слишком велико и вылезает за кромку, оно **само уменьшается** до разумного
(в отчёте будет предупреждение), а не рвёт деталь. `hole_y` (0…1) двигает
отверстие по высоте.

### `на_границе`: посадка на поверхность, а не на центр коробки

`place … on=деталь` ставит деталь относительно **центра габарита**. Для тора
это широкая коробка вокруг кольца: «сбоку» получается сбоку от пустоты.
`на_границе` ищет **ближайшую точку настоящей поверхности** к точке
`point=[x, y, z]` и приставляет к ней деталь:

```
кольцо = torus major=40 minor=8 at=[0,0,70]
шайба = cylinder radius=6 height=4
шайба = на_границе [шайба] on=кольцо point=[60,0,70] offset=1 align=нормаль
```

* `point` — куда целимся (по умолчанию центр детали);
* `offset` — зазор от поверхности, мм;
* `align=нормаль` — развернуть деталь по нормали поверхности (шайба ляжет
  плашмя на кольцо, шарик сядет на бок трубки); без `align` деталь остаётся
  в своей ориентации и лишь касается поверхности;
* `at` — сдвиг уже после посадки.

Внутренняя кромка — та же команда, только цель в отверстии:
`на_границе [втулка] on=кольцо point=[0,0,70]` посадит втулку к внутренней
стенке кольца.

Границу можно взять и формулами мерок, если нужна именно координата, а не
посадка: `at=[0.5*width(кольцо), 0, top(кольцо)]` — внешняя кромка,
`0.5*(width(кольцо) − 2*minor)` — внутренняя. Но `на_границе` не надо
пересчитывать после каждого изменения размеров хозяина.

Проверяйте посадку лучом к фактической границе, а не по центру габарита.

## 30. Воронка, ориентация и посадка по осям хозяина (0.37)

Относительная посадка отвечает на вопрос «где», но не на вопрос «куда смотрит
деталь». После `rotate` верх предмета уже не +Z, и `place … side=top` ставит
деталь на мировой верх, а не на настоящий. В 0.37 появились воронка, памятка
ориентации и посадка по осям хозяина.

### `воронка`: конус, носок и стенка одной деталью

```
воронка = воронка top=120 bottom=16 height=80 spout=40 wall=3
сопло = воронка top=45 bottom=6 height=35 spout=20 wall=1.5 lip=0
```

* `top` / `bottom` — диаметры широкой части и носка;
* `height` — высота конуса; `spout` — длина трубки;
* `wall` — толщина стенки, `lip` — буртик по верхней кромке (0 — без него).

Профиль вращается как **замкнутый контур**: снаружи конус и трубка, изнутри —
то же самое с отступом на стенку. Деталь герметична (`genus()` = 1 — канал
насквозь), кромка сверху открыта, печатается без поддержек. Слишком толстая
стенка не «съест» канал: команда откажет с подсказкой.

### `ориентация`: куда смотрит деталь

```
корпус = box size=[140,40,40]
корпус = rotate [корпус] angle=90 axis=y
ориентация корпус
# верх +X, низ −X, право −Z, лево +Z, перёд −Y, зад +Y
# центр габарита (20, 0, 0); центр массы (60, 0, 0)
```

После поворота у детали сохраняется матрица «мир ← деталь». `ориентация`
печатает её словами: верх, низ, право, лево, перёд, зад. Центр габарита
может оказаться в пустоте — у тора, воронки, кольца; команда это прямо
говорит и показывает центр массы.

Стороны можно задать вручную, если деталь пришла из другого редактора:

```
ориентация [деталь] верх=+x перед=-y
```

### `place … осями=хозяина`: верх едет вместе с хозяином

```
корпус = box size=[140,40,40]
корпус = rotate [корпус] angle=90 axis=y        # верх теперь +X
крышка = cylinder radius=18 height=6
крышка = place [крышка] on=корпус side=top осями=хозяина
```

Деталь садится на настоящий верх корпуса (x = 20), разворачивается по его
осям и получает ту же памятку ориентации. `align=нет` оставит её в своей
ориентации — пригодится, когда важна не «приклеенность», а положение.

Зазор по-прежнему отсчитывается от **крайней границы** хозяина:

```
ручка = place [ручка] on=ящик side=left offset=length(ящик)
```

Это «слева от ящика, на расстоянии одной его длины»: ручка целиком за
границей, ближняя точка — в `offset` от неё. Зазор можно задать любой меркой:
`offset=0.25*width(ящик)`, `offset=2*height(стойка)`.

### Центр массы вместо центра коробки

У тора и воронки центр габарита — пустота. Для этого есть:

* мерки `mx(деталь)`, `my(деталь)`, `mz(деталь)` (и `центр_масс_x` …);
* `place [деталь] on=хозяин side=center центр=масса` — поставить в материал;
* `place [деталь] on=хозяин side=top центр=масса` — центрировать по массе;
* `на_границе [деталь] on=хозяин point=[x,y,z] сторона=верх` — искать
  ближайшую точку только в верхней половине, а не по всему телу.

После поворота хозяина вызовите `ориентация` и проверьте верх крышки в отчёте.

## 31. Порядок примитивов и новые тела (0.38)

### Каталог: сначала тела, потом способы

Панель инструментов разделена на две части. **Примитивы** идут четырьмя
ступенями — так же, как их удобно держать в голове:

| ступень | что внутри | когда брать |
|---|---|---|
| стандартные | лист, куб, призма, октаэдр, пирамида, конус, цилиндр, шар, икосфера, эллипсоид, капсула, тор, кольцо, шайба | базовый объём: из него собирается почти всё |
| производные | полусфера, сектор, уголок, полуовал, арка, воронка, скоба, линза, патрон | половина или часть стандартного тела, профиль |
| природные | яйцо, капля, полумесяц, звезда, молния, сердце, облако, алмаз, рог, камень, лист растения, банан | форма «от природы», без чертёжных углов |
| готовые детали | инь-ян, корона, стрелки, Т/П/Y/U, тарелка, пружина, шестерня, пила, крепёж, шкив, колесо, цепь, крюк, картон, клинок … | стандарт, который нельзя выдумать: резьба, профиль, крепёж |

**Инструменты и способы** (лепка, поверхности, сгибы, массивы, стиль) идут
после и больше не перемешиваются с телами.

### `octa`: октаэдр

Восемь одинаковых треугольных граней. Ширина и длина задаются радиусом,
высота — отдельно:

```
кристалл = octa radius=30 height=80
правильный = octa radius=25 height=50
вытянутый = octa radius=20 depth=35 height=90
```

Если `height` не задан — получается правильный октаэдр (`2·radius`).

### `ellipsoid`: три полуоси

```
дно = ellipsoid x=60 y=40 z=22
капля = ellipsoid x=25 y=25 z=60
```

Для головы, камня, посуды это честнее, чем `scale`: полуоси видны в паспорте
детали и не ломают `place`/`на_границе`.

### `скоба`: П, U и замкнутая рамка

```
кронштейн = скоба length=120 width=40 height=30 wall=3
лоток = скоба length=120 width=40 height=30 wall=3 open=вверх
рамка = скоба length=160 width=90 height=60 wall=4 стороны=4
```

`стороны=3` — две полки и стенка: `open=вниз` даёт форму П (перекладина
сверху), `open=вверх` — U-лоток. `стороны=4` — прямоугольная рамка со стенкой
по кругу, например под стекло или картину.

### «Лист» и «листок» — разные вещи

```
лист = sheet width=120 length=200 thickness=1.2    # плоскость с объёмом
листок = leaf length=90 width=45 thickness=2       # лист растения
```

То же с глаголами: `дуга` сгибает деталь (`bend`), `арка` строит проём,
`зеркало` отражает, а зеркало-изделие — `зеркальная_плита`.

### Пример целиком

Стандартные тела можно вставить из первой группы «Инструментов» и расположить командой `ряд`.
Удобно сравнивать габариты и брать заготовку: скопируйте строку, поменяйте
имя и размеры.

## 32. Восемь новых тел (0.39)

### `disc` и `oval`: плоские тела с объёмом

```
блин = disc diameter=120 thickness=8 round=2
поднос = oval width=200 length=120 thickness=8 round=3
```

Круг — это цилиндр с малой высотой, овал — эллиптическая плита. Разница с
`cylinder`/`sheet` в том, что здесь сразу задаётся диаметр и толщина, а
`round` скругляет кромку по контуру (без него край тонкий и режет).

### `pie`: сектор круга

```
кусок = pie diameter=140 angle=90 thickness=8
стрелка = pie diameter=120 angle=60 start=200 thickness=6
```

`angle` — угол, `start` — откуда начинать (градусы от +X). `angle=360` даёт
круг. Уголок используется и как козырёк, и как сегмент диаграммы.

### `ingot`: объёмная трапеция

```
слиток = ingot length=100 width=50 height=22 taper=8
груз = ingot length=60 width=40 height=30 taper=12 round=6
```

`taper` — насколько верхняя площадка меньше нижней (по каждой стороне).
Объём сходится с формулой усечённой пирамиды, это проверено тестом.

### `paraboloid`: чаша или купол

```
чаша = paraboloid diameter=140 height=34
миска = paraboloid diameter=120 height=40 wall=3
```

`wall=0` — сплошное тело, `wall>0` — чаша со стенкой; стенка меряется по
высоте. От полусферы отличается профилем: склон выполаживается к краю.

### `saddle`: гиперболический параболоид

```
крыша = saddle length=160 width=120 rise=40 thickness=4
чипс = saddle length=120 width=120 rise=30 thickness=3 mode=седло
```

`гипар` — углы попарно вверх и вниз (крыша с прямыми рёбрами); `седло` —
края вверх, середина вниз (чипс). Толщина делает герметичную плиту.

### `stairs`: ступеньки

```
марш = stairs steps=6 rise=18 run=28 width=120
мягкий = stairs steps=5 rise=16 run=30 width=100 shape=скруглённая
```

`steps` — частота ступеней, `rise` — подъём, `run` — глубина проступи.
`shape=прямая|скруглённая` задаёт наружную кромку, а
`inner=прямой|скруглённый` — внутренний угол между проступью и подступенком;
радиусы `round` и `inner_r` независимы. Скошенного режима нет. Марш сплошной;
подъём идёт в +X, поэтому низкая ступень слева.

### `bead`: бусина

```
бусы = bead diameter=16 hole=4
кольцо_бус = bead diameter=24 height=14 hole=6 chamfer=1.2
```

Канал сквозной, `chamfer` снимает фаску у входа, чтобы шнур не резал кромку.
Тело строится вращением профиля, а не вычитанием цилиндра из шара: так
габарит точный, а сетка чистая. Полюса срезаны каналом — фактическую высоту
команда пишет в отчёте.

## 33. Механика и произвольные формы (0.40)

### `ladder`: лестница с настраиваемыми рейками и перекладинами

```
приставная = ladder length=1800 width=420 rungs=9 tilt=72
деревянная = ladder length=1500 width=380 rail=брусок rail_d=44 rung=брусок rung_d=34 rungs=7 tilt=84
стремянка = ladder length=1200 width=340 rail=овал rail_d=32 rungs=6 tilt=90
```

`length` — длина реек, `width` — просвет между ними, `rungs` — сколько
перекладин, `margin` — отступ первой от края (по умолчанию ~1.5 толщины рейки).
`rail` — `капсула`, `брусок` или `овал`; `rung` — `цилиндр` или `брусок`.
`tilt` — угол к полу: 90° стоит, 0° лежит.

Овальная рейка имеет плоские боковые грани, прямые продольные участки и
полукруглые торцы — это не вытянутый эллипсоид. Перекладины заканчиваются у
внутренней поверхности реек и не торчат наружу; технологический стык 0,05 мм
даёт одно тело. Наклон считается вокруг нижнего конца, затем сборка ставится
низом на пол. Требуется `rung_d ≤ rail_d`.

### `lever`: палка и ручка

```
джойстик = lever length=180 diameter=14 knob=шар knob_d=34
ворот = lever length=140 shaft=брусок size=20 knob=цилиндр knob_d=30 knob_h=60
педаль = lever length=260 shaft=брусок size=20 knob=цилиндр knob_d=30 knob_h=70 angle=18
```

`shaft` — `цилиндр` (толщина `diameter`) или `брусок` (сечение `size`),
`knob` — только `шар` или `цилиндр`. `knob_h` задаёт продольный размер обоих
наконечников: шар становится эллипсоидом, а не игнорирует длину. `angle` —
наклон вверх. Палка обрезана по поверхности наконечника и не торчит сквозь него;
общий габарит по X равен `length`. Режима `knob=нет` больше нет.

### `button`: кнопка из двух деталей

```
пуск = button diameter=30 height=10 top=вогнутая
аварийная = button diameter=60 height=18 top=выпуклая base_d=110 base_h=14
тумблер = button diameter=34 height=12 fit=зазор gap=3 base=квадрат
```

`top` — `плоская`, `вогнутая` (ложбинка `sag` под палец) или `выпуклая`.
`base` — `цилиндр` или `квадрат` размером `base_d` и высотой `base_h`.
`fit=плотно` оставляет зазор 0.3 мм (детали не слипаются), `fit=зазор` —
кольцевую щель `gap`.

Команда создаёт **два объекта**: `<имя>` — шляпка и `<имя>_гнездо` —
платформа с вырезом. Это и есть просьба «две разные объекта для простой
анимации»: шляпку двигают отдельно.

```
пуск = button diameter=30 height=10
keyframe пуск at=0 pos=[0,0,6]
keyframe пуск at=0.2 pos=[0,0,0]
animate kind=move dz=6 seconds=0.4 track=1
```

### `tri_prism`: треугольная призма с любыми углами

```
клин = tri_prism a=120 b=90 c=60 height=80
равнобедренная = tri_prism a=100 b=100 c=40 height=50
по_углам = tri_prism base=110 angle_a=55 angle_b=65 height=60
```

Два способа задать треугольник: три стороны (`a`, `b`, `c`) или основание и
два угла при нём (`base`, `angle_a`, `angle_b`) — третий угол и стороны
считаются по теореме синусов. Треугольник строится по Герону, поэтому
равносторонний, прямоугольный и тупоугольный равно честные.

Если стороны не складываются в треугольник, команда пишет ошибку и
подсказывает правило. `round` скругляет рёбра основания; `height` — высота
призмы, треугольник лежит в основании (как у `prism`).

### `torus_sector`: дуга тора

```
полукольцо = torus_sector major=60 minor=10 angle=180
подвес = torus_sector major=50 minor=12 angle=200 hole=8
звено = torus_sector major=30 minor=8 angle=300 hole=6
```

`major` — радиус кольца (до центра трубки), `minor` — радиус трубки, `angle`
— угол дуги, `start` — откуда начинать. `hole` сверлит сквозное отверстие по
оси Z посередине дуги: получается полое кольцо под шнур или облегчённая деталь
(род становится 1, это проверено).

Отверстие не может быть шире трубки — команда проверяет стенку и пишет
допустимый диаметр. Дуга 0…180° идёт от +X через +Y к −X.

## 34. Личные оси, параллельность и посадка нужной стороной (0.41)

**Единый канон исходной детали:** верх `+Z`, низ `−Z`, право `+X`, лево
`−X`, перёд/лицо `−Y`, зад `+Y`. Плоские знаки по умолчанию стоят в XZ
лицом `−Y`; `plane=плашмя` кладёт их в XY лицом `+Z`. У надписи `plane=yz`
чтение идёт `+Y`, высота букв `+Z`, лицо `+X`.

В справке и в отдельном каталоге для нейросети у каждого из 101 примитива
есть пункт **«Исходная ориентация»**. Там указаны не только размеры, но и
остриё, масса, вырез, раскрытие полости и ось отверстия. Например, у серпа
масса `−X`, выкус `+X`; у арки проём снизу; у бусины канал по Z; у лестницы
рейки разнесены по Y, а подъём идёт из исходного `+X` к `+Z`.

### Параллельно другой детали

```forma
опора = cylinder radius=10 height=60
опора = rotate [опора] angle=90 axis=x pivot=[0,0,30]
рейка = box size=[60,12,12] at=[100,30,50] center=да
рейка = parallel [рейка] on=опора axis=top host_axis=top
```

`axis` — локальная ось перемещаемой детали, `host_axis` — локальная ось
хозяина. Принимаются `x/y/z`, `верх/низ`, `перёд/зад`, `лево/право` и вектор
`[x,y,z]`. Команда поворачивает рейку вокруг центра её габарита, **не двигает
центр** и не добавляет произвольный оборот вокруг совмещённой оси.
`flip=да` даёт антипараллельное направление.

### Перпендикулярно другой детали

```forma
стойка = cylinder radius=12 height=90
планка = box size=[70,10,16] at=[100,0,40]
планка = perpendicular [планка] on=стойка axis=top host_axis=top direction=+x
```

Здесь локальный верх планки становится перпендикулярен локальному верху
стойки и направлен `+X`. `direction` задан в мировых координатах и проецируется
в перпендикулярную плоскость. Если его не задать, выбирается проекция `+Z`;
для вертикальной оси хозяина — `−Y`, затем `+X`. Центр детали сохраняется.

### Поставить СВОЕЙ стороной к стороне хозяина

```forma
корпус = box size=[100,60,50]
крышка = box size=[80,40,5]
крышка = place [крышка] on=корпус side=top face=bottom gap=1.5
```

`side=top` выбирает сторону **хозяина**, `face=bottom` — контактную сторону
**крышки**. Наружные нормали контактных сторон направлены друг против друга.
Посадка идёт по локальным осям хозяина, даже если он повёрнут. Зазор измеряется
между крайними точками фактического объёма вдоль контактной оси, а не между
центрами габаритных коробок.

Другой пример — панель своим лицом к передней стороне корпуса:

```forma
панель = box size=[50,4,30]
панель = place [панель] on=корпус side=front face=front gap=2
```

Панель сама развернётся: её исходный перёд `−Y` будет смотреть `+Y`, навстречу
переду корпуса `−Y`. Синонимы `face`: `own_side=`, `своей=`, `стороной=`.
`side=center` с `face` не используется — у центра нет контактной нормали.

### Где посмотреть личные оси

Отдельной панели ориентации нет. Выделите предмет в 3D-окне: из центра его
габарита появляются три временные стрелки **ПРАВО / ПЕРЁД / ВЕРХ**. Они следуют
за поворотами и посадками, исчезают при снятии выделения и не попадают в
зеркальные отражения. Команда `ориентация деталь` по-прежнему печатает те же
стороны текстом.

### Проверенные полости

У `hemisphere wall>0` и `paraboloid wall>0` дно находится снизу, а полость
открыта `+Z`. Сплошной `hemisphere wall=0` остаётся на плоском основании
вершиной `+Z`; отдельного `mode` у полусферы больше нет.

## 35. Плоскости, срезы и ячейки примитивов (0.42)

Соберите по одному телу с каждым параметром и сравните их срезы и сетку.
Каждый предмет должен остаться отдельным замкнутым телом. Поля ниже есть и
в карточках инструментов.

### Верхняя плоскость блока, призмы и цилиндра

```forma
б = box size=[100,80,50] top_size=[60,40] top_offset=[10,-5]
п = prism sides=6 radius=30 r2=20 height=50 top_scale=[1.2,0.8] top_offset=[10,-5]
ц = cylinder radius=40 r2=30 height=60 top_scale=[1.2,0.7] top_offset=[10,-5]
```

* `top_size=[X,Y]` — независимые стороны верха блока; `size` по-прежнему
  задаёт низ и полную высоту.
* `top_scale=[sx,sy]` умножает размеры верхнего сечения призмы/цилиндра.
  У цилиндра поэтому верх может быть эллипсом. Базовый радиус верха — `r2`.
* `top_offset=[dx,dy]` сдвигает **всю верхнюю плоскость** относительно низа.
  Плоскость остаётся горизонтальной: это сдвиг, а не наклон командой `rotate`.
* У наклонных вариантов `round` у блока/цилиндра использует перенос каждой
  грани внутрь и Minkowski-сумму с шаром. Верх и низ по Z сохраняются;
  острые углы естественно скругляются, поэтому крайние XY-точки могут уйти
  внутрь исходного габарита.

### Параллелограмм в основании

```forma
ромб = box size=[100,80,50] base_angle=60
четырёхгранник = prism sides=4 radius=30 height=50 base_angle=60
скошенная = pyramid sides=4 radius=40 height=70 base_angle=60 tip_at=corner
```

`base_angle` — угол между сторонами основания, `90` сохраняет прямой угол.
У блока стороны равны `size.x` и `size.y`. У четырёхсторонних призмы и пирамиды
`base_angle≠90` тоже строит параллелограмм; для другого числа сторон команда
честно отклоняет такой параметр. Объём основания умножается на `sin(base_angle)`.

### Вершина пирамиды и сглаживание

```forma
к_углу = pyramid sides=4 radius=40 height=70 tip_at=corner tip_index=0
к_ребру = pyramid sides=4 radius=40 height=70 tip_at=edge tip_index=1
круглая = pyramid sides=4 radius=40 height=70 smooth=2
```

`tip_at=center` — центр, `edge` — середина выбранного ребра, `corner` —
выбранный угол. Индексы идут от нуля по вершинам исходного профиля. Прямой
числовой `tip=[x,y]` сохранён; его нельзя одновременно смешивать с `tip_at`.

`smooth=0…4` у призмы, пирамиды и октаэдра — настоящее Loop-сглаживание,
а не просто изменение цвета или числа граней. Каждый уровень делит треугольники
на четыре и перемещает вершины. Исходный габарит восстанавливается, поэтому
заданная высота остаётся управляющей величиной. Слишком плотная сетка
ограничивается 220 000 треугольников с понятной подсказкой.

### Октаэдр: больше вершин или другая форма

```forma
гранёный = octa radius=30 height=80 divisions=2
округлый = octa radius=30 height=80 divisions=1 smooth=2
```

Без новых параметров остаются 6 вершин и 8 треугольников. Каждый уровень
`divisions` делит грань на четыре, поэтому при `divisions=n` получается `8·4^n`
треугольников **без изменения формы и объёма**; при `divisions=2` — 66 вершин
и 128 треугольников. `smooth` уже округляет форму.
Два параметра можно сочетать.

### Плоский срез сферы и скругление кромки

```forma
чаша = sphere radius=40 slice=0.5
половина = sphere radius=40 slice=1 round=3
точно_мм = sphere radius=40 cut=12
```

`slice` — отсекаемая доля радиуса, `0…1`; `cut` — та же глубина
в миллиметрах, `0…radius`, то есть `cut = slice·radius`. Верхняя плоскость находится на
`z = at.z + radius·(1−slice)` или `z = at.z + radius−cut`.
Поэтому `slice=0.5` оставляет тело от `−R` до `+R/2`, а `slice=1` — ровную
нижнюю полусферу. **`at` остаётся центром исходного шара**, а не новым центром
габарита. `round` скругляет только образовавшуюся кромку и требует срез;
слишком большой радиус отклоняется до построения.

### Топология икосферы

```forma
треугольники = icosphere radius=40 mode=triangle divisions=0
квадраты = icosphere radius=40 mode=quad divisions=1
додекаэдр = icosphere radius=40 mode=pentagon divisions=0
сота = icosphere radius=40 mode=сота divisions=1
```

Русские синонимы: `треугольный`, `квадратный`, `пятиугольник`, `сота`,
`шестиугольник`, `hexagon`. Минимальный `divisions` теперь **0**, максимум 5.

| Режим | Уровень 0 | Уровень 1 | Уровень 2 | Уровень 3 |
|---|---:|---:|---:|---:|
| `triangle`, панелей | 20 | 80 | 320 | 1280 |
| `quad`, квадратов | 6 | 24 | 96 | 384 |
| `pentagon`/`сота`, панелей | 12 | 42 | 162 | 642 |
| из них пятиугольников | 12 | 12 | 12 | 12 |
| из них шестиугольников | 0 | 30 | 150 | 630 |

`quad` — куб-сфера: шесть квадратных сторон дробятся на сетку. `pentagon=0`
— додекаэдр из 12 пятиугольников. `сота` и более детальный `pentagon` —
двойственная сфера. По теореме Эйлера замкнутая сота обязана содержать 12
пятиугольников: сделать весь закрытый шар только из шестиугольников невозможно.
Поэтому режимы не подменяют пятиугольники треугольниками.

Ядро и GLB хранят треугольную поверхность: квадраты и многоугольники
триангулируются веером. Число логических панелей дополнительно передаётся в
`objects_payload().topology` и доступно отчёту для нейросети.

### Детализация эллипсоида

```forma
э = ellipsoid x=60 y=40 z=22 divisions=2
```

`divisions=0…5` даёт 20, 80, 320, 1280… треугольников. Это альтернатива
прежним `detail/segments`, а не дополнение к ним: два способа одновременно
отклоняются. Даже на нулевом уровне фактические полуоси нормируются к заданным
`x/y/z`, поэтому габарит остаётся `120×80×44` мм. Без `center` низ стоит на
`at.z`, как раньше.

Геометрию закрепляют **25 тестов `tests/test_v042.py`**: аналитические объёмы,
координаты колец и вершин, состав панелей, watertight/одно тело, сохранение
старого октаэдра и карточные поля. Четыре дополнительные проверки входят в
`--uistest`.

## 36. Непрерывные детали и границы инструментов (0.43)

### 36.1. Ручка-скоба с независимыми частями

```forma
ручка = handle length=160 height=34 diameter=10 post_shape=капсула bar_shape=брусок plates=да
без_площадок = handle length=160 height=34 diameter=10 post_shape=цилиндр bar_shape=капсула plates=нет at=[220,0,0]
```

`post_shape` задаёт обе стойки, `bar_shape` — только среднюю перекладину;
доступны `цилиндр`, `капсула`, `брусок`. Сочетания независимы, всего девять.
Капсульные стойки обрезаны по плоскости крепления и стоят плоским торцом.
Перекладина заканчивается внутри внешних габаритов стоек во всех режимах.
`plates=нет` убирает обе монтажные площадки и их отверстия одной операцией.

### 36.2. Завиток — труба, а не стопка дисков

```forma
завиток = swirl radius=40 height=64 coils=3 wire=8
тонкий = swirl radius=40 height=64 coils=3 wire=5 at=[120,0,0]
```

Центр трубы идёт по сужающейся пространственной спирали; радиус сечения
постепенно уменьшается к кончику. Получается один непрерывный объём без
отдельных ярусов и вырезанных канавок. `coils` — число витков, `wire` —
исходный диаметр трубы. Слишком толстая труба, при которой витки сливаются,
отклоняется с понятной подсказкой.

### 36.3. Лестница и ступени

```forma
лестница = ladder length=600 width=300 rail=овал rail_d=38 rung=цилиндр rung_d=30 rungs=4 tilt=0
марш = stairs steps=5 rise=16 run=30 width=100 shape=скруглённая round=3 inner=скруглённый inner_r=2 at=[0,400,0]
```

Овальная рейка — стадион в сечении: два полукруга и две **плоские** боковые
грани, а не вытянутый эллипсоид. Перекладины подрезаются по поверхности реек:
они не проходят сквозь них и не торчат наружу. `rung_d` не может быть больше
`rail_d`. Параметры `rail=` и `rung=` относятся к рейкам и перекладинам
лестницы и сохраняются в сценарии.

У ступеней нет скошенного режима. `shape=прямая|скруглённая` и `round`
относятся к наружным углам, а `inner=острый|скруглённый` и `inner_r` —
к внутренним углам между проступью и подступенком. Два радиуса независимы.

### 36.4. Рычаг, кнопка, люверс и косынка

```forma
рычаг = lever length=180 diameter=14 knob=шар knob_d=34 knob_h=70
кнопка = button smooth=1 at=[250,0,0]
люверс = grommet smooth=1 at=[320,0,0]
косынка = gusset leg=70 height=55 thickness=6 at=[380,0,0]
```

У рычага остаются наконечники `шар` и `цилиндр`; `knob=нет` удалён. Длина
`knob_h` меняет и цилиндр, и шар. Палка заканчивается внутри наконечника,
поэтому её плоский торец не виден на острие. `smooth=0…4` у кнопки и люверса —
настоящее сглаживание поверхности. Кнопка по-прежнему создаёт два объекта:
шляпку и гнездо. Косынка — точный прямой треугольник: шесть вершин, прямой
угол и одна чистая гипотенуза без вырезов.

### 36.5. Клинок: вся длина, а не только наконечник

```forma
катана = blade kind=катана length=700 curve=28 profile=суженный section=клин tip=киссаки
нож = blade kind=нож length=240 curve=0 profile=листовой section=плоский tip=закруглённое at=[0,150,0]
```

`profile=прямой|суженный|листовой` изменяет ширину и сечение по
всей длине. `section=линза|клин|плоский|алмаз` выбирает поперечный профиль; `tip` —
`острое|киссаки|закруглённое|тупое`. Пресеты `kind`: `катана`, `танто`,
`ятоган`, `стилет`, `двуручник`, `серп`, `нож`. `curve` — стрела изгиба в
миллиметрах: при длине 400 и `curve=20` середина смещена ровно на 20 мм,
а оба конца остаются на исходной оси; отрицательное значение гнёт в другую
сторону.

### 36.6. Сглаживание, бортики и полости

* `hemisphere wall=0` — сплошная полусфера; `wall>0` — чаша. Параметра
  `mode=миска` больше нет. Кромка остаётся горизонтальной.
* `smooth=0…4` работает у полуовала, арки, воронки, уголка и скобы. У скобы
  `shape=овал` даёт овальный U-профиль без отдельных команд «П» и «U».
* `воронка`, `полукапсула`, `plate` имеют `rim` и `rim_height`; у тарелки
  `depth` независимо меняет глубину. Бывший `cartridge` — только алиас
  полукапсулы, без режимов боеприпаса.
* `ingot` поддерживает скос, размер и смещение верха и сглаживание граней;
  `pie hole=…`, `bead slice/cut`, `torus_sector hole=…` создают
  настоящие отверстия и срезы.
* `star` сочетает `bevel`, `twist`, `blade`, `hole` и `wall`; полость `wall`
  доступна также `lightning`, `heart`, `horn`, `plus`. У `leaf kind=` пять
  контуров: `овал`, `липа`, `дуб`, `клен`, `заострённый`.
* `arrow` не имеет перьев; `head_width=width` убирает выступы наконечника.
  `yoke shape=капсулы|бруски`, `saw`, `screw`, `pulley grooves=…` и крюк без
  ушка используют те же правила точных размеров и замкнутости.

### 36.7. Ограниченные стрелки

У числовых полей карточек заданы конечные `min` и `max`. Кнопки «−» и «+»
ограничивают значение и на границе перестают его изменять. Это проверяется
выполнением `node tests/ui_bounds_test.js`; одного чтения разметки недостаточно.

## 37. Полосы, решётки и конструкционные формы (0.44)

### 37.1. Полоса: концы, кромки, контур и выемка

```forma
прямая = strip length=200 width=40 thickness=4 ends=прямоугольные
треугольная = strip length=180 width=36 thickness=3 ends=треугольные collapse_left=0.6 collapse_right=0.2 at=[0,120,0]
овальная = strip length=180 width=36 thickness=3 ends=овальные smooth=1 bend=45 at=[0,240,0]
```

`collapse_left` истончает кромку +Y, `collapse_right` — кромку −Y. Значение
0 оставляет полную толщину, 0.95 оставляет у кромки 5% толщины сердцевины.
Низ остаётся плоским. `smooth=0…4` — настоящее Loop-сглаживание замкнутой сетки.
`bend` — общий угол дуги в XZ, а не смещение одного конца.

```forma
эс = strip length=200 width=30 thickness=3 path=S curve=40
зигзаг = strip length=200 width=30 thickness=3 path=зигзаг curve=45 at=[0,140,0]
окно = strip length=180 width=50 thickness=4 recess=круг recess_size=20 at=[0,280,0]
прямоугольное = strip length=180 width=50 thickness=4 recess=прямоугольник recess_size=16 recess_length=30 at=[0,400,0]
квадратное = strip length=180 width=50 thickness=4 recess=квадрат recess_size=18 at=[0,520,0]
треугольное = strip length=180 width=50 thickness=4 recess=треугольник recess_size=18 at=[0,640,0]
```

Выемка проходит по всей толщине и доступна при `path=прямая` и
`path_z=прямая`: у криволинейной полосы центральная вертикальная проекция не
обязана пересекать материал одинаково. `recess_size` — диаметр
круга, ширина прямоугольника или сторона квадрата/равностороннего треугольника;
у прямоугольника `recess_length` независимо задаёт длину по X.

### 37.2. Решётки со сквозными ячейками

```forma
планки = grating width=180 height=100 depth=4 pattern=планки bars=7 bar=3 frame=6
клетка = grating width=180 height=120 depth=4 pattern=клетка cols=5 rows=4 bar=3 frame=6 at=[0,180,0]
соты = grating width=200 height=140 depth=4 pattern=соты cell=22 bar=3 frame=6 at=[0,400,0]
```

Отверстия не нарисованы и не являются тёмными вставками: каждая ячейка вычтена
по `depth`. `bar` — толщина внутренних реек, `frame` — наружной рамки. Слишком
толстые рейки, не оставляющие просветов, отклоняются с подсказкой. `cell` —
размер соты между параллельными гранями. Кроме показанных планок, клетки и сот
есть `pattern=круги` и `pattern=треугольники`; их примеры даны в §40.2.

### 37.3. Шипы на поверхности существующего объекта

```forma
круглые = box size=[120,80,4]
круглые = spikes [круглые] surface=верх cols=4 rows=3 height=28 base_d=12 tip_d=0.8 sides=24
острые = box size=[100,60,3] at=[0,140,0]
острые = spikes [острые] surface=верх cols=3 rows=2 height=24 base_d=10 tip_d=0 sides=3
наклонные = box size=[120,80,4] at=[0,300,0]
наклонные = spikes [наклонные] surface=верх cols=4 rows=3 height=26 lean=15 direction=90
```

`spikes` — инструмент над уже созданным объектом, а не самостоятельная
площадка: размеры и положение основания задаёт исходное тело. `height` — высота
шипа над исходной поверхностью. `tip_d=0` даёт остриё, положительное значение —
плоскую верхушку. `sides=3` создаёт треугольные шипы, большие значения
приближают круг. `lean` и `direction` задают общий наклон и его азимут от +X.
Инструмент также работает на цилиндре, сфере и другой неплоской поверхности;
результат соединяется с исходным телом.

### 37.4. Колонна вместо мебельной ножки

```forma
ровная = column height=180 width=42 form=ровная section=цилиндр base_size=72 base_h=12 rim=8 rim_h=10
конус = column height=160 width=40 form=конус taper=0.5 section=брусок depth=30 at=[140,0,0]
песочные = column height=180 width=42 form=песочные waist=0.55 smooth=1 at=[280,0,0]
```

`height` включает площадку и бортик. `form=песочные` задаёт параболическое
сечение: в середине стержня размер равен `width*waist`, у концов — `width`.
У конуса верх имеет долю `1-taper` от основания; отрицательный `taper`
расширяет колонну кверху. `base_size=0` убирает нижнюю площадку, но `base_h`
по-прежнему задаёт высоту нижней зоны. `rim=0` убирает только вылет бортика,
а `rim_h` независимо сохраняет высоту верхней зоны.

### 37.5. Дуговая треугольная призма

```forma
палатка = arc_prism a=100 b=90 c=90 height=120 arc_a=0 arc_b=-16 arc_c=-16
парус = arc_prism a=110 b=80 c=75 height=90 arc_a=12 arc_b=-10 arc_c=0 at=[0,180,0]
обычная = arc_prism a=100 b=90 c=90 height=120 arc_a=0 arc_b=0 arc_c=0 at=[0,360,0]
```

Сторона `a` — нижняя по X, `b` — левая от начала основания к вершине, `c` —
правая от вершины к концу основания. Дуги являются стрелами парабол в мм:
положительное значение выгибает сторону наружу, отрицательное — внутрь, ноль
оставляет плоскость. Три значения независимы, поэтому можно смешивать вогнутые,
выпуклые и плоские стороны. При нулевых дугах объём совпадает с `tri_prism`.

### 37.6. Вогнутые/выпуклые круг и овал, три отверстия кубика

```forma
плоский = disc diameter=100 thickness=6 top=плоская
чаша = disc diameter=100 thickness=8 top=вогнутая sag=3 at=[140,0,0]
купол = oval width=160 length=100 thickness=6 top=выпуклая sag=4 at=[340,0,0]
```

Верхняя поверхность параболическая, низ плоский. `sag` — стрела в мм. У
выпуклого варианта общая высота равна `thickness+sag`, у вогнутого кромка
остаётся на высоте `thickness`. Для кривого верха используют `round=0`;
скругление кромки относится к `top=плоская`.

```forma
круглое = cube_hole size=[40,40,40] hole=16 hole_shape=круг axis=z
квадратное = cube_hole size=[45,45,35] hole=15 hole_shape=квадрат axis=x at=[100,0,0]
треугольное = cube_hole size=[50,45,40] hole=18 hole_shape=треугольник axis=y at=[200,0,0]
```

Для квадрата `hole` — сторона, для треугольника — диаметр описанной окружности.
Канал всегда сквозной и проходит по выбранной оси.

### 37.7. Труба без координат и старый path

```forma
прямая = pipe length=180 diameter=24 wall=2
плавная = pipe length=220 angle=90 radius=70 joint=плавный diameter=24 wall=2 at=[180,0,0]
острая = pipe length=180 angle=60 joint=острый diameter=20 wall=1.5 at=[360,0,0]
```

`length` — развёрнутая длина центральной линии. Плавный сгиб использует дугу
`radius`, острый — митру между двумя равными прямыми участками. Знак `angle`
выбирает сторону в XZ; доступны углы −180…180°. Радиус должен оставлять
внутреннюю сторону сгиба, а дуга должна помещаться в `length`.

```forma
старая = pipe path=[[0,0,0],[0,0,150],[90,0,150]] diameter=32 wall=2
```

Явный `path` включает прежний режим и имеет приоритет над простыми настройками.
Старые проекты менять не нужно.

### 37.8. Профиль 2020: пазы, рейки и осевая форма

```forma
прямоугольный = profile2020 length=300 size=20 slot=6 channel=9 depth=4 groove=прямоугольная rail=скруглённая rail_r=1.2 bore=5 bore_shape=круг
треугольный = profile2020 length=160 size=24 groove=треугольная rail=фаска rail_r=1.5 bore=6 bore_shape=треугольник at=[60,0,0]
овальный = profile2020 length=160 size=24 groove=овальная rail=прямая bore=7 bore_shape=шестигранник at=[120,0,0]
квадратная_ось = profile2020 length=120 size=20 bore=5 bore_shape=квадрат at=[180,0,0]
```

Четыре паза открыты наружу по ±X/±Y и идут по всей длине +Z. `slot` — узкая
горловина, `channel` — ширина внутреннего углубления, `depth` — полная глубина
от наружной поверхности. `rail` меняет угловые рейки, `rail_r` — радиус или
фаску. `bore` — диаметр описанной окружности осевого отверстия; ноль делает
профиль без центрального канала. Возвращён только этот конструкционный профиль,
не остальные удалённые детали.

## 38. Полости, рельефные грани и сгибаемый лист (0.45)

### 38.1. Непрерывная зеркальность и соты

```forma
пластина = box size=[90,60,24] round=3
цвет пластина #c6d2df mirror=0.35
сотовая = icosphere radius=42 mode=сота divisions=1 at=[150,0,0]
```

`mirror` принимает любое значение 0…1, а не только да/нет. Оно сохраняется в
материале объекта и не создаёт лишнее зеркальное тело. У сот проверяются не
только герметичность и габарит, но и фактические пяти-/шестиугольные панели.

### 38.2. Рамки с Г-каналом, линией и угловым окном

```forma
угол = cavity_frame size=[120,100] depth=8 cavity=Г cavity_size=[60,50] line_width=6 margin=9 corner=право_верх round=1
круг = cavity_frame outer=круг size=[120,120] depth=8 cavity=квадрат cavity_size=[22,22] margin=10
щель = cavity_frame outer=круг size=[120,120] depth=8 cavity=линия cavity_size=[70,6]
овал = cavity_frame size=[120,100] depth=8 cavity=овал cavity_size=[70,16]
```

Полость всегда сквозная. У стоящей рамки она проходит по Y, у плашмя — по Z.
`corner` допускает `право_верх`, `лево_верх`, `право_низ`, `лево_низ`.
Внешний `outer` не подменяет выбранную полость: `квадрат` остаётся
прямоугольным по `cavity_size`, `линия` — прямоугольным пазом, `овал` — таким
же пазом с полукруглыми концами, а `круг` задаёт эллипс по двум размерам.
Не увеличивайте `margin`, чтобы запихнуть слишком большую полость: уменьшите
`cavity_size` или увеличьте наружный `size`.

### 38.3. Выпуклые/вогнутые грани и точный срез угла

```forma
выпуклый = face_box size=[80,80,70] mode=выпуклый profile=линза relief=6 margin=7
вогнутый = face_box size=[80,80,70] mode=вогнутый profile=трапеция relief=5 margin=8 taper=0.4
один = face_box size=[80,80,80] corner_cut=18 corners=один corner=перед_право_верх
верх = face_box size=[80,80,80] corner_cut=12 corners=верх
все = face_box size=[80,80,80] corner_cut=12 corners=все
```

До пересечения срезов один угол снимает тетраэдр объёмом `corner_cut³/6`.
Это позволяет проверить не только вид, но и точный объём. `faces=[верх,перед]`
ограничивает рельеф двумя гранями; `profile=квадрат` даёт прямую прямоугольную
врезку/площадку, а не линзу. Срезы выполняются после рельефа.

### 38.4. Одиночный сгиб, гармошка и диагональ

```forma
один = fold_sheet width=120 length=200 thickness=1.2 parts=2 angle=110 gap=2 offset=0.5
гармошка = fold_sheet width=120 length=300 thickness=1.2 parts=5 angle=120 gap=1 sharp=0.4
диагональ = fold_sheet width=120 length=180 thickness=1.2 parts=2 axis=диагональ angle=90
своя_линия = fold_sheet width=120 length=180 parts=2 direction=30 angle=80
```

`angle=1` почти не гнёт исходный лист, `angle=180` складывает части обратно.
`sharp=0` оставляет больше дуговых сегментов и округлый радиус, `sharp=1`
приближает пресс-биговое ребро. Если сгибы не помещаются, уменьшите
`gap/angle/parts` или увеличьте длину. Старые `sheet` и `fold` сохранены.

### 38.5. Отверстия по трём осям и плоские формочки

```forma
блок = cube_hole size=[70,60,50] round=0 hole_x=12 hole_x_shape=круг hole_y=12 hole_y_shape=квадрат hole_z=18 hole_z_shape=овал oval_aspect=2
яйцо_форма = egg height=70 diameter=50 flat=да depth=6 wall=3 plane=плашмя
капля_форма = drop radius=18 height=55 flat=да depth=6 wall=2.5 plane=плашмя
стрелка_форма = arrow length=130 wall=3 round=0
пила = saw diameter=120 teeth=24 hole=0
```

Отверстия удалены из обычного `box`; центральные каналы выполняет
`cube_hole`. Каждое отверстие вычитается независимо, поэтому пересечения
каналов — настоящая общая пустота. Для овала первый размер `hole_*` — общая длина
капсулы, `oval_aspect=1` даёт круг. Без `flat=да` яйцо и капля остаются
объёмными; `wall=0` оставляет плоский силуэт сплошным.

### 38.6. Ветви, крепёж, ручка и завиток

```forma
т = tee arm=100 bar=20 stem=20 leg=60 shape=капсулы round=1
т_овал = tee arm=100 bar=20 stem=20 leg=60 shape=овалы round=1
ы = yoke height=110 spread=60 arm=14 shape=бруски smooth=1
саморез = screw d=4 length=25 head=полукруг drive=звезда neck=0
ручка = handle length=160 height=34 diameter=10 posts=2 post_mode=сквозь post_top=6 bar_shape=капсула post_shape=капсула
завиток = swirl radius=30 height=70 coils=3 wire=24 root_d=6 merge=да base=да
косынка = gusset leg=70 height=55 thickness=6 shape=горка notch=8 notch_width=24
```

`post_top` измеряется от фактического верха перекладины, а не от её оси.
У завитка `merge=да` необходим для касающихся витков; `base=да` добавляет
плоскую площадку высотой `wire`, а `root_d` независимо сужает начало витка.
У Т и Y `shape=овалы` означает цельные эллиптические ветви, `капсулы` — прямые
стороны и полукруглые торцы. У самореза Torx — шесть округлых лопастей,
слепой карман не пробивает головку насквозь.

## 39. Точные поверхностные инструменты (0.46)

### 39.1. Яма и отверстие с известным дном

```forma
ямки = box size=[100,80,30]
ямки = porous [ямки] mode=поры size=5 depth=2.5 count=22 smooth=.35 uneven=.12 rough=.08 seed=3
отверстия = box size=[100,80,30]
отверстия = porous [отверстия] mode=отверстия width=10 depth=7 count=18 smooth=.25 seed=8
```

`size` — радиус, `width` — диаметр и перекрывает `size`. Для сферической ямы
радиус сферы вычисляется как `R=(r²+d²)/(2d)`; у цилиндра дно плоское.
`smooth` закругляет переход, `uneven` меняет кромку, `rough` — стенки.
Центры разводятся минимум на два радиуса: ямы не сливаются, а невозможный
`count` отклоняется с подсказкой. Одинаковый seed повторяет и раскладку, и
неровности.

### 39.2. Трещины на реальной поверхности

```forma
удар = box size=[125,100,16]
удар = crack [удар] mode=удар at=[0,0,16] dir=[0,0,1] count=8 radius=43 width=2 depth=1.2 seed=4
разлом = box size=[125,100,16]
разлом = crack [разлом] mode=разлом count=5 radius=48 width=2 depth=1.2 seed=9
дерево = box size=[135,90,16]
дерево = crack [дерево] mode=дерево count=13 width=1.7 depth=.8 angle=0 seed=2
```

`at+dir` выбирают грань, лучи находят на ней точки линий, затем исходная сетка
разбивается и вдавливается. Если линии не попали на тело, команда сообщает об
этом, а не возвращает неизменённый объект.

### 39.3. Наружная стенка рукава

```forma
наружная = cylinder radius=40 height=90 segments=64
внутренняя = cylinder radius=28 height=90 segments=64
рукав = difference [наружная,внутренняя]
delete наружная
delete внутренняя
рукав = wrinkle [рукав] mode=радиус amp=2.5 freq=12 surface=наружная
```

Для обеих стенок используйте `surface=вся`. У режимов `радиус` и `трещины`
деформация плавно затухает на последних 8 % высоты у каждого торца: плоский
торец и кромка не превращаются в звезду или зубцы.

### 39.4. Равная гармошка и сгиб через угол

```forma
лист = sheet width=105 length=240 thickness=1
гармошка = fold [лист] parts=5 angle=150 gap=.8 sharp=.15 axis=x
квадрат = sheet width=120 length=120 thickness=1
угол = сгиб [квадрат] at=[0,0,1] dir=45 angle=120 gap=.5
```

Из исходной длины сначала вычитаются все дуги, затем остаток делится поровну
между полотнищами. `сгиб` использует ту же непрерывную дугу и работает с
собственной сеткой листа, включая диагональ и многократную гармошку.

### 39.5. Гребень и канавка без добавленной детали

```forma
гребень = sheet width=125 length=105 thickness=1
гребень = складка [гребень] from=[-52,0,1] to=[52,0,1] r=6 depth=5 mode=гребень taper=.3
канавка = box size=[120,90,30]
канавка = складка [канавка] from=[-48,0,30] to=[48,0,30] r=6 depth=4 mode=канавка taper=.3
```

На тонком листе обе стороны движутся вместе и сохраняют толщину. На объёмном
теле смещение идёт по нормалям: гребень поднимается, канавка вдавливается.
`r` — полуширина, `taper` плавно сводит профиль на концах.

### 39.6. Вафля отличается от рифления

```forma
рифление = sheet width=105 length=145 thickness=1
рифление = corrugate [рифление] mode=рифление step=18 amp=5 angle=0
вафля = sheet width=105 length=145 thickness=1
вафля = corrugate [вафля] mode=вафля step=18 amp=5 angle=0
```

Рифление зависит только от одной координаты, вафля — от произведения волн по
двум координатам. При одинаковых `step` и `amp` это разные сетки и разные
силуэты, а не два названия одного узора.

### 39.7. Наращивание и встроенный рельеф

```forma
основа = cylinder radius=43 height=28 segments=56
иголки = hair [основа] style=иголки surface=верх count=65 length=22 thick=1.6 spread=.18 seed=4
рельеф = box size=[125,100,12]
рельеф = relief [рельеф] depth=2 mode=плоскость
```

`hair` без объекта выдаёт ошибку. Корни входят в основу, результат остаётся
одним телом. `relief` без `image` всегда использует встроенную карту.

## 40. Профили, внутренние полости и лопасть (0.47)

### 40.1. Конус, цилиндр, пирамида и кольцо

```forma
прямой = cone radius=45 height=90 form=прямой
горка = cone radius=45 height=90 form=парабола
холмик = cone radius=45 height=90 form=холмик
полый = cone radius=45 height=90 form=парабола wall=4 smooth=1
стакан = cylinder radius=40 height=90 wall=5 cavity=верх
пирамида = pyramid sides=4 radius=55 height=90 wall=5
кольцо = ring diameter=30 width=12 thickness=6 cavity=2 round=0
```

У конуса полость открыта снизу, вершина закрыта. У цилиндра `cavity=верх|низ`
выбирает открытый торец и оставляет противоположное дно. Пирамида сохраняет
вершину и открывает полость только у основания. `ring cavity` — закрытый канал
внутри материала обода; центральное отверстие кольца от него не зависит.

### 40.2. Подкова, ячейки и центральные отверстия

```forma
подкова = strip length=200 width=14 thickness=5 path=подкова curve=40
круги = grating width=180 height=120 pattern=круги cols=6 rows=4 bar=3
треугольники = grating width=180 height=120 pattern=треугольники cols=6 rows=4 bar=3
окно = cavity_frame size=[110,90] cavity=квадрат cavity_size=[45,35]
овал = cavity_frame outer=круг size=[110,90] cavity=овал cavity_size=[65,20] line_width=12
блок = cube_hole size=[90,70,60] hole=24 axis=z
```

У подковы `length` — длина центральной линии, `curve` — радиус. У прямой
полосы `path_z` добавляет независимый контур в XZ, а `recess` — ровное
центральное отверстие. Обычный `box` отверстий больше не имеет.

### 40.3. Локальные кромки и радиусные рёбра

```forma
круг = disc diameter=120 thickness=10 edge=2 edge_band=18
овал = oval width=140 length=90 thickness=10 edge=2 edge_band=15
сектор = pie diameter=130 angle=110 thickness=10 edge=2 edge_band=18
полукруг = полуовал width=130 height=80 thickness=10 edge=2 edge_band=16
арка = arch radius=80 width=22 thickness=12 edge=3 edge_band=8
пирамида = pyramid sides=4 radius=60 height=90 smooth=2
```

истончаются. У пирамиды и колонны `smooth` скругляет рёбра, не стягивая широкие

### 40.4. Овалы, капсулы и полые витки

```forma
т = tee arm=90 bar=20 stem=22 leg=60 shape=капсулы round=2
т_овал = tee arm=90 bar=20 stem=22 leg=60 shape=овалы round=2
ы = yoke height=110 spread=64 arm=16 shape=овалы
инь = yin_yang diameter=120 thick=16 form=объёмная side=левый
пружина = spring diameter=30 wire=6 hole=2.5 turns=4 pitch=9
червяк = worm_shaft length=90 diameter=30 pitch=12 depth=5 profile=круглый bore=4 channel=2
```

Эллиптические ветви не являются капсулами с другой сеткой: это цельные эллипсы.
У капсул прямые стороны и полукруглые торцы. Основная форма инь-ян объёмная;
`form=плоская` возвращает пластину. `spring hole` идёт по всей винтовой длине,
`worm channel` — внутри червячного выступа, `bore` — по оси вала.

### 40.5. Линзы рычага, крышка люверса и зоны колонны

```forma
выпуклый = lever length=180 diameter=14 knob=линза knob_d=42 knob_h=45
вогнутый = lever length=180 diameter=14 knob=вогнутая knob_d=42 knob_h=45
ровно = grommet diameter=18 height=12 wall=2 flange=4 fill=ровно fill_h=2
купол = grommet diameter=18 height=12 wall=2 flange=4 fill=выпуклая fill_h=4
чаша = grommet diameter=18 height=12 wall=2 flange=4 fill=вогнутая fill_h=4
колонна = column height=180 width=42 form=конус taper=-0.6 base_size=0 base_h=20 rim=0 rim_h=12
```

У вогнутого рычага чаша только снаружи, стык выпуклый, палка подрезана. У
люверса крышка и втулка остаются одним телом. У колонны `base_size=0` удаляет
только площадку: `base_h` остаётся нижней зоной стержня, а `rim_h` задаёт верхнюю
зону даже при нулевом вылете `rim`.

панель = box size=[120,80,12]
панель = spikes [панель] surface=верх cols=4 rows=3 height=28 base_d=12 tip_d=.8
лопасть = turbine_blade length=180 chord=70 root_chord=20 tip_chord=42 thick=7 tip_thick=2.5 camber=.09 stagger=25 twist=55 sweep=28 root_h=12

У косынки шесть явных режимов: три контура и независимый вариант `*_с_пазом`.

## 41. Детальные вмятины, сгибы и швейная пуговица (дополнение 0.47)

### 41.1. Детализация вмятины и слепая полость призмы

```forma
вмятина = face_box size=[60,50,40] mode=вогнутый profile=линза relief=8 margin=5 faces=верх detail=5
полая = prism sides=6 radius=35 height=60 wall=3 cavity=верх cavity_depth=40
снизу = prism sides=5 radius=35 r2=25 height=60 top_offset=[8,4] twist=20 wall=3 cavity=низ cavity_depth=45
```

`face_box detail=0…5` меняет число радиальных колец именно на кривых гранях,
а не размер и не рельеф в миллиметрах. Концентрическая сетка сходится к центру
вмятины, поэтому диагонали исходного четырёхугольника не проходят через неё.

У призмы `wall` — одновременно толщина стенок и минимальное оставшееся дно.
`cavity=верх|низ` выбирает открытую сторону, `cavity_depth` не может превышать
`height-wall`. Внутренний контур получается настоящим смещением многоугольника
и следует `r2`, `top_scale`, `top_offset` и `twist`; это не вертикальный
цилиндр внутри произвольной призмы.

### 41.2. Сплошная труба и четыре профиля сгиба

```forma
труба = pipe diameter=20 wall=2 length=100 angle=75 radius=45
стержень = pipe diameter=20 wall=2 hole=нет length=100 angle=75 radius=45
круг = fold_sheet width=90 length=180 thickness=1.2 parts=3 angle=115 joint=круг
широкая = fold_sheet width=90 length=180 thickness=1.2 parts=3 angle=115 joint=широкая
сплайн = fold_sheet width=90 length=180 thickness=1.2 parts=3 angle=115 joint=сплайн
фаска = fold_sheet width=90 length=180 thickness=1.2 parts=3 angle=115 joint=фаска
```

`pipe hole=нет` отключает весь внутренний канал, а не закрывает только торцы.
Наружный путь и габарит сохраняются, объём увеличивается; параметр `wall` в
сплошном режиме не влияет на геометрию.

Профиль `joint` работает также у `fold` и `сгиб`. `круг` — обычная дуга;
`широкая` увеличивает её радиус в 2,5 раза; `сплайн` плавно сводит кривизну к
нулю на входе и выходе; `фаска` соединяет две дуги коротким прямым участком.
`sharp` по-прежнему управляет радиусом, а `gap` — просветом. У обычной круговой
дуги даже при `sharp=1` остаётся не меньше восьми сегментов вместо прежних трёх
угловатых скачков. Все варианты деформируют исходную замкнутую сетку и остаются
одним телом.

### 41.3. Вогнутые дуги круга и овала

```forma
плоская = disc diameter=100 thickness=5 outline=вогнутая4 indent=.35
купол = disc diameter=100 thickness=6 outline=вогнутая4 indent=.35 top=выпуклая sag=5 edge=2 edge_band=12
чаша = oval width=160 length=100 thickness=8 outline=вогнутая4 indent=.3 top=вогнутая sag=3 edge=3 edge_band=12
```

`outline=вогнутая4` сохраняет четыре кончика на осях и прогибает стороны между
ними внутрь. Это не ромб: при `indent>0` показатель дуги больше двух, а сами
точки контура не коллинеарны. `indent=0` возвращает обычную окружность/эллипс.
Для купола и чаши верх строится концентрическими кольцами фактического контура;
`edge/edge_band` измеряют расстояние до него, а не до воображаемого эллипса.
У такого контура используйте `edge`, а не `round`.

### 41.4. Полоса в форме J

```forma
крючок = strip length=180 width=10 thickness=4 path=J curve=24
```

J состоит из длинной ноги, полукруга и короткого подъёма с другой стороны.
Длины прямых частей относятся как 80 % к 20 % после вычитания длины дуги.
`length` — полная длина центральной линии, поэтому объём прямоугольного сечения
остаётся примерно `length·width·thickness`; `curve` — радиус крюка. Нужно
`length > π·curve + 2` мм. Путь лежит в XY, толщина идёт по Z.

### 41.5. Пуговица с лицевыми отверстиями и односторонним бортиком

```forma
две = sewing_button diameter=30 thickness=3 holes=2 hole_d=3.5 pitch=9 rim_side=нет top=плоская
четыре = sewing_button diameter=30 thickness=4 holes=4 hole_d=3 pitch=8 rim_side=верх rim=2 rim_h=1 top=вогнутая sag=1
выпуклая = sewing_button diameter=30 thickness=4 holes=0 rim_side=низ rim=2 rim_h=1 top=выпуклая sag=4
```

`sewing_button` и псевдоним `пуговица` создают отдельный примитив одним телом;
прежняя `button` из двух объектов сохранена. При `kind=отверстия` параметр
`holes` принимает целые значения 0…8. Одно отверстие стоит в центре, два — на
расстоянии `pitch`, четыре — в квадрате со стороной `pitch`; три и пять–восемь
равномерно расположены по окружности диаметром `pitch`. Все каналы сквозные,
что проверяется родом тела, а не только видимой отметкой на лице.

`hole_d` — диаметр каждого канала. Слишком большой `pitch/hole_d`, задевающий
край или верхний бортик, отклоняется с подсказкой. `rim_side=верх|низ` создаёт
только один бортик, `нет` убирает его; `rim=0` или `rim_h=0` также отключает
ободок. `top` и `sag` задают плоское лицо, купол или чашу. У чаши `sag` должен
оставлять материал над плоским низом.

### 41.6. Заднее ушко и перфорированная трапеция

```forma
ушко = sewing_button diameter=30 thickness=4 kind=ушко top=выпуклая sag=4 eye_d=6 shank_w=10 shank_h=11 shank_thick=2.2 rim_side=нет
трапеция = sewing_button diameter=30 thickness=4 kind=трапеция top=выпуклая sag=4 eye_d=6 shank_w=11 shank_h=11 shank_thick=2.2 rim_side=нет
```

Оба режима заменяют лицевые отверстия одним задним креплением. Ушко имеет
округлый низ, трапеция расширяется книзу; отверстие проходит по Y и остаётся
сквозным после объединения с диском. `eye_d` — диаметр канала, `shank_w` —
наружная ширина, `shank_h` — высота ниже диска, `shank_thick` — толщина по Y.
Размеры проверяются так, чтобы вокруг канала оставался материал и крепление не
распадалось на отдельные детали.
