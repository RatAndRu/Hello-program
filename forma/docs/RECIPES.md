# РЕЦЕПТЫ КОМАНД — копируйте в окно сценария

Всё в миллиметрах, ось Z — вверх. Каждая строка — одна команда.
Вставляйте блок целиком и нажимайте «Собрать» (Ctrl+Enter).

## 0.1 Мышь, «Загрузки» и свои текстуры (новое в 0.6)

**Мышь в окне модели**

* левая кнопка — вращать, колесо — приблизить, **правая кнопка — двигать сцену**;
* двойной клик — вернуть общий вид;
* режим «выбор»: **левая кнопка тянет рамку**, средняя вращает, правая двигает;
  Shift добавляет область к уже выбранным, Ctrl+клик по области — убрать её.

**Куда сохраняются файлы.**
Кнопки экспорта и «сохранить» пишут готовые файлы в папку **«Загрузки»**
(Windows: `C:\Users\<имя>\Downloads`). Адрес показан во всплывающем сообщении.
Внутренние копии для окна лежат в `%APPDATA%\Forma3D\exports`.

**Своя текстура** — узор и два цвета прямо в сценарии:

```
texture кружка kind=своя pattern=полосы color1=#c0504d color2=#f2e6d9 scale=1.2
texture ваза kind=своя pattern=камень color1=#6b7f8c color2=#e9e2d4 scale=2
texture кузов kind=своя pattern=волны color1=#1f6f8b color2=#d7e6ea
```

Узоры: `полосы`, `клетка`, `волны`, `градиент`, `шум`, `камень`, `точки`, `сетка`.
В панели материала выберите «своя…» и нажмите «Создать свою текстуру» —
та же строка появится в сценарии.

**Новые проверки и инструменты**

```
# готовые детали для примеров ниже
корпус = cylinder radius=34 height=95 r2=40
полость = cylinder radius=30 height=89 r2=36
полость = translate [полость] offset=[0,0,6]
кружка = difference [корпус, полость]
шестерня = gear teeth=20 module=2 thickness=8 bore=8
сфера = sphere radius=30 segments=48

check кружка wall_min 3..5          # самая тонкая стенка + её координата
check шестерня sharp_edge 95        # самое острое ребро, в градусах
check сфера tri_quality 1           # доля «игольчатых» треугольников, %

# сварить вершины и убрать мусор у готовой детали
чистая = clean [сфера]
```

Из консоли: `forma diff старый.forma новый.forma`, `forma doctor`,
`forma build модель.forma --strict` (код 3, если проверка не выполнена),
`--json`, `--digest`, `--trace журнал.jsonl`. Экспорт: `--format 3mf`.

## 0.4 Кромки: скругление и фаска (новое в 0.7)

**Скруглить наружные рёбра (радиус 3 мм, габарит не меняется):**

```
плита = box size=[150,75,10]
плита = fillet [плита] radius=3 edges=convex
check плита size 149.7..150.3 74.7..75.3 9.7..10.3
```

**Скруглить внутренний стык** (например, дно полости или угол буквы «Г»):

```
а = box size=[90,30,30] at=[-30,0,0]
б = box size=[30,30,80] at=[15,0,0]
угол = union [а, б]
угол = fillet [угол] radius=6 edges=concave
```

**Скруглить всё сразу** (сначала вогнутые, потом выпуклые — так считает быстрее):

```
корпус = box size=[120,60,20]
корпус = fillet [корпус] radius=5 edges=all
```

**Плоская фаска 45°** (ширина 2 мм, снимает кромку без радиуса):

```
плита = box size=[150,75,10]
плита = chamfer [плита] width=2 edges=convex
```

Параметры: `radius` / `width` — в миллиметрах, `edges` — `convex`, `concave`
или `all`, `segments` у `fillet` — качество (12 по умолчанию: без тонких
треугольников; 24–40 — глаже, но появляются вытянутые треугольники).
Если объект тяжелее 12 000 треугольников, сначала `simplify [объект] tolerance=0.2`.

**Математическая поверхность** (поле считается массивами, поэтому быстро):

```
капля = from_sdf expression="smin(sd_sphere(x,y,z-40,30), sd_sphere(x,y,z-95,20), 12)" bounds=[-40,-40,-5,40,40,120] resolution=1.5
```

## 8. Лофт: плавный переход между контурами

```
# sections — контуры [[x,y], …], positions — где каждый контур стоит по оси X
корпус = loft sections=[[[-60,-40],[-70,20],[-40,60],[40,60],[70,20],[60,-40]],[[-40,-30],[-50,15],[-25,45],[25,45],[50,15],[40,-30]]] positions=[-160,160] axis=x smooth=3
check корпус watertight
check корпус size 310..330 130..150 110..130
```

Контуров может быть сколько угодно: `loft` соединяет их по порядку, `positions`
задаёт места по оси, `smooth` — плавность перехода, `profile_smooth` — сглаживание
самих контуров. Тот же приём, но на четырёх контурах и с арками, собран в примере
«Кузов машины»: там лофт — только первая строка, остальное — вычитание арок,
пересечение с зонами стёкол и `scale` на 0,3 % для зазора.

> Целиком — пример «Кузов машины»: 72 000 треугольников, 4 колеса, стёкла, швы дверей.

Красить можно и кистью в окне: выделите деталь, нажмите «Кисть» и ведите
мышью с зажатой кнопкой — за один мазок красится целая область, а не один
полигон. При отпускании в сценарий дописывается одна команда `paint`.

```
check кружка watertight              # покраска не ломает тело
screw d=5 length=9 head=полукруг     # три вида головки: потай, полукруг, шестигранник
```

Проверки сборки (0.18): `check деталь gap другая_деталь 0` — детали должны
касаться, а не висеть; `check деталь parts 1` — тело не распалось на куски.

## 13. Сопряжения: деталь на место отношением

Сопряжение — это ограничение сборки, как mates в SolidWorks/Fusion. Геометрия
детали не меняется: программа только переносит её (или поворачивает) так, чтобы
выполнилось условие, и запоминает связь.

```
# плоскость к плоскости: низ детали встаёт на верх основания (+ отступ)
плитка = box size=[60, 60, 10] at=[0, 0, 200]
сопряжение плитка основание type=плоскость axis=z offset=0

# ось: деталь центруется по другой в двух поперечных осях
шайба = cylinder radius=20 height=4 at=[300, 90, 200]
сопряжение шайба втулка type=ось axis=z

# паз-рейка: центруется по рейке и садится на её верхнюю грань
каретка = box size=[90, 70, 40] at=[250, 0, 300]
сопряжение каретка рейка type=паз axis=y

# зазор: ровно 3 мм между деталями (по кратчайшему расстоянию)
сопряжение шайба плита type=зазор offset=3

# точка: точка детали попадает в заданное место
шильдик = box size=[84, 3, 30] at=[0, 0, 600]
сопряжение шильдик основание type=точка point=[0, 0, 600] to=[-80, -78, 14]

# петля: поворот вокруг оси через точку (дверная петля)
сопряжение дверь корпус type=петля axis=z point=[-70, 80, 100] angle=-28
```

Что запоминается и проверяется:

```
check рейка связь          # остаток 0 мм — связь держится
check дверь связь 5        # для петли допуск можно задать: 5 мм
```

Остаток (residual) — на сколько деталь ушла от условия. После `translate`,
`rotate` или правки размеров `check … связь` пересчитывает его заново и
краснеет, если связь разъехалась.

Где смотреть в окне: вкладка **«Связи»** — мастер зазоров. Он считает точные
расстояния между телами и показывает сборки, висящие детали и щели; кнопка
«связать» дописывает `сопряжение` в сценарий.

> Целиком — пример `examples/mates.forma`: 7 связей всех видов, 10 проверок,
> дверь на петле и колесо на валу.

## 14. Приёмы 0.21: настройки, принцип отбора и что осталось за кадром

**Что изменилось в «Инструментах»**

* у каждого приёма появились **поля**, как у фигур: меняете число — предпросмотр
  сценария под карточкой пересчитывается сразу, вставляется уже готовый текст;
* **«Сечение, проба и паспорт» разведены на три карточки.** Это три разных
  вопроса к детали (`section` — контур разреза, `probe` — есть ли материал в
  точке, `passport` — габарит, объём, масса, герметичность), и одна карточка
  на три команды только путала;
* **«Отверстия сеткой»** получили поле **сдвиг**: сетка смещается по детали
  (`holes … offset=[12,-8]`), а не только стоит по центру;
* **«Накатка»** получила число канавок и глубину (было жёстко `count=24 depth=1`);
* **«Резьба: болт» убрана.** Это был однострочник, дублирующий команду
  `thread`; карточка самой команды с параметрами есть в разделе «Все команды»;
* добавлены приёмы, которых не хватало: **«Корпус с полостью»** (`shell`),
  **«Зеркальная пара»** (`mirror_copy`), **«Сечение»**, **«Проба материала»**,
  **«Паспорт детали»**, **«Надпись»**.

**Принцип отбора: почему приёмов 17, а команд 111**

1. **Приём — это сценарий, а не команда.** Он решает задачу целиком: делает
   заготовку, обрабатывает её и красит. Если для задачи хватает одной команды,
   приём не нужен — за это отвечает карточка команды в «Все команды».
2. **У приёма должны быть осмысленные поля.** Если параметр нечего менять
   (или он всегда один и тот же), это не приём, а демонстрация.
3. **Приём обязан собираться.** Все 17 проверены сборкой со значениями по
   умолчанию и с изменёнными полями (сдвиг сетки, снятая ручка кружки,
   другая плоскость зеркала, открытый низ корпуса).
4. **Дубли не держим.** Однострочники-дубли команд (`thread`, «Резьба: болт»)
   из приёмов убраны.
5. **Остальные 94 команды не потеряны**: они все в разделе «Все команды» —
   с описанием, параметрами и примером, который вставляется одной кнопкой.

**17 приёмов и их поля**

| Приём | Поля | Что делает |
|---|---|---|
| Кружка | ⌀, высота, стенка, ручка (да/нет) | корпус, полость, ручка, повторное вычитание полости |
| Накатка | ⌀, высота, канавок, глубина | цилиндр + `knurl` |
| Скрутка | ширина, высота, угол | брусок + `twist` |
| Изгиб | ширина, длина, размах, угол | брусок + `bend` |
| Надпись | текст, высота, толщина | `text` + цвет |
| Резьба: гайка | ⌀, высота, шаг | `thread internal=true` |
| Фаска | размер, фаска, режим | брусок + `bevel` (авто/скругление/фаска) |
| Облегчение | размер, допуск | брусок + `simplify` |
| Уклон | размер, угол | брусок + `draft` |
| Отверстия сеткой | размер, сетка, ⌀, шаг, **сдвиг** | панель + `holes` |
| Разброс деталей | штук, площадь, масштаб, seed | `rock` + `scatter` |
| Выпуклая оболочка | радиус, высота, верх | призма + сфера + `hull` |
| Корпус с полостью | размер, стенка, что открыто | брусок + `shell` |
| Зеркальная пара | размер, плоскость, зазор | половинка + `mirror_copy` |
| Сечение | высота Z | деталь + `section` |
| Проба материала | X, Y, Z | деталь + `probe` |
| Паспорт детали | — | деталь + `passport` |

**Что не стало приёмами и почему**

* сопряжения (`сопряжение`) и массивы (`array`) — это приёмы *сборки*: им нужен
  уже готовый объект в сцене, поэтому они живут в справочнике и в мастере
  зазоров;
* анимация (`кадр`, `движение`, `заготовка`) — это касается сцены, а не детали;
* проверки (`check`) и служебные команды (`clean`, `import`, `export`) —
  не «приёмы», а инструменты.

**Что стоит добавить дальше**

* «Рёбра жёсткости» — пластина + массив рёбер + объединение;
* «Крепёж по месту» — отверстия + саморезы с крестом из одной карточки;
* «Массив по кругу» — `array mode=radial` с полем «сколько»;
* «Петля» — ось + зазор + `check связь` (когда сопряжения выйдут в панель).

## 15. Наполнение, горка, капля и массив по кругу (0.22)

### 15.1. Крупа в тарелке: `fill`

```forma
тарелка = plate diameter=180 depth=55 wall=4
каша = fill [тарелка] grain=зерно size=8 level=0.8 density=0.75 seed=7
color каша #b98a4a
```

Как это работает:

1. по габариту посуды строится сетка XY с шагом `size · (0.82 + 0.3 · (1 − density))`;
2. в каждой колонке пускается луч сверху вниз — первое попадание с нормалью
   вверх считается дном полости;
3. восемь боковых лучей проверяют, что колонка внутри, а не снаружи (иначе
   зерно повисло бы над ручкой кружки); зазор до стенки — `inset`;
4. колонка заполняется снизу вверх: каждое зерно садится **дном** на пол или на
   предыдущий слой, с джиттером, случайным поворотом (`rotate`) и разбросом
   размера; предел — уровень `level · (высота борта − дно)`;
5. всё объединяется одним `batch_boolean(OpType.Add)`.

| параметр | смысл | по умолчанию |
|---|---|---|
| `grain` | шар, горох, зерно, капля, куб, галька | капля |
| `size` | характерный размер зерна, мм | 6 |
| `level` | 0.5 — половина, 1 — по край борта | 0.8 |
| `density` | плотность укладки 0…1 | 0.7 |
| `seed` | повтор раскладки | 1 |
| `rotate` | доля случайного поворота | 0.6 |
| `inset` | зазор до стенки, мм | 0.4 |
| `count` | предел числа зёрен (≤ 1600) | по месту |
| `dome` | горб к центру 0…1: 0 — ровно, 1 — с горкой | 0 |
| `as` | `одно` тело или `отдельные` объекты (≤ 150) | одно |

Одинаковый `seed` даёт ту же раскладку до треугольника — это и есть проверяемость.
Если зёрен выходит больше предела, ядро **укрупняет** их и пишет об этом в лог,
а не молча обрезает: каша остаётся кашей. Закрытый шар или купол наполнить
нельзя — команда честно скажет, что полости, открытой вверх, нет.

### 15.2. Горка: `pile`

```forma
горка = pile radius=105 height=46 grain=галька size=15 seed=5
```

Профиль — округлый конус `h · (1 − (r/R)^1.7)`. Зёрна укладываются колонками
от пола до поверхности; верхние слои ложатся по нормали склона.

Горка из **готовых предметов** — дайте объект позиционным аргументом:

```forma
конфета = drop radius=9 height=26 tip=0.6
куча = pile [конфета] radius=90 height=42 size=18 count=40 seed=4
```

Предмет приводится к единичному габариту, копии ставятся на склон с наклоном по
нормали и случайным поворотом. Исходник после сборки гасится (как после
`union`), но остаётся в сцене.

Подложка — необязательный круглый диск под насыпью: `base=8` добавит плиту
толщиной 8 мм, и горка уже не «висит» на нулевой плоскости.

### 15.3. Яйцо: новый профиль

```forma
яйцо = egg height=60 diameter=42 proportion=0.55
перепелиное = egg height=32 diameter=26 proportion=0.6 sharp=низ
```

Профиль собран из двух кусков: низ — четверть эллипса (круглое дно, без шипа
в полюсе), верх — кубическая кривая Безье от экватора к острому концу, с
вертикальной касательной на стыке. Самая широкая точка — на 45 % высоты
(у куриного яйца 42–45 %), `H/⌀ = 1.43`. `proportion`: 0 — симметричный овоид,
0.55 — куриное яйцо, 1 — сильно вытянутое. `sharp=верх|низ` переворачивает.

### 15.4. Капля: `drop`

```forma
капля = drop radius=14 height=40 tip=0.5
стекло = drop radius=9 height=52 tip=0.85
```

Полушарие снизу, хвост Безье сверху: вертикальная касательная на экваторе
(гладкий стык) и точка на конце. `tip=0` — почти сфера, `tip=1` — длинная
острая капля. Высота должна быть хотя бы 1.15 радиуса.

### 15.5. Массив по кругу: `array mode=radial`

```forma
стойка = cylinder radius=6 height=60
кольцо = array [стойка] count=8 mode=radial radius=60
веер   = array [стойка] count=5 mode=radial radius=80 angle=180 spin=да
```

* `radius` — окружность, по которой встают копии (по умолчанию вокруг центра
  самого предмета);
* `angle` — 360 (полный круг) или сектор; для сектора копии распределяются
  вместе с концами;
* `spin=да` — каждая копия поворачивается вокруг своей оси (деталь смотрит
  наружу), `spin=нет` — копии переносятся без поворота;
* `radius=0` — прежнее поведение: копии вращаются вокруг оси, оставаясь на месте;
* `center` — центр вращения, `at` — сдвиг готового массива.

### 15.6. Атлас по материалу

Команда `texture` сама выбирает развёртку, если `uv` не указан:

| материал / рисунок | развёртка | почему |
|---|---|---|
| металл, ткань, кожа, клетка, шум | `атлас` | рисунок мелкий, швы не видны, зато нет растяжений |
| «своя» текстура с точками, сеткой, клеткой, шумом | `атлас` | то же |
| дерево, мрамор, кирпич, керамика, камень, полосы, волны, градиент | `auto` | крупный узор должен оставаться целым |

Явный `uv=атлас` или `uv=auto` в команде всегда перебивает выбор по материалу.
Причина выбора пишется в лог сборки.

## 16. Сварка объёмов, свечение и новые фигуры (0.23)

### 16.1. `fuse` — одно тело вместо набора примитивов

`union` просто склеивает детали: на стыке остаётся резкое ребро, и модель
читается как «кубик, к которому приставили цилиндр». `fuse` сваривает и
скругляет **вогнутые** рёбра радиусом `radius`.

```
стойка = box size=[200,62,34] round=8 at=[0,0,0]
блок   = box size=[210,52,96] round=12 at=[0,0,20]
скос   = box size=[188,20,26] round=6 at=[0,-14,8]
корпус = fuse [стойка, блок, скос] radius=9 edges=все
```

* `radius` — ширина видимого перехода. Правило: **10–20 %** от меньшей
  стороны детали. Для стыка «шея–голова» 8–15 мм, для ручки кружки 3–5 мм.
* `edges=вогнутые` (по умолчанию) — трогает только стыки, внешние рёбра
  остаются острыми (так делают корпус прибора).
* `edges=все` — скругляет и наружные рёбра: получается «литая» мягкая форма.
* `angle` — порог, ниже которого ребро считается плоским (34°); увеличивайте,
  если между деталями остался barely-заметный шов.
* `detail` — шаг сетки (авто ≈ radius/4). Меньше = глаже и дороже.

Чего `fuse` не делает: не меняет топологию и не сливает детали, которые
**не пересекаются** (сначала `union`, потом `fuse`), и не заменяет `fillet`
на одной детали. Детали должны реально входить друг в друга на радиус.

### 16.2. Свечение

```
color цифры #2bff72 emissive=#2bff72 emissive_strength=4.5
color лампа material=lamp
```

| preset | что это |
|---|---|
| `led` | зелёный светодиод, яркость 4 |
| `neon` | розовый неон, яркость 6 |
| `lamp` | тёплая лампа, яркость 5 |
| `screen` | тёмное полупрозрачное стекло экрана |

В окне bloom включается автоматически, если в модели есть эмиссия.
В GLB уходит `KHR_materials_emissive_strength` — Blender видит яркость.

### 16.3. Стекло

```
стекло = box size=[186,1.4,76] round=0.7 at=[0,-27,28]
color стекло #7fd6e8 transmission=0.72 rough=0.04 metal=0
```

В GLB — `KHR_materials_transmission` + `KHR_materials_ior` (1.45).
В PNG-снимках прозрачные тела рисуются последними со смешиванием, поэтому
сквозь стекло видны цифры. В окне — `MeshPhysicalMaterial` с `thickness`.
Если нужен простой эффект «дымчатого» стекла без преломления — ставьте
`transmission=0.2…0.35`.

### 16.4. Светодиодные цифры

```
цифры = seven_seg text="21:38" height=54 width=26 thick=8.2 gap=11 depth=2.2
цифры = rotate [цифры] angle=90 axis=x
цифры = place [цифры] at=[0,-25.4,66] align=center
color цифры #2bff72 emissive=#2bff72 emissive_strength=4.5
```

`seven_seg` строит **плоскую** панель в XY (толщина по Z), поэтому для
вертикального экрана её надо повернуть на 90° вокруг X. Понимает `0-9`,
`A-F`, `:`, `.`, `-`, пробел.

### 16.5. Сердце, плюс, сектор, спираль, верёвка

```
сердце = heart width=60 depth=18 round=3
плюс   = plus arm=60 thick=18 depth=14 round=2
долька = sector radius=50 angle=90              # четвертинка шара
купол  = sector radius=80 angle=180 thickness=6 # полусфера-стенка
завиток = spiral radius=60 turns=3 wire=6 height=6
канат  = rope length=300 diameter=24 strands=3 twist=60
```

* `heart` — настоящая кривая сердца (16sin³t …), не два круга. `height`
  переопределяет высоту, `round` скругляет кромки.
* `plus` — два бруса в одно тело, `round` скругляет внутренние углы.
* `sector` — `angle` любой от 1 до 360, `start` — откуда отсчёт, `up` — какая
  половина шара, `thickness` — стенка.
* `spiral` — архимедова спираль; если витки налезают друг на друга, команда
  честно скажет, какой шаг и какая нить.
* `rope` — каждая нить это настоящая винтовая линия с круглым сечением;
  толщина нити подбирается автоматически так, чтобы нити касались, а наружный
  диаметр совпадал с `diameter`. Торцы подрезаны ровно.

### 16.6. Часы целиком

Готовый пример — `examples/clock_led.forma`: сварной корпус, ниша, экран,
стекло, LED-цифры, индикатор. 6 проверок, все проходят. Собирается за 0.7 с.

### 16.7. Примитив или ручная сборка: что выгоднее

Примитив — это **не другая геометрия**, а тот же `manifold3d`, собранный тем же
ядром: экструзия контура, `revolve`, `sweep`, булевы операции. Разница только
в том, кто пишет координаты — вы или проверенная функция. Замеры (лист
`docs/primitive_vs_script_023.png`, скрипт `docs/make_primitive_vs_script.py`):

| фигура | вызов примитива | добросовестная ручная сборка |
|---|---|---|
| сердце 72×65×20 | `heart width=72 depth=20 round=3` — 1 стр., 40 симв., 1.1 с, **1 тело**, 3 366 трис | 8 стр., 278 симв., 2 шара + призма + `fuse`, 99 590 трис, силуэт совпал на **87 %** |
| верёвка ⌀26×150 | `rope length=150 diameter=26 strands=3` — 1 стр., 45 симв., 0.07 с, **1 тело, род 1** | 3 `sweep` по 150 точек — 8 683 симв., **3 отдельных тела**, концы не сведены |
| индикатор «21:38» | `seven_seg text="21:38" height=54` — 1 стр., 48 симв., 754 трис, концы штрихов скруглены | 21 стр., 943 симв., 380 трис коробок с острыми углами, силуэт совпал на **88 %** |

Вывод: примитив выигрывает **всегда, когда форма уже есть в наборе** — он
короче в 5–200 раз, даёт одну проверенную топологию и одинаковый результат у
всех. Ручная сборка нужна, когда формы в наборе нет или когда деталь — часть
сцены с собственными размерами (тогда берите простые примитивы и `fuse`).

Слитность даёт **не примитив, а `union`/`fuse`**: `seven_seg` честно отдаёт
каждый знак отдельным телом, потому что цифры в приборе и должны быть
отдельными. Если нужен один объём — сваривайте.

## 17. Знаки и фигуры (0.24)

Семь новых примитивов категории «Примитивы». У всех плоские фигуры лежат
в плоскости XY (толщина по Z), стоят центром на полу, а `stand=да`
разворачивает их вертикально, как табличку.

```
стрелка = arrow length=120 width=26 head=42 head_width=68 depth=12 round=2
тавр    = tee arm=90 bar=20 stem=22 leg=60 depth=14 round=2
луна    = crescent radius=50 thickness=18 depth=12 round=1.5
куча    = swirl radius=42 height=70 coils=3
молния  = lightning height=90 width=44 depth=10 round=1.5
банан   = banana length=120 bend=110 thick=28 flat=0.75
рогатка = yoke height=110 spread=64 arm=16 fork=0.38 depth=14 round=2
```

| команда | что это | главные параметры |
|---|---|---|
| `arrow` | указатель остриём вправо | `length`, `width` (древко), `head`, `head_width`, `tail` — вырез-оперение |
| `tee` | буква Т, тавр | `arm` (ширина), `bar` (толщина перекладины), `stem`, `leg` |
| `crescent` | полумесяц | `radius`, `thickness`, `bite` — радиус выкуса в долях радиуса |
| `swirl` | завиток-наплыв | `radius`, `height`, `coils`, `groove`, `taper` |
| `lightning` | молния | `height`, `width`, `depth` |
| `banana` | банан / бровь / стручок | `length` (по дуге), `bend`°, `thick`, `flat`, `taper` |
| `yoke` | буква Y, рогатка | `height`, `spread` (между концами), `arm`, `fork` |

### 17.1. Почему габарит совпадает с параметром

Скругление кромок (`round`) сжимает контур на радиус — острия при этом
срезаются, и деталь стала бы меньше заданной. Поэтому после скругления
`_flat()` возвращает точный габарит масштабом. Проверено тестами:
`arrow length=120 head_width=68 round=2` даёт ровно 120 × 68 мм,
`lightning height=90 width=44 round=1.5` — ровно 44 × 90 мм.

### 17.2. Знаки одной сценой

```
стойка = cylinder radius=5 height=118
пятка = cylinder radius=22 height=8 round=2 at=[0,0,-12]
табличка = arrow length=104 width=20 head=34 head_width=54 depth=9 stand=да
табличка = translate [табличка] offset=[26,0,74]
вторая = arrow length=76 width=15 head=26 head_width=40 depth=7 stand=да
вторая = rotate [вторая] angle=180 axis=z
вторая = translate [вторая] offset=[-20,0,44]
```

`stand=да` поворачивает знак на 90° вокруг X, поэтому `depth` становится
толщиной по Y, а высота фигуры — по Z. Это проверено тестом `TestStand`.

### 17.3. Вырезание фигурой (роспись примитивами)

Примитивы — тела, поэтому фигурой можно **резать**: «кубик с кружками на
всех гранях» из вашей идеи — это куб минус сфера радиусом чуть больше
полуребра:

```
куб = box size=[60,60,60] round=3
дырка = sphere radius=34 at=[0,0,30]
куб = вычесть [куб] дырка
```

Сфера больше куба по всем осям, поэтому вырезает по кружку на каждой из
шести граней, а внутри остаётся сфера-полость.

## 18. 0.25: поверхность, одежда, экраны, покраска узором

Пятнадцать команд одной версии. Все они работают по-русски и по-английски:
`складки` = `wrinkle`, `чешуя` = `scales`, `узор` = `pattern` и так далее.

### 18.1. Поверхность: одна деформация вместо десяти инструментов

| команда | что делает | главные параметры |
|---|---|---|
| `wrinkle` | волна по телу (ткань, гофра, кора, пемза) | `amp`, `freq`, `mode`, `detail`, `seed` |
| `relief` | карта высот PNG на поверхности | `image`, `depth`, `mode=обёртка\|плоскость`, `invert` |
| `porous` | поры, ячеи, пузыри, глазки | `mode`, `size`, `count`, `seed` |
| `scales` | наложенная чешуя | `rows`, `per_row`, `length`, `lift`, `overlap` |
| `lattice` | сетка прутьев сквозь тело | `cell`, `wire`, `mode=прямоуг\|ромб\|соты`, `depth` |
| `bark` | ствол с бороздами | `height`, `radius`, `grooves`, `depth`, `taper` |
| `bricks` | кладка вперевязку | `width`, `height`, `thick`, `brick=[w,h]`, `joint` |
| `repair` | доводка скана до замкнутого тела | `smooth`, `simplify`, `drop` |

Все поверхностные команды — **модификаторы**: они берут готовое тело и меняют
его, формулировка одна:

```
ваза = lathe points=[[0,0],[40,0],[46,90],[38,92],[36,6],[0,5]] thickness=3 open=top
wrinkle ваза amp=2 freq=14 mode=радиус
porous ваза mode=поры size=3 count=40
```

`wrinkle` считает дробление сетки от **длины волны** (шаг ≈ wavelength/6),
поэтому мелкая рябь не превращается в миллион треугольников: радиус 14 →
54 тыс. трис за 0.09 с, высота 20 → 108 тыс., трещины → 57 тыс. Предел —
140 тыс. трис на деталь; `detail=` переопределяет шаг вручную.

Режимы `wrinkle`:

* `радиус` — тело «дышит» по радиусу от оси Z (мятая ткань, животные);
* `высота` — волны по Z (гофра, пирог, берег);
* `шум` — фрактальный шум (камень, кора, органическое);
* `клетка` — ромбическая сетка вмятин (стеганая куртка, вафля);
* `трещины` — узкие канавки по границам ячеек (сухая земля, керамика).

### 18.2. Клинок

```
катана = blade length=700 width=32 thick=7 kind=катана curve=24
стилет = blade length=280 width=14 thick=5 kind=стилет
серп   = blade length=300 width=46 kind=серп curve=90
```

Клинок строится как лофт линзовидного сечения по дуге: `curve` — стрелка
прогиба в мм, `edges` — угол заточки, `taper` — сужение к острию,
`kissaki` — длина острия, `dol` — дол (0…1). **Клинок лежит плашмя**:
ширина по Y, толщина по Z, изгиб уходит вверх по Z. Поэтому вид сверху —
это силуэт клинка, а вид спереди — его толщина.

### 18.3. Люди и вещи

```
причёска = hair length=200 style=аниме clumps=28
кот      = hair radius=70 length=16 style=мех density=160
юбка     = skirt waist=76 hem=190 length=240 pleats=12 depth=10 thick=3
пиджак   = jacket height=740 chest=1040 waist=920
```

* `hair`: пряди-веретёна по дуге от макушки. `clumps` — сколько прядей,
  `spikes` — рваность кончиков 0…1, `thick` — ширина пряди в долях длины.
  Основа-шапка врезается в пряди, поэтому тело одно: у меха из 300 клоков
  тоже (крошки мельче 0.4 % объёма выбрасываются).
* `skirt`: тело вращения по **замкнутому** профилю — наружная стенка вниз,
  внутренняя вверх. Складки затухают к поясу (`depth·cos(pleats·φ)`), стенка
  настоящая, низ открыт.
* `jacket`: обхваты в миллиметрах, как на бирке. Полуобхват считается из
  периметра эллипса `C ≈ π(a+b)`, иначе пиджак выходит вдвое уже. Спина
  площе груди на 12 %, рукава входят в торс, лацканы и пуговицы врезаны.
  Сварка `fuse` на крупной сборке не используется — она раздувает сетку;
  вместо неё `union` + допуск.

### 18.4. Экраны и зеркала: свет и стекло

```
часы    = display width=180 height=90 thick=45 style=будильник content=led text="21:38"
телефон = display width=71 height=147 thick=8 style=смартфон content=ui
монитор = display width=520 height=320 thick=26 style=монитор
зеркало = mirror_plate width=600 height=900 frame=40
```

`display` создаёт не один объект, а четыре — потому что это разные материалы:

| объект | материал |
|---|---|
| `часы` | корпус с нишей и подставкой, одно тело |
| `часы.экран` | тёмная панель (#11151b), rough 0.22 |
| `часы.цифры` | светодиоды: `emissive=#ff2d20`, яркость 2.2 |
| `часы.стекло` | `transmission=0.82`, rough 0.03 |

Смартфон лежит экраном вверх, будильник и монитор стоят: сборка строится
«плоско» и поворачивается на 90° вокруг X, подставка добавляется уже в
мировых координатах. Цифры собираются той же командой `seven_seg`, что и
`индикатор`, но напрямую — без промежуточной сцены.

`mirror_plate` тоже даёт два объекта: рама с задником и подвесом (одно тело)
и `зеркало.зеркало` — пластина с `metal=1, rough=0.02`.

### 18.5. Покраска узором — «куб с кружками»

```
куб = box size=[60,60,60] round=3
pattern куб #d94f3d shape=круги size=12 step=24

кубик = box size=[50,50,50]
pattern кубик #2f6fb0 shape=клетка size=10 step=20 angle=45 offset=[5,5]

ваза = cylinder radius=40 height=90
pattern ваза #e0b64a shape=полосы size=4 step=16 angle=90 side=бок
```

Это **покраска**, а не вычитание: геометрия не меняется, меняется цвет
треугольников. Узор накладывается трипланарно — у каждой точки берётся
плоскость по главной компоненте нормали, поэтому кружки есть и на верхней
грани, и на боковых, и на дне.

* `shape`: `круги` (горошек, точки), `кольца`, `полосы`, `клетка`
  (шахматы), `треугольники`, `ромбы`, `волны`;
* `size` — размер фигуры, `step` — шаг повторения (должен быть ≥ size,
  иначе фигуры сливаются и команда честно ругается);
* `angle` — поворот узора, `offset=[u,v]` — сдвиг;
* `side=верх|низ|бок…` — ограничить узор одной гранью.

Узор виден и в окне, и в PNG, и в GLB (там — по треугольникам, поэтому для
чётких границ берите более мелкую сетку через `refine`).

### 18.6. Что чем делать: выбор инструмента

| задача | команда |
|---|---|
| мятая ткань, гофра, кора | `wrinkle` |
| логотип или узор рельефом | `relief` |
| пемза, губка, сыр | `porous` |
| чешуя, шишка, дракон | `scales` |
| решётка, купол, окно | `lattice` |
| ствол дерева | `bark` |
| стена, камин | `bricks` |
| починить скан | `repair` |
| нож, меч, серп | `blade` |
| причёска, мех | `hair` |
| юбка, пиджак | `skirt`, `jacket` |
| экран со светящимися цифрами | `display` |
| зеркало | `mirror_plate` |
| кружки и клетка **цветом** | `pattern` |
| кружки и клетка **отверстиями** | `porous`, `вычесть` |

## 19. 0.26: аниме и манга — контуры по форме

Стиль — это не текстура и не материал, а **подача кадра**. Он применяется
в окне модели (живой, без пересборки) и на PNG-снимках; в GLB уходит обычная
геометрия, а стиль остаётся в сценарии строкой `anime`.

### 19.1. Четыре пресета

```
ваза = lathe points=[[0,0],[26,0],[40,30],[30,62],[16,90],[0,92]]
шар = sphere radius=30 at=[70,0,30]
anime mode=аниме                # цвет + чёрный контур + ступени тона
```

| стиль | что делает | когда нужен |
|---|---|---|
| `аниме` | цвет, ступени тона, блик, чёрные контуры | кадр «как в аниме» |
| `манга` | бумага, серый тон точками, заливка в тени | чёрно-белая иллюстрация |
| `комикс` | цвет + толстый контур + точки в тенях | обложка, постер |
| `линия` | только контуры на бумаге, без тона | чертёж, Line Art |

```
anime mode=манга line=2.2 paper=#ffffff
anime mode=комикс line=3 crease=40
anime mode=линия line=1.4
```

### 19.2. Что именно попадает в контур

* **силуэт** — граница предмета с фоном;
* **излом** — ребро, фаска, складка: там, где нормали соседних пикселей
  расходятся сильнее, чем `crease` градусов (`crease=32` — обычный аниме-вид,
  `crease=15` — больше линий, `crease=55` — только жёсткие рёбра);
* **перепад глубины** — уступ, стык двух объёмов (`depth`, доля размера сцены);
* **стык деталей** — отдельная линия на границе объектов (`seams`).

Это те же три источника, что у Line Art в Blender (контур, излом, стык), —
поэтому линии идут по форме, а не обводят только абрис.

### 19.3. Настройки

```
anime mode=аниме line=2 color=#0b0b12 crease=26 depth=0.02 seams=да inner=да
anime mode=манга tone=0.8 paper=#fbfbf7 toon=3
anime mode=линия shade=нет
anime off=да
```

* `line` — толщина в пикселях снимка (1–3 обычно достаточно);
* `toon` — число ступеней тона, `0` — без ступеней;
* `tone` — сила растра (манга/комикс), `0` — чистые ступени серого;
* `paper` — цвет бумаги; `paper=сцена` — оставить фон сцены;
* `shade=нет` — не затенять поверхность, оставить чистый контур;
* `inner=нет` — не рисовать внутренние линии, только силуэт.

### 19.4. В окне

Панель «вид → Стиль»: чипы `обычный / аниме / манга / комикс / линия`,
ползунки контура и тона, цвет бумаги. Кнопка **«в сценарий»** вставляет
строку `anime …` — так стиль сохраняется в проекте и попадает на снимки.
Если нужен только быстрый взгляд — сценарий менять не нужно.

### 19.5. Что чем делать: выбор

| задача | способ |
|---|---|
| посмотреть модель «как рисунок» | чипы в окне |
| сохранить стиль в проекте и на снимках | `anime mode=…` + кнопка «в сценарий» |
| только силуэт, без рёбер | `anime inner=нет` |
| больше внутренних линий | `crease=18…24` |
| тонкие аккуратные линии | `line=1.2…1.6` |
| жирный комиксовый контур | `line=2.5…3.5`, `crease=38…45` |
| чистый чёрно-белый рисунок | `mode=манга tone=0.8` |
| обводка чертежа | `mode=линия`, `shade=нет` |
