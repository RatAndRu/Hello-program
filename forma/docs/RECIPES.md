# Готовые сценарии для командной строки

Скопируйте блок целиком и вставьте в сценарий (или наберите короткую команду
в нижней строке — она подставит пример).

| Команда в строке | Что появится |
| --- | --- |
| `/банан` | банан: дуга, переменная толщина, круглые торцы |
| `/гриб` | гриб: шляпка-купол, ножка, юбочка, пятнышки |
| `/кружка` | кружка 350 мл с ручкой и проверками |
| `/ваза` | ваза с вогнутой кромкой |
| `/шестерня` | шестерня с отверстиями |
| `/кузов` | кузов машины |
| `/рецепты` | напомнить список |

Все примеры открываются и из меню «Проекты → Примеры».

## Банан

```forma
# Банан — дуга, овальное сечение и скруглённые торцы.
# Форму держат три вещи: путь-дуга, scale_curve (толщина по длине)
# и round_caps (полукруглые концы вместо плоских срезов).
# Полигонаж ~3.5 тыс. треугольников — гладко и без «лесенок».

путь = [[-101.4, 0, 22.5], [-89.4, 0, 17.3], [-77.1, 0, 12.7], [-64.6, 0, 8.9], [-51.9, 0, 5.7], [-39.1, 0, 3.2], [-26.1, 0, 1.4], [-13.1, 0, 0.4], [0, 0, 0], [13.1, 0, 0.4], [26.1, 0, 1.4], [39.1, 0, 3.2], [51.9, 0, 5.7], [64.6, 0, 8.9], [77.1, 0, 12.7], [89.4, 0, 17.3], [101.4, 0, 22.5]]

сечение = [[22, 0], [21.58, 3.71], [20.33, 7.27], [18.29, 10.56], [15.56, 13.44], [12.22, 15.8], [8.42, 17.55], [4.29, 18.63], [0, 19], [-4.29, 18.63], [-8.42, 17.55], [-12.22, 15.8], [-15.56, 13.44], [-18.29, 10.56], [-20.33, 7.27], [-21.58, 3.71], [-22, 0], [-21.58, -3.71], [-20.33, -7.27], [-18.29, -10.56], [-15.56, -13.44], [-12.22, -15.8], [-8.42, -17.55], [-4.29, -18.63], [-0, -19], [4.29, -18.63], [8.42, -17.55], [12.22, -15.8], [15.56, -13.44], [18.29, -10.56], [20.33, -7.27], [21.58, -3.71]]

  scale_curve=[0.45, 0.72, 0.9, 0.99, 1.0, 0.98, 0.9, 0.72, 0.48] round_caps=0.55

check банан watertight
check банан parts 1
check банан size 200..230 35..42 50..60
check банан tris ..40000
```

## Полезные одиночные команды

```forma
# согнуть деталь дугой и закрутить
деталь = bend [деталь] angle=60
деталь = twist [деталь] angle=90 axis=z

# сузить кверху и скруглить кромки
деталь = taper [деталь] factor=0.6 axis=z
деталь = bevel [деталь] width=2

# выровнять по столу и разрезать плоскостью
деталь = align [деталь] z=min
деталь = slice [деталь] axis=z at=0 keep=top

# канавки на пробке и зеркальная копия
пробка = groove [пробка] at=[0,0,20] radius=14 depth=1.2 height=2 count=3
пара = mirror_copy [деталь] axis=x
```
