# РЕЦЕПТЫ КОМАНД — копируйте в окно сценария

Всё в миллиметрах, ось Z — вверх. Каждая строка — одна команда.
Вставляйте блок целиком и нажимайте «Собрать» (Ctrl+Enter).

## 0.1 Мышь, «Загрузки» и свои текстуры (новое в 0.6)

**Мышь в окне модели**

* левая кнопка — вращать, колесо — приблизить, **правая кнопка — двигать сцену**;
* двойной клик — вернуть общий вид;
* режим «выбор»: **левая кнопка тянет рамку**, средняя вращает, правая двигает;
  Shift добавляет область к уже выбранным, Ctrl+клик по области — убрать её.

**Куда сохраняются файлы.**
Кнопки экспорта и «сохранить» пишут готовые файлы в папку **«Загрузки»**
(Windows: `C:\Users\<имя>\Downloads`). Адрес показан во всплывающем сообщении.
Внутренние копии для окна лежат в `%APPDATA%\Forma3D\exports`.

**Своя текстура** — узор и два цвета прямо в сценарии:

```
texture кружка kind=своя pattern=полосы color1=#c0504d color2=#f2e6d9 scale=1.2
texture ваза kind=своя pattern=камень color1=#6b7f8c color2=#e9e2d4 scale=2
texture кузов kind=своя pattern=волны color1=#1f6f8b color2=#d7e6ea
```

Узоры: `полосы`, `клетка`, `волны`, `градиент`, `шум`, `камень`, `точки`, `сетка`.
В панели материала выберите «своя…» и нажмите «Создать свою текстуру» —
та же строка появится в сценарии.

**Новые проверки и инструменты**

```
# готовые детали для примеров ниже
корпус = cylinder radius=34 height=95 r2=40
полость = cylinder radius=30 height=89 r2=36
полость = translate [полость] offset=[0,0,6]
кружка = difference [корпус, полость]
шестерня = gear teeth=20 module=2 thickness=8 bore=8
сфера = sphere radius=30 segments=48

check кружка wall_min 3..5          # самая тонкая стенка + её координата
check шестерня sharp_edge 95        # самое острое ребро, в градусах
check сфера tri_quality 1           # доля «игольчатых» треугольников, %

# сварить вершины и убрать мусор у готовой детали
чистая = clean [сфера]
```

Из консоли: `forma diff старый.forma новый.forma`, `forma doctor`,
`forma build модель.forma --strict` (код 3, если проверка не выполнена),
`--json`, `--digest`, `--trace журнал.jsonl`. Экспорт: `--format 3mf`.

## 0.4 Кромки: скругление и фаска (новое в 0.7)

**Скруглить наружные рёбра (радиус 3 мм, габарит не меняется):**

```
плита = box size=[150,75,10]
плита = fillet [плита] radius=3 edges=convex
check плита size 149.7..150.3 74.7..75.3 9.7..10.3
```

**Скруглить внутренний стык** (например, дно полости или угол буквы «Г»):

```
а = box size=[90,30,30] at=[-30,0,0]
б = box size=[30,30,80] at=[15,0,0]
угол = union [а, б]
угол = fillet [угол] radius=6 edges=concave
```

**Скруглить всё сразу** (сначала вогнутые, потом выпуклые — так считает быстрее):

```
корпус = box size=[120,60,20]
корпус = fillet [корпус] radius=5 edges=all
```

**Плоская фаска 45°** (ширина 2 мм, снимает кромку без радиуса):

```
плита = box size=[150,75,10]
плита = chamfer [плита] width=2 edges=convex
```

Параметры: `radius` / `width` — в миллиметрах, `edges` — `convex`, `concave`
или `all`, `segments` у `fillet` — качество (12 по умолчанию: без тонких
треугольников; 24–40 — глаже, но появляются вытянутые треугольники).
Если объект тяжелее 12 000 треугольников, сначала `simplify [объект] tolerance=0.2`.

**Математическая поверхность** (поле считается массивами, поэтому быстро):

```
капля = from_sdf expression="smin(sd_sphere(x,y,z-40,30), sd_sphere(x,y,z-95,20), 12)" bounds=[-40,-40,-5,40,40,120] resolution=1.5
```

## 8. Лофт: плавный переход между контурами

```
# sections — контуры [[x,y], …], positions — где каждый контур стоит по оси X
корпус = loft sections=[[[-60,-40],[-70,20],[-40,60],[40,60],[70,20],[60,-40]],[[-40,-30],[-50,15],[-25,45],[25,45],[50,15],[40,-30]]] positions=[-160,160] axis=x smooth=3
check корпус watertight
check корпус size 310..330 130..150 110..130
```

Контуров может быть сколько угодно: `loft` соединяет их по порядку, `positions`
задаёт места по оси, `smooth` — плавность перехода, `profile_smooth` — сглаживание
самих контуров. Тот же приём, но на четырёх контурах и с арками, собран в примере
«Кузов машины»: там лофт — только первая строка, остальное — вычитание арок,
пересечение с зонами стёкол и `scale` на 0,3 % для зазора.

> Целиком — пример «Кузов машины»: 72 000 треугольников, 4 колеса, стёкла, швы дверей.

Красить можно и кистью в окне: выделите деталь, нажмите «Кисть» и ведите
мышью с зажатой кнопкой — за один мазок красится целая область, а не один
полигон. При отпускании в сценарий дописывается одна команда `paint`.

```
check кружка watertight              # покраска не ломает тело
screw d=5 length=9 head=полукруг     # три вида головки: потай, полукруг, шестигранник
```

Проверки сборки (0.18): `check деталь gap другая_деталь 0` — детали должны
касаться, а не висеть; `check деталь parts 1` — тело не распалось на куски.

## 13. Сопряжения: деталь на место отношением

Сопряжение — это ограничение сборки, как mates в SolidWorks/Fusion. Геометрия
детали не меняется: программа только переносит её (или поворачивает) так, чтобы
выполнилось условие, и запоминает связь.

```
# плоскость к плоскости: низ детали встаёт на верх основания (+ отступ)
плитка = box size=[60, 60, 10] at=[0, 0, 200]
сопряжение плитка основание type=плоскость axis=z offset=0

# ось: деталь центруется по другой в двух поперечных осях
шайба = cylinder radius=20 height=4 at=[300, 90, 200]
сопряжение шайба втулка type=ось axis=z

# паз-рейка: центруется по рейке и садится на её верхнюю грань
каретка = box size=[90, 70, 40] at=[250, 0, 300]
сопряжение каретка рейка type=паз axis=y

# зазор: ровно 3 мм между деталями (по кратчайшему расстоянию)
сопряжение шайба плита type=зазор offset=3

# точка: точка детали попадает в заданное место
шильдик = box size=[84, 3, 30] at=[0, 0, 600]
сопряжение шильдик основание type=точка point=[0, 0, 600] to=[-80, -78, 14]

# петля: поворот вокруг оси через точку (дверная петля)
сопряжение дверь корпус type=петля axis=z point=[-70, 80, 100] angle=-28
```

Что запоминается и проверяется:

```
check рейка связь          # остаток 0 мм — связь держится
check дверь связь 5        # для петли допуск можно задать: 5 мм
```

Остаток (residual) — на сколько деталь ушла от условия. После `translate`,
`rotate` или правки размеров `check … связь` пересчитывает его заново и
краснеет, если связь разъехалась.

Где смотреть в окне: вкладка **«Связи»** — мастер зазоров. Он считает точные
расстояния между телами и показывает сборки, висящие детали и щели; кнопка
«связать» дописывает `сопряжение` в сценарий.

> Целиком — пример `examples/mates.forma`: 7 связей всех видов, 10 проверок,
> дверь на петле и колесо на валу.

## 14. Приёмы 0.21: настройки, принцип отбора и что осталось за кадром

**Что изменилось в «Инструментах»**

* у каждого приёма появились **поля**, как у фигур: меняете число — предпросмотр
  сценария под карточкой пересчитывается сразу, вставляется уже готовый текст;
* **«Сечение, проба и паспорт» разведены на три карточки.** Это три разных
  вопроса к детали (`section` — контур разреза, `probe` — есть ли материал в
  точке, `passport` — габарит, объём, масса, герметичность), и одна карточка
  на три команды только путала;
* **«Отверстия сеткой»** получили поле **сдвиг**: сетка смещается по детали
  (`holes … offset=[12,-8]`), а не только стоит по центру;
* **«Накатка»** получила число канавок и глубину (было жёстко `count=24 depth=1`);
* **«Резьба: болт» убрана.** Это был однострочник, дублирующий команду
  `thread`; карточка самой команды с параметрами есть в разделе «Все команды»;
* добавлены приёмы, которых не хватало: **«Корпус с полостью»** (`shell`),
  **«Зеркальная пара»** (`mirror_copy`), **«Сечение»**, **«Проба материала»**,
  **«Паспорт детали»**, **«Надпись»**.

**Принцип отбора: почему приёмов 17, а команд 111**

1. **Приём — это сценарий, а не команда.** Он решает задачу целиком: делает
   заготовку, обрабатывает её и красит. Если для задачи хватает одной команды,
   приём не нужен — за это отвечает карточка команды в «Все команды».
2. **У приёма должны быть осмысленные поля.** Если параметр нечего менять
   (или он всегда один и тот же), это не приём, а демонстрация.
3. **Приём обязан собираться.** Все 17 проверены сборкой со значениями по
   умолчанию и с изменёнными полями (сдвиг сетки, снятая ручка кружки,
   другая плоскость зеркала, открытый низ корпуса).
4. **Дубли не держим.** Однострочники-дубли команд (`thread`, «Резьба: болт»)
   из приёмов убраны.
5. **Остальные 94 команды не потеряны**: они все в разделе «Все команды» —
   с описанием, параметрами и примером, который вставляется одной кнопкой.

**17 приёмов и их поля**

| Приём | Поля | Что делает |
|---|---|---|
| Кружка | ⌀, высота, стенка, ручка (да/нет) | корпус, полость, ручка, повторное вычитание полости |
| Накатка | ⌀, высота, канавок, глубина | цилиндр + `knurl` |
| Скрутка | ширина, высота, угол | брусок + `twist` |
| Изгиб | ширина, длина, размах, угол | брусок + `bend` |
| Надпись | текст, высота, толщина | `text` + цвет |
| Резьба: гайка | ⌀, высота, шаг | `thread internal=true` |
| Фаска | размер, фаска, режим | брусок + `bevel` (авто/скругление/фаска) |
| Облегчение | размер, допуск | брусок + `simplify` |
| Уклон | размер, угол | брусок + `draft` |
| Отверстия сеткой | размер, сетка, ⌀, шаг, **сдвиг** | панель + `holes` |
| Разброс деталей | штук, площадь, масштаб, seed | `rock` + `scatter` |
| Выпуклая оболочка | радиус, высота, верх | призма + сфера + `hull` |
| Корпус с полостью | размер, стенка, что открыто | брусок + `shell` |
| Зеркальная пара | размер, плоскость, зазор | половинка + `mirror_copy` |
| Сечение | высота Z | деталь + `section` |
| Проба материала | X, Y, Z | деталь + `probe` |
| Паспорт детали | — | деталь + `passport` |

**Что не стало приёмами и почему**

* сопряжения (`сопряжение`) и массивы (`array`) — это приёмы *сборки*: им нужен
  уже готовый объект в сцене, поэтому они живут в справочнике и в мастере
  зазоров;
* анимация (`кадр`, `движение`, `заготовка`) — это касается сцены, а не детали;
* проверки (`check`) и служебные команды (`clean`, `import`, `export`) —
  не «приёмы», а инструменты.

**Что стоит добавить дальше**

* «Рёбра жёсткости» — пластина + массив рёбер + объединение;
* «Крепёж по месту» — отверстия + саморезы с крестом из одной карточки;
* «Массив по кругу» — `array mode=radial` с полем «сколько»;
* «Петля» — ось + зазор + `check связь` (когда сопряжения выйдут в панель).

## 15. Наполнение, горка, капля и массив по кругу (0.22)

### 15.1. Крупа в тарелке: `fill`

```forma
тарелка = plate diameter=180 depth=55 wall=4
каша = fill [тарелка] grain=зерно size=8 level=0.8 density=0.75 seed=7
color каша #b98a4a
```

Как это работает:

1. по габариту посуды строится сетка XY с шагом `size · (0.82 + 0.3 · (1 − density))`;
2. в каждой колонке пускается луч сверху вниз — первое попадание с нормалью
   вверх считается дном полости;
3. восемь боковых лучей проверяют, что колонка внутри, а не снаружи (иначе
   зерно повисло бы над ручкой кружки); зазор до стенки — `inset`;
4. колонка заполняется снизу вверх: каждое зерно садится **дном** на пол или на
   предыдущий слой, с джиттером, случайным поворотом (`rotate`) и разбросом
   размера; предел — уровень `level · (высота борта − дно)`;
5. всё объединяется одним `batch_boolean(OpType.Add)`.

| параметр | смысл | по умолчанию |
|---|---|---|
| `grain` | шар, горох, зерно, капля, куб, галька | капля |
| `size` | характерный размер зерна, мм | 6 |
| `level` | 0.5 — половина, 1 — по край борта | 0.8 |
| `density` | плотность укладки 0…1 | 0.7 |
| `seed` | повтор раскладки | 1 |
| `rotate` | доля случайного поворота | 0.6 |
| `inset` | зазор до стенки, мм | 0.4 |
| `count` | предел числа зёрен (≤ 1600) | по месту |
| `dome` | горб к центру 0…1: 0 — ровно, 1 — с горкой | 0 |
| `as` | `одно` тело или `отдельные` объекты (≤ 150) | одно |

Одинаковый `seed` даёт ту же раскладку до треугольника — это и есть проверяемость.
Если зёрен выходит больше предела, ядро **укрупняет** их и пишет об этом в лог,
а не молча обрезает: каша остаётся кашей. Закрытый шар или купол наполнить
нельзя — команда честно скажет, что полости, открытой вверх, нет.

### 15.2. Горка: `pile`

```forma
горка = pile radius=105 height=46 grain=галька size=15 seed=5
```

Профиль — округлый конус `h · (1 − (r/R)^1.7)`. Зёрна укладываются колонками
от пола до поверхности; верхние слои ложатся по нормали склона.

Горка из **готовых предметов** — дайте объект позиционным аргументом:

```forma
конфета = drop radius=9 height=26 tip=0.6
куча = pile [конфета] radius=90 height=42 size=18 count=40 seed=4
```

Предмет приводится к единичному габариту, копии ставятся на склон с наклоном по
нормали и случайным поворотом. Исходник после сборки гасится (как после
`union`), но остаётся в сцене.

Подложка — необязательный круглый диск под насыпью: `base=8` добавит плиту
толщиной 8 мм, и горка уже не «висит» на нулевой плоскости.

### 15.3. Яйцо: новый профиль

```forma
яйцо = egg height=60 diameter=42 proportion=0.55
перепелиное = egg height=32 diameter=26 proportion=0.6 sharp=низ
```

Профиль собран из двух кусков: низ — четверть эллипса (круглое дно, без шипа
в полюсе), верх — кубическая кривая Безье от экватора к острому концу, с
вертикальной касательной на стыке. Самая широкая точка — на 45 % высоты
(у куриного яйца 42–45 %), `H/⌀ = 1.43`. `proportion`: 0 — симметричный овоид,
0.55 — куриное яйцо, 1 — сильно вытянутое. `sharp=верх|низ` переворачивает.

### 15.4. Капля: `drop`

```forma
капля = drop radius=14 height=40 tip=0.5
стекло = drop radius=9 height=52 tip=0.85
```

Полушарие снизу, хвост Безье сверху: вертикальная касательная на экваторе
(гладкий стык) и точка на конце. `tip=0` — почти сфера, `tip=1` — длинная
острая капля. Высота должна быть хотя бы 1.15 радиуса.

### 15.5. Массив по кругу: `array mode=radial`

```forma
стойка = cylinder radius=6 height=60
кольцо = array [стойка] count=8 mode=radial radius=60
веер   = array [стойка] count=5 mode=radial radius=80 angle=180 spin=да
```

* `radius` — окружность, по которой встают копии (по умолчанию вокруг центра
  самого предмета);
* `angle` — 360 (полный круг) или сектор; для сектора копии распределяются
  вместе с концами;
* `spin=да` — каждая копия поворачивается вокруг своей оси (деталь смотрит
  наружу), `spin=нет` — копии переносятся без поворота;
* `radius=0` — прежнее поведение: копии вращаются вокруг оси, оставаясь на месте;
* `center` — центр вращения, `at` — сдвиг готового массива.

### 15.6. Атлас по материалу

Команда `texture` сама выбирает развёртку, если `uv` не указан:

| материал / рисунок | развёртка | почему |
|---|---|---|
| металл, ткань, кожа, клетка, шум | `атлас` | рисунок мелкий, швы не видны, зато нет растяжений |
| «своя» текстура с точками, сеткой, клеткой, шумом | `атлас` | то же |
| дерево, мрамор, кирпич, керамика, камень, полосы, волны, градиент | `auto` | крупный узор должен оставаться целым |

Явный `uv=атлас` или `uv=auto` в команде всегда перебивает выбор по материалу.
Причина выбора пишется в лог сборки.
