# Этап 1: геометрический фундамент

Версия Forma **0.64**. Этап не относится к оригами: история складок, разгиб,
FOLD/.cp, кинематика и kerf остаются отдельным этапом 3.

## Contour2D

`contour2d` создаёт именованный аналитический контур, а не твёрдое тело. Контур
можно использовать несколько раз; при создании тела с тем же именем контур
заменяется телом, чтобы ссылки не были неоднозначными.

Одиночные сегменты:

```forma
круг = contour2d kind=arc center=[0,0] radius=20 tolerance=.08
эллипс = contour2d kind=ellipse rx=20 ry=10 tolerance=.08
кривая = contour2d kind=bezier points=[[0,0],[10,20],[30,20],[40,0]] tolerance=.08
линия = contour2d kind=line points=[[0,0],[10,0],[10,10]]
```

Составной контур задаётся tagged-сегментами:

```forma
п = contour2d start=[0,0] segments=[
  ["line",[40,0]],
  ["arc",[40,10],10,-90,0],
  ["bezier",[[50,10],[55,20],[45,30],[40,40]]],
  ["line",[0,40]]
] closed=да tolerance=.08 join_tolerance=.00001
д = extrude profile=п height=5
```

Поддерживаются линия, дуга (`center`, `radius`, `from`, `to` в градусах),
эллипс (`center`, `rx`, `ry`, необязательные углы), квадратичная и кубическая
Bézier (3 или 4 управляющие точки). Полный круг/эллипс нельзя вставлять в
середину составного контура. Разрыв на стыке, нулевая линия, нечисловые точки,
превышение бюджета и дуга длиннее одного оборота отклоняются на команде создания.

### Адаптивная выборка и допуски

- `tolerance` — хордовый допуск в мм; по умолчанию используется общий
  `FINENESS_MM` (0.06 мм в текущем ядре).
- Дуги и эллипсы получают число сегментов из геометрического sagitta;
  Bézier подразделяется де Casteljau, гладкие параметрические участки —
  адаптивно по контрольным точкам хорды.
- `join_tolerance` — допуск сварки стыков в мм (по умолчанию `1e-5`).
- `max_points` — явный предел 4…16384; превышение является ошибкой, а не
  молчаливым ухудшением кривой.
- `extrude`, `lathe`, `loft` могут временно переопределить `tolerance` для
  2D-контура. В `sweep` этот параметр относится к 2D-профилю; путь использует
  собственный допуск и `plane=xy|xz|yz`, `at=[x,y,z]`.

`Contour2D.sample()` детерминирован. `to_dict()` содержит аналитическую
сигнатуру, отчёт выборки, длину, площадь и bounding box. Сцена только из
контуров валидна, но не имеет GLB до создания тела.

## Операции

- `extrude profile=контур` и `lathe points=контур` принимают контур наряду со
  старым списком точек.
- `loft sections=[а,б] positions=[0,20]` согласует направление обхода, фазовый
  сдвиг и число точек адаптивных сечений. Для разных верхнего и нижнего контуров
  торцы триангулируются по собственному сечению, включая `smooth>1`.
- `sweep path=путь profile=профиль` принимает контур и как 3D-путь, и как
  2D-профиль. Замкнутый контур пути по умолчанию включает `closed_path`.
- `extrude thickness=2 open=top|bottom|both|none` строит полость через точный
  2D-offset всего сечения, включая отверстия. `draft=2` задаёт уклон в градусах:
  положительный сужает наружный контур кверху и расширяет отверстие; отрицательный
  работает в противоположную сторону. Верхнее смещение равно
  `height*tan(draft)`. При совместном `draft+thickness` учитывается наклонная
  нормальная толщина, без приближённого mesh-Minkowski.

Для несовместимых `draft+twist` и `draft+scale_top` выдаётся явная ошибка.
Проверяются пустая полость, вырожденное сечение, нулевой объём и статус
Manifold.

## Измерения

В числовых выражениях доступны:

| Функция | Результат |
|---|---|
| `area(объект)` | площадь поверхности, см² |
| `volume(объект)` | объём, см³ (существующее соглашение) |
| `tris(объект)` | число треугольников |
| `parts(объект)` | число связных компонент |
| `genus(объект)` | топологический род |
| `length(контур)` | длина дискретизированного контура, мм |
| `area(контур)` | площадь замкнутого контура, см² |

Например: `let a=area(деталь)` и `let n=parts(деталь)`.

## Семантический diff

```bash
python -m forma diff old.forma new.forma --json
python -m forma diff old.forma new.forma --json \
  --linear-tol .01 --area-tol .1 --volume-tol 1
```

JSON-схема `forma.semantic-diff.v1` содержит `added`, `removed`, `changed` для
объектов, отдельный блок `contours`, `parameters` и `tolerances`. Для изменённого
объекта сохраняются before/after/delta габаритов, bounding box, объёма, площади,
центра, топология и изменённые атрибуты/материал/метаданные. Сырые mesh-id и
порядок вершин не сравниваются.

Линейный допуск задаётся в мм, площадь — в мм², объём — в мм³. Если допуски
производных величин не заданы, они вычисляются из линейного допуска и размера
каждого объекта (`12·δL·size` и `12·δL·size²`), чтобы не сообщать о шуме
площади/объёма при допустимой линейной погрешности. Нулевой или отрицательный
допуск отклоняется.

Программный API:

```python
from forma.semantic_diff import semantic_diff
report = semantic_diff(build(old_script), build(new_script), linear_tol=.01)
```
