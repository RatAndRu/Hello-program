# Муфта разрезная INNOCONT CPI-20P-8x8

Готовая сцена: [`forma/examples/coupling_cpi20p_8x8.forma`](../../examples/coupling_cpi20p_8x8.forma) ·
GLB: [`coupling_cpi20p_8x8.glb`](../../examples/assets/coupling_cpi20p_8x8.glb)

Собрано по последним правкам (ревизия после фото детали): конец каждого
надреза — **круглое скругление радиусом cut_w/2** (фреза Ø0,96 вместо
вытянутого клина `round_caps`); отверстия отведены от осевого канала —
**Ø3,0 «большой конец» → Ø2,5 резьбовой «малый»**, между каналом Ø8 и
отверстием остаётся стенка 0,6…0,85 мм, пересечения нет; на торцах —
диаметральный пропил с **разной глубиной с двух сторон**; отверстий всего три:
два **сквозных хордовых** (в них ввёрнуты втулки-винты с шестигранным
углублением) и одно осевое Ø8.

- виды: `coupling_iso.png`, `coupling_front.png`, `coupling_right.png`,
  `coupling_top.png`, крупно — `coupling-iso-big.png`
- превью, по которому согласовывали: [`coupling/proposal_v2.png`](coupling/proposal_v2.png)

## 1. Что это за деталь

Разрезная (щелевая) муфта — упругая вставка между двумя валами: передаёт
момент, но прощает несоосность. Корпус — одна цилиндрическая деталь, у которой
средний пояс разрезан поперечными прорезями, а на каждой ступице есть
продольный пропил под зажимной винт.

Код `CPI-20P-8x8` читается по табличке производителя:

| Часть кода | Значение |
|---|---|
| `CPI` | серия «разрезная муфта с зажимным кольцом» |
| `20` | наружный диаметр 20 мм |
| `P` | материал — пластик (в этой же серии `C` — алюминий) |
| `8x8` | диаметры отверстий под валы: 8 мм с одной стороны, 8 мм с другой |

**Карточка товара в магазине противоречит сама себе** и чертежу:

| В карточке | В чертеже / арифметике | Комментарий |
|---|---|---|
| «Длина 260 мм» | **26 мм** | потеряна запятая: 26,0 см → «260 мм» |
| «Вес 5 кг» | **5 г** (по таблице) | килограммы вместо граммов |
| «оптический энкодер», «DC», «Push/pull», «IP54», «−20…+85 °C» | — | это описание энкодера, а не муфты |

Поэтому все размеры взяты из заводской таблицы, а не из карточки.

## 3. Конструкция — как деталь устроена

1. **Корпус** — тело вращения Ø20 × 26, фаска 0,5 × 45° на обоих наружных
   торцах. Сквозное отверстие Ø8 с зенковкой 0,5 × 45° с двух сторон —
   это и есть третье, осевое отверстие.
2. **Две ступицы** — по 7,5 мм с торцов, между ними упругий пояс 11 мм.
3. **Шесть поперечных надрезов в поясе.** Плоскости строго ⊥ оси. Каждый
   надрез идёт **по дуге** (угол — параметр `cut_arc`, по умолчанию 270°) и
   имеет **глубину** `cut_depth` = 4,5 мм: до осевого отверстия остаётся
   стенка 1,5 мм, насквозь надрез не прорезает. Резак — не «тело вращения с
   донышками», а фреза постоянного профиля, протянутая по дуге (`sweep` с
   `round_caps`): концы канавки скругляются **самим телом фрезы**, поэтому
   внутри надреза нет ни пятен, ни дисков-«кружков», ни острых углов.
   У соседних этажей надрез развёрнут на 180° (шахматка). Ширина 0,8 мм,
   шаг 1,8333 мм.
4. **Диаметральные пропилы на торцах с разной глубиной.** На торце пропил
   0,8 мм идёт **через весь диаметр**: с одной стороны он прорезан на всю
   глубину ступицы (до осевого канала), с другой — только **верхнее
   углубление** `slit_notch` = 2 мм на поверхности. Поэтому на торце видна
   прямая линия через всё лицо, но глубина у неё с двух сторон разная; внутри
   вдоль оси остаётся один диаметральный разрез. Пропил ступицы A лежит в
   плоскости XZ, ступицы B — в плоскости YZ.
5. **Два боковых отверстия — ХОРДОЙ, сквозные, с сужением к выходу.** Ось
   каждого отверстия смещена от оси муфты на `hole_chord` = 6,1 мм: в центр
   она не идёт, осевой канал Ø8 **не пересекает** (проверено булевым
   пересечением — ровно 0,000 мм³) и не подходит к нему вплотную: между
   стенкой канала и отверстием остаётся 0,85 мм по малому концу и 0,6 мм по
   большому. Оси двух отверстий взаимно перпендикулярны.

   | Ступень | Размер | Что видно |
   |---|---|---|
   | **большой конец** (вход) | гнездо **Ø3,0 × 1,7 мм**, ось по хорде | круглый карман на наружной поверхности, в нём — головка втулки |
   | **сужение** | ступень с Ø3,0 на Ø2,5 на глубине 1,7 мм | внутри видна ступень/буртик, дальше идёт только резьбовой канал |
   | **малый конец** (выход) | **Ø2,5**, шаг 0,9 мм, виток 0,3 мм | с другой стороны стенки — маленькое круглое отверстие с резьбой |
   | втулка-винт | отдельная деталь: цилиндр **Ø2,8** с наружной резьбой 0,8 мм + хвостовик Ø2,4 | ввёрнута в гнездо, головка утоплена на 1,4 мм |
   | шестигранное углубление | `prism sides=6`, радиус 0,8 (**1,6 мм по вершинам**), глубина 1,0 мм | идёт **вдоль оси** втулки, под шестигранный ключ |

   Важно: шестигранник — это **не гайка и не призма снаружи**. Наружная форма
   втулки круглая (цилиндр), шестигранник — углубление внутри её торца.
   Плоскости двух отверстий перпендикулярны: A — по оси Y (перед), B — по
   оси X (право); обе оси проходят мимо центра.

6. **Материал** — пластик (в модели светло-серый); в исполнении `C` —
   алюминий, как на большей части фото.

## 4. Из чего собирать в Forma (план после согласования)

| Элемент | Команды |
|---|---|
| корпус с фасками | `lathe` по профилю с фаской 0,5 |
| отверстие с зенковкой | `lathe` (профиль отверстия) + `difference` |
| хордовые отверстия | гнездо `cylinder` Ø3,0 + `cylinder` Ø2,44 (гладкий канал) + `thread diameter=2.5` (резьба) → `rotate` → `translate` (хорда 6,1 мм) → `difference` ×2 |
| втулки-винты | `thread` (наружная резьба) − `prism sides=6` (углубление) → `rotate` → `translate` |
| надрезы пояса | `sweep` профиля по дуге `path` + `cylinder` Ø cut_w (рунд на концах) → `difference` ×6 |
| диаметральные пропилы | `box` (мелкий на весь диаметр + глубокий на одну сторону) → `difference` |
| материалы | `color`, `scene`, `light` |

Размеры выносятся в `param`/`derive`, чтобы модель пересчитывалась при
изменении D, L, L1, L2 или отверстия. **Ядро (интерпретатор Forma) не
меняется** — только сцена-пример.

## 5. Проверки, которые должна пройти новая сборка

```
check корпус watertight      — оболочка замкнута
check корпус parts 1         — тело одно, прорези его не разорвали
check корпус height 25.9..26.1
check корпус tris ..120000
```

Плюс контроль по отчёту сборки: габарит 20 × 20 × 26, объём ≈6,0 см³,
род тела = числу перемычек, каждая прорезь выходит на наружную поверхность
и в отверстие, ни одна не пересекает соседнюю.

## 6. Что осталось допущением

- **Масса 5,0 г не сходится с геометрией.** Объём только заготовки
  (кольцо Ø20/Ø8 длиной 26) — 6,86 см³; модель даёт 5,74 см³, то есть 7,1 г
  при плотности 1,4 г/см³. Чтобы деталь весила 5 г, плотность должна быть
  0,97 г/см³ — похоже, в таблице масса скопирована из строки CPI-12C.
- **Цвет.** В магазине на фото алюминиевое исполнение (`C`, серебристое), а
  заказано пластиковое (`P`). В модели пластик светло-серый; материал
  задаётся одной командой `color`.
- **Шаг надрезов** 11 / 6 = 1,8333 мм — из «шести этажей» и пояса 11 мм.
- **Смещение хорды 6,1 мм** подобрано по трём жёстким условиям сразу:
  1. **не пересекать канал Ø8** — внутренняя стенка отверстия Ø2,5 при хорде
     6,1 стоит на радиусе 6,1 − 1,25 = 4,85 против радиуса канала 4,0, то есть
     0,85 мм материала. Булево пересечение «канал ∩ отверстие» = **0 мм³**;
  2. **гнездо Ø3,0 не должно выходить наружу через кривую стенку** — его
     кромка лежит на радиусе √((6,1+1,5)² + (7,92−1,7)²) = 9,82 < 10;
  3. **оси не должны сходиться в центр** — это и есть «хорда».
  При меньшей хорде (4 мм) отверстие Ø2,5 вскрывало канал Ø8 — именно на это
  и была претензия по фото; при большей хорде гнездо прорывает наружную
  стенку «языком». 6,1 мм — единственное окно, где выполняются все три.

## 6а. Что проверяет сама сцена

```
check корпус watertight      — оболочка замкнута
check корпус parts 1         — тело одно
check корпус height 25.9..26.1
check корпус tris ..120000
```

Фактические метрики сборки: габарит **20,00 × 20,00 × 26,00 мм**, объём
**5,850 см³**, масса **7,25 г** при 1,24 г/см³, **69 504 треугольника**,
частей — **3** (корпус и две втулки-винта). Площадь поверхности 53,5 см²,
род тела 12, плоское дно 3,96 %, нависания 21,1 %. GLB — 2,94 МБ.

### 6б. Что можно крутить в панели параметров

`cut_arc` — угол боковых надрезов (90…350°), `cut_depth` — их глубина,
`cut_w` — ширина, `cut_end_k` — радиус круглого окончания реза в долях
полуширины (1 = ровно фреза Ø cut_w); `slit_w` — ширина диаметрального
пропила, `slit_notch` — глубина верхнего углубления (мелкой стороны пропила),
`slit_inner` — где глубокий пропил останавливается от оси; `hole_chord` —
смещение оси винта от оси муфты, `cb_d`/`cb_depth` — большой конец (гнездо),
`thr_d`/`thr_pitch` — малый конец (резьба), `hex_sock`/`hex_sock_h` —
шестигранное углубление втулки. Плюс базовые `D`, `L`, `L1`, `L2`, `d_bore`.

### 6в. Почему кромки отверстий не гранёные

Три причины дефектов «огранки» и «сколов», найденные и устранённые:

1. **Точность задавалась в конце файла.** Строка `precision` стоит *до*
   построения; иначе всё считается по допуску 0,06 мм. Хуже того: если у
   `cylinder`/`lathe` указан явный `segments=…`, операция **всё равно** режет
   число сегментов по 0,06 мм — круглая дырка Ø5 получала **16 граней**.
   В сцене явного `segments` нет, а сверху стоит
   `precision mode=ultra tolerance=0.005` → Ø5 получает **104 сегмента**,
   корпус — 200.
2. **Фаска отдельным конусом на смещённом входе.** Ось отверстия идёт под 41°
   к нормали стенки, поэтому мелкая фаска ложится клином: на одной стороне
   она есть, на другой нет — получался «скол». Фаска убрана, кромка ровная.
3. **Резьба, доведённая до самой кромки выхода.** Витки на выходе пересекают
   кривую стенку почти по касательной и оставляют тонкие лепестки. Теперь
   резьба укорочена на 1,2 мм с каждой стороны (`thr_len = 2·surf − 2,4`), а
   сквозной канал даёт гладкий цилиндр Ø2,44 — на выходе ровный круг, ни
   одного лепестка.
4. **Совпадающие поверхности.** Если гладкий канал делать ровно Ø2,5 — он
   ложится **точно на вершины витков** и даёт 2784 схлопнувшиеся грани и
   33 non-manifold ребра (GLB не экспортировался). Канал уменьшен на 0,06 мм,
   вершины витков остаются рабочими — экспорт проходит.
