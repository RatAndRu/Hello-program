# Dragon Sovereign

Параметрическая скульптура дракона по трём визуальным референсам пользователя.
Это художественная реконструкция, **не фотограмметрия**: абсолютный масштаб и
невидимые поверхности из изображений не восстанавливаются однозначно.

## Файлы

- `forma/examples/dragon_sovereign.forma` — самодостаточная редактируемая сцена
  для Forma 0.59; внешние mesh, текстуры и референсы для её открытия не нужны.
- `forma/docs/make_dragon_sovereign.py` — генератор сценария, контрольных видов,
  GLB и JSON-паспорта.
- `forma/exports/dragon_sovereign/dragon_sovereign.glb` — Blender-совместимый
  экспорт с узлами `dragon`, `base`, `eye_L`, `eye_R`.
- `forma/exports/dragon_sovereign/dragon_sovereign_full_report.json` — исходная
  и экспортная топология, размеры, SHA-256 и контрольные ракурсы.

GLB и производные рендеры следуют существующим ignore-правилам репозитория и
публикуются как release assets, а не как большие бинарные файлы в Git.

## Масштаб и пропорции

Проектная высота дракона — 360 мм. Она выбрана как удобная единица компоновки,
а не измерена по фотографии. Основные отношения:

| Элемент | Проектное отношение |
|---|---:|
| диаметр основания / высота | 0,61 |
| размах крыльев / высота | около 1,0 |
| торс / высота | около 0,36 |
| шея и голова / высота | около 0,34 |

Канон координат: `+Z` вверх, `−Z` низ, `+X` право, `−X` лево, `−Y` перед,
`+Y` зад. Спина, вторая сторона пасти и нижняя часть основания достроены по
аналогии с видимыми участками.

## Конструкция

- Мышцы торса, S-образная шея, открытые челюсти, конечности и пальцы построены
  как сглаженные SDF-поля; отдельные шары в готовом теле не используются.
- Крылья имеют собственный анатомический контур, пять неравных пальцев,
  объёмное плечо, вогнутые секции и замкнутую мембрану толщиной 0,9 мм.
  Небольшой twist создаёт реальную пространственную кривизну.
- Зубы и когти — отдельные tapered-sweep-тела. Корни зубов вычисляются по
  фактическим эллипсоидным поверхностям верхней и нижней десны.
- Чешуя — 363 плоские пятиугольные пластины с ray-cast-посадкой на реальный торс,
  небольшим наклоном и микрозазорами. У корня хвоста оставлен гладкий участок:
  одна потенциальная пластина была исключена, чтобы не замыкать второй контакт
  между хвостом и торсом.
- Грудные пластины следуют меняющемуся по высоте профилю живота, а не строятся
  на одной фиксированной глубине.
- Камни основания связаны через основной камень без замкнутых пустот.

Финальная сцена содержит цельного дракона, цельное основание и две отдельные
глазные вставки. Все четыре объекта имеют имена и отдельные GLB-узлы.

## Проверенный результат

Проверка выполнена на исходных Manifold-телах и повторно на самом GLB после
импорта. Перед анализом GLB дубли вершин с UV/normal seams свариваются только по
координатам; это не repair и не изменение граней.

| Объект | Треугольники GLB | Компоненты | Род | Boundary | Non-manifold | Degenerate |
|---|---:|---:|---:|---:|---:|---:|
| dragon | 156 470 | 1 | 0 | 0 | 0 | 0 |
| base | 2 798 | 1 | 0 | 0 | 0 | 0 |
| eye_L / eye_R | 512 + 512 | 1 + 1 | 0 | 0 | 0 | 0 |

Дополнительно:

- статус всех тел — `Error.NoError`;
- наконечник хвоста имеет с хвостом объём пересечения 27,26 мм³;
- ray-cast picking на экспортированном GLB: малая сцена 1/1, полный состав 4/4;
- проверены изометрия, спереди, справа, сзади и сверху;
- итоговый GLB — 5 116 544 байта;
- SHA-256 GLB — `22295198ac2663c921bbd5b2d1e88535e205676bdaa56ae41e288d71cd55a698`.

## Повторная генерация

Из корня репозитория, с зависимостями `forma/requirements.txt`:

```bash
PYTHONPATH=forma python forma/docs/make_dragon_sovereign.py --stage silhouette
PYTHONPATH=forma python forma/docs/make_dragon_sovereign.py --stage full
```

`--no-render` пропускает только PNG, но не геометрический и GLB-контроль.
В showcase и ядро приложения эта модель не добавляется.
