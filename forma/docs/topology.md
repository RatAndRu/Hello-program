# Forma 0.59: топология твёрдых тел и честный экспорт

## Что было принято из аудита

Для Forma применимы правила **замкнутого треугольного твёрдого тела**: конечные
координаты, невырожденные грани, ровно две согласованно ориентированные грани на
внутреннем ребре, отсутствие границ и неоднозначных рёбер. Сохраняются число
частей, назначение отверстий и топологический род.

Правила quad/SubD, анимации и скиннинга — петли, полюса, валентность вершины и
«красивые» квады — не объявляются ошибками Manifold. Иглы на плоскости,
неравномерная плотность и вытянутые треугольники остаются контекстными
предупреждениями: одного такого признака недостаточно для изменения формы.

Диагностика и лечение разделены. Допуск сварки в отчёте не даёт разрешения
удалить близкую грань или закрыть отверстие в исходной модели.

## Что изменилось в ядре

- `forma/topology.py` содержит единый аудит соседних ячеек и union-find сварки,
  структурные счётчики и отдельные метрики качества.
- Все mesh-экспорты используют один фильтр в фактической точности float32.
  Перед записью GLB экспортная копия проходит structural gate; открытая или
  неоднозначная сетка не выдаётся за успешный файл.
- Guarded weld выполняется только в экспортной копии. Кандидат заново
  конструируется как Manifold и принимается лишь при `NoError`, нулевых
  структурных ошибках, прежних рода/частях, объёме, площади и габаритах в узких
  пределах. Иначе сохраняется консервативная исходная копия, а gate сообщает
  ошибку.
- Адаптивный SDF cleanup начинается с малого допуска относительно шага сетки и
  проверяет кандидатов только от исходной сетки. Глобальное увеличение допуска
  не используется: оно немонотонно и может создать новые дефекты.
- `check <объект> topology` использует ту же экспортную диагностику. Отчёт
  содержит структурные ошибки, площадь игл, долю игл на изгибе и разброс рёбер.
- В `expand` убраны совпадающие крышки на посадочных и flush-стыках. Для
  посадки большая половина продлевается только внутрь пояса. Для flush выбор
  вспомогательной перемычки охраняется обычным и точным аудитом, родом, числом
  частей, объёмом, площадью и bbox; меньшая половина не деформируется.

## Воспроизведённые примеры: до и после

Плохие случаи находятся в `tests/test_topology.py`, а не в меню проектов.
До правки были получены описанные ниже ошибки; после правки те же сценарии
экспортируются и повторно импортируются.

| Сцена / fixture | До | После |
|---|---:|---:|
| `gear teeth=36 module=2.6 thickness=8 bore=5 hub=12` | 32 вырожденные грани | 0, точный watertight/winding |
| `bulb shape=candle … segments=48` | 64 вырожденные грани у корня | 0, точный watertight/winding |
| `alien` | 19 056 треугольников, 3 NM-ребра | 16 224, 0 структурных ошибок |
| `clock` | 50 062 треугольника, 6 вырожденных | 50 062, 0 структурных ошибок |
| гостиная | 140 168 треугольника, 96 вырожденных + loose vertex | 140 168, 0 структурных ошибок |
| фото-кронштейн | 413 346 исходных треугольников | 413 310; 18 вершин сварено, 36 нулевых граней удалено; genus 3 и одна часть сохранены |
| `шар_колпачок`, `expand_joint=посадка` | 44 NM-ребра, 34 нулевые грани, genus 3 | 0 NM/границ/вырождений, genus 0 |
| вся `glyphs_expansion_053` | 57 162 треугольника, GLB остановлен gate | 56 950, 7/7 замкнутых оболочек |

Для `alien` объём тела изменился примерно на −0,0885 % при выборе guarded
SDF-кандидата; это явно измерено, а не скрыто. Габариты и назначение частей
сохранены. У кронштейна род 3 относится к существующим конструктивным
промежуткам и сквозному отверстию, поэтому автоматически не «исправляется».

Дополнительно проверена матрица `sphere/ellipsoid/capsule/box`: 40 посадочных и
16 flush-случаев, обе стороны и разные значения `expand_smooth`. Все итоговые
экспортные копии прошли обычный и точный аудит. Прежняя проверка неизменности
противоположной половины также проходит.

## Как пользоваться диагностикой

```forma
деталь = gear teeth=36 module=2.6 thickness=8 bore=5 hub=12
check деталь topology
check деталь watertight
```

`ok` у topology означает только структурную пригодность треугольного тела. Он
не заменяет визуальную проверку силуэта, соединений, пустот, размеров и
размещения. Предупреждение о плотности не является разрешением на decimate или
Loop-сглаживание.

Нулевые грани удаляются до разбиения вершин по нормалям/UV. Разведённые швы
нормалей в GLB не считаются дырками: аудит сваривает диагностическую копию по
координатам. После записи дополнительно выполняется независимый round-trip с
точной проверкой watertight и winding.

## Воспроизведение проверок

```bash
cd forma/tests
PYTHONPATH=.. python -m unittest test_topology -v
PYTHONPATH=.. python -m unittest test_regressions -v
PYTHONPATH=.. python -m unittest test_v048_acceptance.BarrelTilesExpansionTest -v
```

Перед публикацией маленькая picking-сцена дала 7/7 выбираемых деталей, а один
полный проход семи GLB — 311/311 объектов, включая все 60 деталей часов и 238
деталей комнаты. Локальный набор topology + общих регрессий: 38/38.

Стенд 0.59 показывает только существующий `examples/alien.forma` и изменения
этой версии. Тестовые fixtures и старые версионные выставки в основное меню
программы не добавляются.
