# Гостиная 1:20 — параметрическая миниатюра

Отдельный проект комнаты, созданный только командами Forma и собственной параметрической генерацией повторяющихся деталей. Внешние 3D-модели, импортированные сетки, текстуры и чужие координатные шаблоны не используются.

## Содержимое сцены

- Витринное основание с табличкой, деревянный пол из отдельных планок со стыками вразбежку.
- Внутренний размер комнаты 320 × 240 × 140 мм. Задняя и левая стены полные; передняя и правая показаны низким архитектурным срезом для обзора.
- Сквозной дверной проём, открытая на 30° дверь с углублёнными панелями, петлями и ручкой.
- Сквозной оконный проём, четыре стекла, рама и переплёт, ручка, наличники, подоконник, карниз и шторы.
- Трёхместный диван с подушками и пледом, овальный журнальный стол, ковёр и пуф.
- Телевизор на ножках, ТВ-тумба с настоящей нишей, ящиками, ресивером и саундбаром.
- Пульт с отдельными кнопками лежит на столешнице; рядом чашка с полостью, кофе и ручкой.
- Придиванный столик с книгой, книжный шкаф с книгами и корзиной, торшер с полым абажуром, растение и настенные часы.

## Файлы

- `forma/examples/living_room_diorama.forma` — самодостаточная исходная сцена.
- `forma/docs/make_living_room.py` — воспроизводимый генератор, проверки, GLB-экспорт и рендеры.
- `forma/exports/living_room/living_room_diorama.glb` — экспортированная модель.
- `forma/renders/living_room/living_room_iso.png` — основной вид.
- `forma/renders/living_room/living_room_views.png` — лист с четырьмя видами.
- `forma/renders/living_room/living_room_table_detail.png` — крупный вид пульта, чашки и стола.
- `forma/renders/living_room/validation.json` — численный отчёт проверки.
- `forma/docs/living_room_primitive_ideas.md` — только предложения будущих инструментов, без внедрения.

## Пересборка

Из корня репозитория, при установленных NumPy, Manifold3D, Pillow и trimesh:

```bash
PYTHONPATH=forma python forma/docs/make_living_room.py
```

## Проверка результата

- 218 видимых объектов, 57 462 исходных треугольника до экспортного разбиения по нормалям.
- Все тела непустые, имеют положительный объём и статус `NoError`.
- Объёмный зонд в дверном проёме: 0 мм³ стены.
- Объёмный зонд в оконном проёме: 0 мм³ стены.
- Нежелательные пересечения между сборками мебели: 0. Намеренные соединения рамы/двери/часов со стеной исключены из этого отчёта.
- Низ корпуса пульта и низ чашки: z = 27 мм, то есть точно на плоской столешнице.
- Основной вид, вид сверху, спереди, справа и детальный вид визуально проверены.
