# Библиотеки и измерения — Форма 3D 0.76.4

## Что добавлено

* FastNoiseLite через PyFastNoiseLite 0.0.7: `wrinkle [деталь] mode=шум
  engine=fastnoise noise_kind=simplex|perlin|value|cellular amp=1 freq=5 seed=7`.
  Без `engine` остаётся старый генератор, проекты не меняются. `cellular` —
  значение по расстояниям до двух ячеек, а не генератор готовой пены, осколков
  или чешуи. Domain warping в этой Python-обёртке не реализован.
* В редакторе текстур и `texture … kind=своя` доступны `pattern=fastnoise` и
  `pattern=вороной`; из одной 2D-карты строятся цвет и нормали. Для повторения
  карты используется сглаженное периодическое смешивание. Общий движок шума
  **не означает**, что 2D-текстура совпадёт с 3D-рельефом: UV и координаты
  поверхности различаются. Визуальное совпадение разных рендереров не проверено.
* `scatter … distribution=poisson distance=11`: расстояние между **центрами в
  плоскости XY**, миллиметры. Если `distance` не задано, выбирается приближённое
  значение по площади и числу точек. `gap` дополнительно учитывает габариты
  деталей консервативными окружностями. Без gap большие или вытянутые детали
  могут пересечься. Область `on=` — XY-габарит и высота верха, не размещение по
  кривой поверхности. Если разместить все детали нельзя, команда выдаёт ошибку.
  По умолчанию остаётся прежний `distribution=random` и прежний seed.
* Исправлен поиск ближайшего треугольника при измерении расстояний: вместо
  корзин центроидов используется дерево полных ограничивающих объёмов (BVH).
  В отчёте simplify отклонение помечено как **найденное по выборке**. Ни выборка,
  ни сравнение объёма не доказывают сохранность всех мелких отверстий и стенок.
* Пример: `examples/noise_scatter_0764.forma` — 21 видимый объект, 8440
  треугольников в проверке на Linux; проект можно открыть и менять.

## Что действительно измерено

Локально: Linux x86-64, Python 3.11, NumPy 2.4.6, manifold3d 3.5.5;
один поток OpenBLAS/OMP. Время зависит от машины; это не обещание скорости на
Windows. Шумы дают разные узоры и не являются взаимозаменяемыми побитно.

| Проба | Результат |
|---|---|
| 100 000 трёхмерных точек, 3 октавы, 3 запуска | FastNoiseLite: 0,015–0,018 с; прежний 3D `_fbm`: 0,062–0,073 с. Оба конечные и повторяются при том же seed. |
| Реальная сфера с рельефом, 30 672 треугольника, 3 сборки | прежний шум: 0,134–0,167 с; FastNoiseLite: 0,046–0,098 с, включая первую загрузку. Совокупный пик RSS процесса около 70,3 МиБ, не отдельный замер каждой библиотеки. |
| 100 центров в квадрате 100×100 мм, seed=7 | случайно: ближайшие центры от 1,89 мм; Poisson Формы при distance=7: от 7,03 мм, 0,0079 с; SciPy PoissonDisk: от 7,02 мм, 0,0469 с. У методов разные последовательности и накладные расходы. |
| Ближайшая точка: сфера 5000 граней, 400 запросов | собственный BVH 0,61 с, Point Cloud Utils 0,0063 с; максимальная разница примерно 2,7e-15 мм. Это только один тест, не общая оценка скорости. |
| Длинный треугольник плюс 3001 мелкий | старый поиск возвращал 0,15 и 0,953 мм вместо 0,05 мм; новый совпал с полным перебором и Point Cloud Utils: 0,05 мм для обеих проб. |
| Упрощение сферы с цилиндрическим отверстием | fast-simplification: 3376 → 1688 граней за 0,0025 с, mesh принят manifold3d, максимальное отклонение по 399 пробам 0,114 мм. Manifold simplify с допуском 0,4 мм: 1608 граней за 0,0084 с. Критерии разные; один пример не доказывает превосходства. |

Тесты в `tests/test_libraries_0764.py` проверяют повторяемость, выбранные типы
шума, материалы/GLB, расстояние центров, невозможную плотность, сохранение
старых режимов и BVH против полного перебора. Проверка собранного EXE запускает
готовый пример через API, проверяет 18 объектов, расстояния и normal map.

## Решение по зависимостям

* **Встроен FastNoiseLite**: Windows CPython 3.12 x64 wheel 0.0.7 доступен;
  его размер на PyPI около 0,10 МБ. Лицензии ядра и обёртки MIT находятся в
  `ЛИЦЕНЗИИ/` полного ZIP, включены в EXE и приложены к релизу.
* **Poisson-disk** реализован внутри Формы по идее алгоритма Bridson (2007),
  без копирования кода SciPy. Сравнен с `scipy.stats.qmc.PoissonDisk`.
* **Point Cloud Utils 0.34.0** проверен локально; его пакет требует SciPy.
  Windows wheel PCU около 5,43 МБ, SciPy 1.18.1 — около 36,66 МБ ещё до
  распаковки. Текущая сборка EXE исключает SciPy; в этой версии они не включены.
* **fast-simplification 0.2.0** проверен на одном теле, но не встроен: нужно
  сравнить тонкие стенки, отверстия, допуски и Windows EXE на большем наборе.
* Shapely, scikit-image, embreex, libigl, Voro++, OpenVDB и рост ветвей в этом
  прогоне не испытывались и не встроены. Пространственный паспорт как отдельный
  новый инструмент не добавлен: пока улучшена достоверность одной из его
  существующих измерительных основ.
