# Этап 3 — оригами и механизмы

Документ описывает текущий контракт версии 0.65. Все размеры в мм, верх — `+Z`.

## Ограниченная история и разгиб

`fold`, `fold_sheet` и `сгиб`/`fold_along` сохраняют только локальную историю листа: параметры, линии складок и скрытый snapshot состояния до операции. На объекте хранится до 8 последних записей, на сцене — до 32. Это не дерево истории всех тел и не обязательный параметрический CAD-контейнер.

```forma
лист = fold_sheet width=120 length=200 thickness=1 angle=80
разгиб = unfold лист groove=0.5 depth=0.2
```

`unfold` восстанавливает snapshot до последней складки и вычитает настоящую канавку шириной `groove` и глубиной `depth`. Координаты канавок соответствуют фактическим центрам дуг гармошки, включая длину дуг, а не условному делению bounding box. Поэтому разогнутый лист плоский, но не является нетронутым исходным телом: в нём остаётся след фиктивного сгиба. `groove=0` отключает канавку, `all=да` разгибает всю сохранённую историю этого листа. Если snapshot уже вытеснен лимитом, команда сообщает об этом, а не выдаёт приближение за точный разгиб.

## FOLD и ORIPA .cp

```bash
python -m forma export model.forma --format fold --out model.fold
python -m forma export model.forma --format cp --out model.cp
```

В интерфейсе те же действия доступны в меню **Экспорт → FOLD / .cp**. FOLD сохраняет стандартные `vertices_coords`, `edges_vertices`, `edges_assignment`, `edges_foldAngle`; типы рёбер — `B`, `M`, `V`, `A`, `U`, `F`. `.cp` использует числовые коды ORIPA, единый масштаб и центрирование в квадрате 0…1 без изменения углов; при импорте без явных размеров сохраняется соотношение сторон. Boundary-рёбра или граница `faces_vertices` задают настоящий многоугольный контур листа.

Импорт выполняется командой:

```forma
схема = fold_pattern file=pattern.fold thickness=0.6 at=[0,0,0]
# или: схема = fold_pattern file=pattern.cp width=160 length=160
```

Импорт создаёт лист постоянной толщины, записывает линии Mountain/Valley и позволяет дальше применять обычные операции сгиба. Это поддержка обмена развёрткой, а не общий rigid-origami solver: произвольная схема с одновременными контактами, самопересечениями и неоднозначными состояниями не складывается автоматически.

## Реальный пакет

```forma
слой = sheet width=160 length=220 thickness=0.8
пакет = packet слой layers=6 gap=0.15 axis=z
```

Каждый слой — настоящая копия объёма. Толщина пакета равна `layers × layer_thickness + (layers−1) × gap`, а не только числу в карточке.

## Hinge/slider-кинематика

`hinge` остаётся командой параметрической дверной петли. Для движения существующей детали используются отдельные команды:

```forma
створка = hinge_move дверь angle=90 axis=z pivot=[0,0,0] against=[стена] steps=16
ящик = slider ящик distance=120 direction=[0,-1,0] against=[корпус] steps=12
```

Проверяются промежуточные положения, AABB-отбор дополняется точным объёмом пересечения Manifold. По умолчанию столкновение останавливает операцию и называет пару объектов. `allow=да` сохраняет движение и записывает столкновения в `scene.mechanisms`. Это управляемая кинематика и геометрическая проверка, не динамика с массой, силами и не FEA.

## Надрезы с kerf

```forma
рез = kerf_cut лист from=[0,-100,0.5] to=[0,100,0.5] kerf=0.6
биг = kerf_cut лист from=[0,-100,1] to=[0,100,1] kerf=0.5 depth=0.2 side=top
```

`kerf` — полная ширина реза. Без `depth` рез сквозной и оставляет физический зазор; с `depth` создаётся неглубокая канавка с заданной глубиной внутри материала. Технологический малый выход cutter наружу не добавляет лишнюю глубину детали.

## Проект Arte Lamp Banker A2492LT-1AB

Исходник: `forma/examples/arte_lamp_banker_a2492lt_1ab.forma`, также доступен в постоянном каталоге проектов. Это отдельная редактируемая модель по трём референсам, а не новый одноимённый примитив.

- общая высота: **ровно 400 мм**;
- основание: Ø180 мм, плавный купол и ступенчатый обод;
- абажур: 240×110×90 мм, вертикальные стенки и арочная крыша;
- зелёная наружная оболочка и светлый вкладыш имеют открытый низ и настоящую толщину;
- колонна, шарнир, изогнутая стойка, боковые крепления, задний П-образный держатель, рама, лампочка, цоколь, цепочка и наконечник — отдельные детали;
- 30 бусин цепочки создаются `array ... as=objects` и выбираются по отдельности.

Проверки `tests/test_stage3_origami.py` (17 тестов) и `tests/test_banker_lamp.py` (6 тестов) измеряют габариты, высоту, статус Manifold, отсутствие непредусмотренных пересечений, пустоту пробным телом и лучом снизу, состав GLB и наличие проекта в каталоге. Дополнительно выполняются изометрические, передний, боковой, задний и нижний визуальные рендеры; технический `NoError` сам по себе визуальной приёмкой не считается.
