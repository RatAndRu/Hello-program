# Драпировка: устранение колебаний и повторная проверка

**Это промежуточное исправление, не готовый контактный решатель и не новый
выпуск EXE.** Результаты ниже выявляют нарушения обязательных требований:
проникновение в опоры, потерю толщины и недостаточную сходимость. Новую
сборку выпускать нельзя, пока эти дефекты не устранены и все шесть сцен не
перепроверены.

## Что изменено

В существующем решателе каждый шаг теперь начинает проход ограничений рёбер
в одном и том же порядке, сохраняя чередование порядка **внутри** шага.
Прежняя смена порядка между шагами могла создавать численный двухшаговый
цикл. Например, в отдельной проверке мягкого шара с `g=0.05`,
`constraints=60`, пределом `steps=140` и остальными параметрами штатной сцены
порог малого движения достигнут на шаге 89: последнее смещение 0,00106 мм
при пороге 0,0025 мм. Шар при этом уменьшился по высоте с 28 до 26,33 мм,
максимальное изменение ребра составило 4,21%. При старом порядке тот же
эксперимент продолжал колебаться: 0,07495 мм на шаге 300. Порог движения не
является проверкой баланса сил; `equilibrium_verified` остаётся `false`.

Добавлено измерение нормальной проекции **найденных** пар стенки и
предупреждение при заметном изменении. Сохранение одной только длины пары
недостаточно: пара может наклониться при сжатии нормальной толщины. Это
измерение использует сглаженные нормали и не является полной картой толщины.
Поле `wall_thickness_verified` специально не заявляет, что толщина проверена
целиком. Аудит также показывает инверсии в контрольной призменной сетке;
некоторые её граничные диагонали отличаются от исходных, поэтому это отдельная
диагностика, а не точная тетраэдрализация исходной поверхности.

## Шесть исходных сцен после изменения порядка

Фактический запуск на Linux, Python 3.11.2, NumPy 2.4.6, Manifold3D 3.5.4,
Trimesh 5.2.0, python-fcl 0.7.0.11 и IPC Toolkit 1.6.1. Параметры исходных
`.forma` не менялись. Все шесть сцен и их GLB имеют меньше 100 000 видимых
треугольников. Полный отчёт с SHA-256 исходников и сценариев:
[`audit-fixed-order.json`](../benchmarks/drape_six/audit-fixed-order.json).

| Сцена | FCL опор / объём boolean | CCD | Макс. изменение ребра | Проекция пар стенки, мин.–макс. | Последний шаг / порог, мм |
|---|---|---|---:|---:|---:|
| Лист на шаре и площадке | шар: 100 пар / **32,44567 мм³** | сбой на шаге 2/55 | 8,38% | 93,50–103,56% | 0,1221 / 0,005 |
| Лист на плоскости | 0 / 0 | 11/11 | 0,00290% | 99,9986–99,9998% | 0,000083 / 0,005 |
| Мягкий шар | 0 / 0 | 100/100 | 11,94% | не применяется | 0,00527 / 0,005 |
| Скатерть на столе | 0 / 0 | 70/70 | 6,84% | 95,66–102,38% | 0,2586 / 0,0075 |
| Полый рукав на плоскости | 0 / 0 | 80/80 | 8,84% | 91,97–104,43% | 0,1322 / 0,005 |
| Рукав вокруг капсулы | капсула: 431 пара / **79,32126 мм³** | сбой на шаге 36/100 | 15,87% | 92,94–100,07% | 0,0817 / 0,005 |

Проверка FCL считает как пересечение, так и касание; положительный объём
пересечения подтверждён отдельно boolean. В конечных кадрах FCL не выявила
самопересечений несоседних или уменьшенных соседних граней. CCD проверяет
линейные переходы между концами шагов **после размещения**, не проверяет
промежуточные проекции и соседние примитивы. Она не доказывает сохранение
толщины или равновесие. До порога малого движения дошёл только лист на
плоскости; баланс сил не проверялся ни в одной сцене.

Шар изменил высоту 28 → 24,10 мм. Углы четырёх краёв скатерти к вертикали
составили 70,7–81,9°, то есть требуемого почти вертикального свисания нет.
Скатерти не требуется достигать пола.

## Почему контактные опыты пока не включены

Проверялись отдельные варианты коррекции треугольников, отката и жёсткого
удержания пар стенки. Некоторые сочетания обеспечивали почти неизменную
проекцию найденных пар и отсутствие конечного проникновения в отдельных
сценах, но не все условия одновременно. Например, в опыте с рукавом на
капсуле непрерывная проверка прошла 100/100 шагов и boolean дал ноль, но одно
ребро изменилось на 15,22%, а движение осталось 0,254 мм за шаг. В опыте со
скатертью при почти вертикальном свисании обнаружены 54 несоседние и 16
уменьшенных соседних пересечений FCL; CCD не подтвердила шаг 93. Другой опыт
с контрольной непрерывной проверкой избежал найденных конечных пересечений,
но не достиг порога остановки и не сохранил все поверхностные рёбра.

Эти одноразовые опытные коррекции **не являются частью приложения** и не
обосновывают выпуск. Контакт граней, непрерывный откат, трение и совместное
сохранение размеров и толщины ещё нужно довести и проверить вместе. IPC
Toolkit использовался для диагностики, а не добавлен как зависимость Windows
программы.

## Повторить штатную диагностику

```sh
python -m pip install numpy manifold3d trimesh python-fcl ipctk
OPENBLAS_NUM_THREADS=1 PYTHONPATH=forma python forma/tools/drape_six_probe.py \
  --mode current --fcl --ccd --glb --output six-current.json
```

Для тестов изменений порядка и измерений стенки:

```sh
OPENBLAS_NUM_THREADS=1 PYTHONPATH=forma python -m pytest -q \
  forma/tests/test_drape_step_order.py forma/tests/test_drape_six_probe.py
```
