# Каталог внешних источников: что можно брать, а что нельзя

Дата проверки: **2026-11-03**. Проверялись только источники, у которых лицензия
видна в первоисточнике (файл `LICENSE` в репозитории, страница лицензии сайта,
условия использования). Обзоры и «все знают, что CC0» — не доказательство.

Критерий заказчика жёсткий: **коммерческое использование без упоминания автора**,
и «делать с моделями что угодно», включая перепродажу и правку.

---

## 1. Три уровня, а не «свободно/платно»

| Уровень | Что требует | Что это значит на практике |
|---|---|---|
| ✅ **CC0 / public domain** | ничего | можно всё, указание автора не нужно, можно не хранить даже лицензию |
| ⚠️ **MIT / BSD / Apache-2.0** | сохранить текст лицензии и копирайт **в исходниках** | в готовом изделии/рендере имя автора писать не надо; в репозитории — файл `LICENSE` с их строкой |
| ⛔ **LGPL / GPL / CC-BY / CC-BY-SA / CC-BY-NC / «только исследования»** | атрибуция, «наследование» лицензии или запрет коммерции | по умолчанию не берём; каждое исключение — отдельным решением с юристом |

Важная тонкость про MIT/BSD: «без указания авторства» относится к **продукту**.
Текст лицензии всё равно обязан ехать вместе с исходниками библиотеки. Это не
атрибуция в изделии и не мешает продавать напечатанную деталь — но файл
`THIRD-PARTY-LICENSES` в репозитории иметь придётся.

---

## 2. Методика проверки источника за пять минут

1. **Найти первоисточник, а не зеркало.** Модель на Printables с лицензией CC0
   может быть выложена туда копией чужой CC-BY-NC работы. Смотрим автора.
2. **Открыть файл лицензии, а не бейдж.** GitHub API часто возвращает
   `NOASSERTION` (так было с `kennetek/gridfinity-rebuilt-openscad`, где на
   самом деле MIT). Читаем `LICENSE` в репозитории.
3. **Проверить четыре слова**: `commercial`, `attribution`, `share-alike`,
   `no derivatives`. Первое разрешает продажу, второе — обязательство,
   третье — заразу на производные, четвёртое — запрет правки.
4. **Проверить не сайт, а ассет.** У Sketchfab, Thingiverse, Printables,
   MakerWorld, Poly Pizza лицензия **у каждой модели своя**. Фильтр «CC0» —
   единственный способ не ошибиться.
5. **Записать улику**: URL, дата, цитата строки лицензии. Через год сайт
   переедет, и доказывать будет нечем.

`THIRD-PARTY-LICENSES`.

## 4. Что брать нельзя (и почему это не переубедить)

| Источник | Причина отказа |
|---|---|
| [ShapeNet](https://shapenet.org/terms) | условия: «use the Database only for **non-commercial research and educational** purposes». Прямой запрет коммерции, плюс обязательная регистрация и цитирование |
| NopSCADlib ([nophead/NopSCADlib](https://github.com/nophead/NopSCADlib)) | **GPL-3.0**: библиотека «заражает» производный код |
| dotSCAD ([JustinSDK/dotSCAD](https://github.com/JustinSDK/dotSCAD)) | **LGPL-3.0**: нужна возможность замены библиотеки пользователем — для встроенного генератора неудобно |
| MCAD ([openscad/MCAD](https://github.com/openscad/MCAD)) | **LGPL-2.1** (по заголовкам файлов; GitHub API лицензию не определяет) — та же история |
| FreeCAD Fasteners Workbench | **GPL-2.0** |
| KiCad 3D-модели | **CC-BY-SA 4.0** с исключением: атрибуция обязательна, производные — под той же лицензией |
| [NASA 3D Resources](https://science.nasa.gov/3d-resources/) | формально public domain, но NASA **просит** указывать источник, **запрещает** использовать логотип/«meatball»/«worm» и намекать на одобрение; часть моделей — от сторонних авторов. Это не «совсем без упоминания» |
| Thingiverse / Printables / MakerWorld по умолчанию | лицензия у каждой модели, очень часто **CC-BY-NC** или **CC-BY-NC-SA**: в коммерцию нельзя |

Отдельно про **Blender**: GPL относится к самой программе и аддонам, но **не** к
`.blend`-файлам и не к геометрии, которую вы из него выводите
([FAQ Blender](https://www.blender.org/support/faq/)). Лицензия конкретной
модели при этом остаётся главной: «сделано в Blender» ничего не разрешает.

Отдельно про **CC-BY-SA**: для 3D-модели «наследование» касается производных
моделей, а не всего изделия. Но если вы печатаете и продаёте именно правленую
модель — это производная, и её придётся отдавать под той же лицензией. Для
закрытого продукта это неприемлемо.

Отдельно про **товарные знаки**: CC0-скан автомобиля не даёт права продавать
изделие «в форме Ferrari». Лицензия на модель не отменяет прав на дизайн,
логотипы и персонажей.

## 5. Что из этого можно параметризовать, а что нет

Это главный вопрос раунда. Ответ короткий: **параметризуется то, что задано
числами, а не треугольниками.**

| Класс источника | Пример | Что мы можем | Что не можем |
|---|---|---|---|
| **Процедурный генератор** (код с числами) | Gridfinity, BOSL2, MCAD | перенести как наши примитивы: `loft`, `array`, `difference`, `bore`; получить полноценную параметризацию (размер, высота, перегородки, отверстия) | — |
| **Параметрическая деталь** (FreeCAD/STEP с параметрами) | крепёж FreeCAD | импортировать **меш** готовой детали; наращивать вокруг неё параметрический интерфейс | изменить параметры внутри STEP нашими средствами — импорт даёт только геометрию |
| **Готовый меш** (GLB/STL/OBJ скульптуры) | паки Kenney/Quaternius, сканы | вписать в габарит, повернуть, просверлить крепёж, упростить (`simplify`), починить, привязать к сетке | «сделать ручку длиннее»: у меша нет ручки, есть только вершины |

Практический вывод: **чемпионы по универсальности — процедурные наборы**.
Тяжёлые CC0-паки хороши для наполнения сцен и фоновых объектов, но не для
деталей, которые заказчик будет менять по размерам.

## 6. Что уже сделано в коде под этот каталог

* `включить файл=…` — таблица размеров + фигуры, параметризация без Python.
  Рабочий пример: `forma/lib/fastener/` (умолчания → переопределение → фигуры).
* `forma lib` — реестр перенесённых библиотек: список, сборка сценария по
  параметрам, сразу проверка (`--check`).
* `forma/lib/gridfinity.py` — перенос Gridfinity (MIT) нашими `loft`/`array`:
  `forma lib gridfinity size=2x3 height=6 --check`.
* `import` — приём мешей GLB/OBJ/STL/PLY/3MF/`.blend`, дальше `simplify`, `repair`, `check`.
  Файл `.blend` читается через установленный Blender (`forma/blender.py`:
  `blend_to_glb`), обратный путь — `glb_to_blend`; то есть CC0-сцену из
  Blender можно взять как обстановку, а свою деталь — отдать обратно в Blender.
  Параметров у такой сцены нет: это меш с материалами, а не генератор.
* Отчёт по переносу и его честные границы: [`gridfinity_port.md`](gridfinity_port.md).

## 7. Оговорка

Это инженерная памятка, а не юридическое заключение. Лицензии меняются,
ассеты перезаливаются. Перед коммерческим релизом: сохранить копию текста
лицензии и URL на дату, а спорные случаи отдать юристу. Для продуктов, где
лицензия запрещает коммерцию, замена ассета дешевле спора.
