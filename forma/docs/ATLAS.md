# Атлас понятий Формы 3D

Плакат конструктивных элементов перечисляет **детали тела вращения**: фаска,
галтель, буртик, проточка, шлицы. Этого достаточно для валов, но не для
корпусов и не для поверхностей. Поэтому здесь три уровня, и каждый термин
определён так, чтобы его можно было проверить измерением:

1. **поверхность** — геометрический класс, из которого сделаны все грани;
2. **элемент** — узнаваемый кусок формы с собственными размерами;
3. **структура** — то, как элемент встроен в корпус: стенка, полость,
   перегородка, разъём.

Статус: ✅ — строится командой и проверяется; ◐ — строится с оговоркой;
✗ — понятия в языке пока нет (честный пробел, а не «сделаем вид, что есть»).

---

## 0. База описания

| Термин | Определение | В Форме |
|---|---|---|
| **Габарит** | Наименьший прямоугольный ящик, в который деталь входит целиком, по осям X, Y, Z. Размеры изделия, а не ядра. | ✅ `size` у примитивов; `check <деталь> size` |
| **Ядро** | Тело до наращивания выступов. Габарит = ядро + выступы. | ✅ считается внутри `face_box` |
| **База** | Поверхность, от которой отсчитываются все размеры детали. Обычно нижняя или привалочная. | ◐ `at`, `place … face=`, `check … symmetric` |
| **Ось симметрии** | Прямая, поворот вокруг которой переводит деталь в себя. | ✅ `check … symmetric x/y/z`, `axis` |
| **Плоскость симметрии** | Плоскость, отражение относительно которой переводит деталь в себя. | ✅ `check … symmetric <плоскость>` |
| **Сопряжение** | Характер контакта двух деталей: встык, внахлёст, с зазором, с натягом. | ◐ `expand_seat`, `relief` («припуск»), `gap` |
| **Посадка** | Сопряжение по поверхности с нормированным зазором или натягом (H7/g6 и т. п.). | ✗ в языке есть только зазор в мм |
| **Стандартизованность** | Свойство элемента браться из нормированного ряда, а не назначаться на глаз: диаметры подшипников, шаги резьбы, размеры «под ключ», радиусы галтелей. Стандартный элемент узнаётся по числу, а не по форме. | ◐ числа берутся из рядов вручную; готовые ряды есть только у резьбы (`thread pitch=`), шестигранника (`nut`, `prism sides=6`) и подшипников (`bearing`) |

## 1. Поверхности

Класс поверхности — это то, чем деталь ограничена. Шесть классов покрывают
почти всё, что делают на станке; всё остальное — свободная форма.

| Поверхность | Определение | Параметры | В Форме |
|---|---|---|---|
| **Плоскость** | Поверхность с нулевой кривизной в обоих направлениях: любая прямая на ней — прямая. Требование — плоскостность. | нормаль, контур | ✅ `box`, `extrude`, `cut`, `cut_plane` |
| **Цилиндр** | Постоянный радиус: вдоль образующей кривизна нулевая, поперёк — 1/R. | `radius`, `height` | ✅ `cylinder`, `lathe`, `holes` |
| **Конус** | Радиус линейно меняется вдоль оси; задаётся углом или вторым радиусом. | `r2`, `taper` | ✅ `cone`, `cylinder r2=`, `taper`, `draft` |
| **Тор (кольцевая)** | Вращение окружности вокруг оси, не пересекающей её. Беговая дорожка, галтель, кольцевая канавка. | R кольца, r трубки | ✅ `torus`, `torus_sector`, `groove` |
| **Сфера** | Равная кривизна в двух направлениях: навершие, линза, сферическое гнездо. | `radius` | ✅ `sphere`, `hemisphere`, `face_box profile=линза` |
| **Винтовая** | Образующая, смещаемая вдоль оси на шаг за оборот: резьба, шнек, пружина. | шаг, глубина витка | ✅ `thread`, `spiral`, `spring`, `worm_shaft` |
| **Свободная (кривая)** | Всё, что не описывается шестью классами: лофт, органическая форма, скрутка. | точки, сечения | ✅ `loft`, `sweep`, `bend`, `twist`, `knot` |
| **Бочка** | Цилиндр с выпуклой образующей: бочкообразный ролик, натяжитель. | выпуклость, длина | ✅ `barrel` |
| **Седло** | Поверхность с кривизной разных знаков: под цилиндр, под шар. | стрела `sag` | ✅ `saddle`, `disc sag=` |

**Требование к поверхности** — это не форма, а допуск: плоскостность,
цилиндричность, шероховатость. В Форме проверяются толщина стенки, габарит,
симметрия и герметичность (`check`); шероховатость не проверяется.

## 2. Элементы

### 2.1 Тела вращения (плакат, э01–э36)

| Элемент | Определение | В Форме |
|---|---|---|
| **Фаска** | Срез острого ребра плоскостью под углом: снимает заусенец, облегчает сборку. | ✅ `chamfer`, `bevel` |
| **Галтель** | Плавный переход между поверхностями по дуге: снижает концентрацию напряжений. | ✅ `fillet` |
| **Буртик** | Кольцевой выступ на валу, ограничивающий осевое перемещение. | ✅ `shaft flange=` |
| **Заплечик** | Ступень вала: перепад диаметров, в который упирается ступица. | ✅ `shaft steps=` |
| **Канавка** | Углубление вытянутой формы по замкнутому или разомкнутому контуру; ширина и глубина задаются отдельно, профиль дна — плоский, круглый или трапециевидный. Родовая форма для проточки, паза и канавки под уплотнение. | ✅ `groove`, `cut` по профилю, `lathe` с вырезом |
| **Канавка под уплотнение** | Кольцевая канавка нормированного прямоугольного сечения под резиновое кольцо (O-ring): глубина и ширина выбираются так, чтобы кольцо сжималось на 15–25 %. | ◐ `groove depth= height=` даёт прямоугольное сечение; скругления дна нет |
| **Проточка** | Кольцевое углубление на поверхности вращения — выход резьбы, разгрузка. | ✅ `groove` |
| **Выточка** | Углубление на торце или внутри отверстия (режется по торцу, а не по образующей). | ◐ `groove` + `bore` |
| **Лыска** | Плоский срез на цилиндре под ключ или стопор. | ✗ нет отдельной команды |
| **Шпоночный паз** | Продольный паз в валу или ступице под шпонку. | ✗ нет отдельной команды |
| **Шлиц** | Паз на торце под отвёртку. | ✅ `screw drive=` |
| **Шлицы** | Продольные зубья на валу или в отверстии для передачи момента. | ✗ нет |
| **Квадрат** | Плоская грань под ключ; нормированный частный случай лыски. | ✅ `prism sides=4`, `nut` |
| **Центровое отверстие** | Коническое гнездо на торце для установки в центрах. | ◐ `bore tip=конус` |
| **Сквозное отверстие** | Проходит тело насквозь; род детали растёт на 1. | ✅ `cube_hole`, `holes`, `bore through=да` |
| **Глухое отверстие (гнездо)** | Отверстие с дном: род не меняется, глубина считается от торца. | ✅ `cube_hole depth=`, `bore` |
| **Резьбовое гнездо** | Глухое отверстие с резьбой под винт. | ✅ `thread` (гайка), `bore` + `thread` |
| **Резьба** | Винтовая поверхность нормированного профиля. | ✅ `thread` |
| **Накатка** | Регулярный мелкий рельеф на цилиндре для сцепления с рукой. | ✅ `knurl` |
| **Бобышка** | Местное утолщение под отверстие или опору. | ✗ нет отдельной команды (собирается `union`) |
| **Прилив** | Местное утолщение без отверстия — усиление или площадка. | ◐ `face_box mode=выпуклый`, `union` |
| **Ребро жёсткости** | Тонкая стенка по направлению нагрузки. | ✗ нет отдельной команды |
| **Косынка** | Ребро треугольной формы в углу между поверхностями — самый частый вид ребра в отливках. | ✅ `gusset` |
| **Лапка** | Плоский выступ с отверстием под крепёж, примыкающий к корпусу. | ✗ нет |
| **Ушко** | Проушина: выступ с отверстием под палец или трос. | ✗ нет |
| **Фланец** | Плоский выступ по контуру с отверстиями под крепёж. | ◐ `shaft flange=`, `plate rim=` |
| **Обод** | Наружное кольцо колеса, шкива, короны. | ✅ `rim`, `ring`, `crown`, `pulley` |
| **Спица** | Радиальный элемент между ступицей и ободом. | ✅ `wheel` |
| **Ступица** | Центральная толстая часть колеса вокруг оси. | ✅ `wheel` |
| **Втулка** | Кольцевая деталь с внутренним отверстием под вал. | ✅ `pipe`, `ring`, `grommet` |
| **Шип** | Короткий выступ, входящий в ответное гнездо. | ✅ `bolt`, `hinge` (палец) |
| **Торец** | Плоскость, ограничивающая деталь вдоль оси. | ✅ `plate`, `disc` (плоский низ) |

### 2.2 Оболочки и корпус

Плакат их не содержит: оболочку нельзя получить объединением цилиндров, она
получается **смещением поверхности** (shell/offset). Такой оператор в Форме
есть, и он же — основа всех корпусных параметров.

| Элемент | Определение | Параметры | В Форме |
|---|---|---|---|
| **Стенка** | Толщина материала оболочки между наружной и внутренней поверхностью. Главный размер корпуса. | `wall`, `thickness` | ✅ `shell thickness=`, `box wall=`, `box_body`, `cylinder wall=`, `pipe` |
| **Полость** | Внутренний объём, вокруг которого построен корпус; открыта с одной стороны. | `cavity`, `cavity_depth` | ✅ `box wall= cavity=верх/низ`, `box_body`, `cylinder` |
| **Днище** | Дно полости: материал между полостью и наружной нижней поверхностью. | `bottom` | ✅ `box_body bottom=` |
| **Перегородка** | Внутренняя стенка, делящая полость на отсеки. | толщина, положение | ✗ нет команды |
| **Юбка** | Стенка, охватывающая опору и ставящая корпус на плоскость. | `wall`, высота | ◐ `shell open=низ`, `box wall= cavity=низ` |
| **Привалочная плоскость** | Поверхность, которой корпус ложится на ответную деталь; к ней предъявляется требование плоскостности. | — | ◐ `place … face=`, `check … flat` |
| **Разъём (плоскость разъёма)** | Плоскость, по которой корпус делится на половины и по которой расходится форма. | положение, нахлёст | ◐ `slice`, `box expand*` (посадка половин) |
| **Ниша** | Выборка, открытая с одной стороны; в отличие от полости не окружена материалом, в отличие от кармана — открыта. | размеры, глубина | ✅ `face_box mode=вогнутый`, `dent`, `cut` |
| **Козырёк** | Нависающий выступ над окном или разъёмом. | вынос, угол | ✗ нет команды |
| **Борт** | Низкий подъём по краю листа, тарелки или корпуса. | высота, толщина | ✅ `plate rim=`, `crown`, `column` |
| **Окно** | Сквозное отверстие в стенке, обычно прямоугольное со скруглениями. | размеры, радиусы | ✅ `cut`, `cube_hole`, `holes` |
| **Уклон стенки** | Технологическое сужение стенки кверху, чтобы деталь вынималась из формы. | `angle` | ✅ `draft angle=` |

| Элемент | Определение | В Форме |
|---|---|---|
| **Рельеф выпуклый** | Выступ над поверхностью: логотип, знак, декоративная линза. | ✅ `face_box mode=выпуклый`, `emboss`, `relief` |
| **Рельеф утопленный** | Углубление в поверхность той же формы. | ✅ `face_box mode=вогнутый`, `emboss` (гравировка) |

| **Рифление на плоскости** | Регулярный мелкий рельеф на плоской поверхности. | ✗ нет; на цилиндре — ✅ `knurl` |

| **Вмятина** | Местное плавное углубление от удара или декоративное. | ✅ `dent` |

## 3. Структура корпуса

Как понятия связаны между собой:

```
габарит ──> стенка ──> полость ──> днище
              │            │
              │            └──> перегородка (делит полость)
              ├──> привалочная плоскость (ложится на ответную деталь)
              └──> разъём (делит корпус на половины; здесь расходится форма)
```

Читается так: **корпус** — это оболочка заданной **толщины стенки** вокруг
**полости** с **днищем**; он ложится на **привалочную плоскость**, может
делиться **разъёмом** и иметь **перегородки** внутри.

В Форме эта цепочка выражается тремя способами:

```forma
корпус = box size=[120,80,60] wall=4 cavity=верх cavity_depth=50
ящик   = box_body size=[200,150,80] wall=4 bottom=6 round=8
любая  = shell толщина=3 open=верх
```

У `box` полость повторяет форму основания — годится и для сужающегося, и для
параллелограммного блока; у `box_body` — прямая коробка с дном; у `shell` —
оболочка любой готовой детали.

## 4. Чего в языке пока нет и что для этого нужно

| Пробел | Что нужно | Почему не решается существующим |
|---|---|---|
| Перегородки в полости | `partition` у `box`/`box_body`: число, толщина, направление | Режется после полости с учётом стенки и дна |
| Ласточкин хвост | `dovetail`: ширина, глубина, угол поднутрения | Трапеция с поднутрением не выводится из `cut` без ручных координат |
| Т-паз | `t_slot`: ширина шейки, ширина дна, глубина | Профиль с поднутрением, как у хвоста |
| Защёлка | Упругая балка с крючком и расчёт хода | Нужно понятие упругости, а не только формы |
| Лыска и шпоночный паз | Параметры `flat`, `keyway` у вала | Плоскость и паз по цилиндру вдоль оси |
| Рифление на плоскости | Массив канавок с шагом | `knurl` работает только по цилиндру |
| Цапфа, ушко, лапка | Отдельные элементы с отверстием и галтелью | Собираются вручную из `union` + `holes` |
| Посадки по ISO | Таблица допусков вместо зазора в мм | Нужна числовая модель допусков |
| Козырёк | Нависание с заданным выносом и уклоном | Требует проверки нависания для печати |
| Канавка под уплотнение | `oring_groove`: сечение по ISO 3601 (ширина, глубина, скругление дна) | `groove` даёт только прямоугольное сечение |
| Гребень | `ridge`: выступ по контуру с шириной и высотой | Сейчас собирается объединением полосы |
| Стандартизованность | Таблицы ГОСТ/ISO для крепежа, подшипников и галтелей | Ряды нужны как данные, а не как форма |

Приоритет по влиянию на реальные детали: **перегородка → ласточкин хвост и
Т-паз → лыска и шпоночный паз → рифление на плоскости → цапфа/ушко/лапка**.
