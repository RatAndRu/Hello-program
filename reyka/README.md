# 📐 Рейка AR — AR-направляющие для рисования на бумаге

Телефон стоит в держателе **камерой вниз** над листом. На экране ты видишь свой лист, руку и карандаш, а поверх — ровные AR-направляющие: линии, круги, эллипсы, перспективу, кальку. Рисуешь на настоящей бумаге, ориентируясь по экрану.

Всё считается на телефоне: без интернета, без ИИ, камера никуда не отправляется.

## Как это работает

1. **Поиск листа (без ИИ).** Кадр уменьшается до 320 px. Порог Оцу отделяет светлый лист от фона, а фильтр по насыщенности — от кожи руки. Дальше берётся самая большая светлая область, её выпуклая оболочка сводится к 4 углам, а стороны уточняются подгонкой прямых. Поэтому даже частично закрытый рукой лист находится.
2. **Гомография.** По 4 углам строится перспективное преобразование «миллиметры листа → пиксели камеры → экран».
3. **Направляющие хранятся в миллиметрах листа.** Поэтому они «прилипают» к бумаге: если лист сдвинулся или телефон стоит не идеально ровно, линии остаются на своём месте на бумаге, а круг на бумаге остаётся кругом.
4. **Слежение.** 10–12 раз в секунду лист ищется заново, дрожание сглаживается, а случайные резкие скачки игнорируются (принимаются, только если повторяются 3 кадра подряд).

## Что умеет (v1.0)

**Направляющие (12 типов):** прямая (с делениями, перпендикуляром, отметками ½ и ⅓), параллели, круг (концентрические), эллипс, прямоугольник/квадрат, многоугольник/звезда, дуга по 3 точкам, сетка, перспектива на 1/2/3 точки схода, круг в перспективе, ось симметрии (с зеркальными копиями других направляющих), мандала.

**Управление:** тянешь за кружки, чтобы менять фигуру, или за саму линию, чтобы её двигать. Двумя пальцами — масштаб экрана, двойной тап по пустому месту — сброс. 🧲 Магнит прилипает к углам и серединам листа, к точкам других фигур и к углам, кратным 15°. Есть отмена ↶. Цвет у каждой фигуры свой, толщина и тёмная обводка настраиваются, подписи показывают размеры в сантиметрах.

**Калька:** картинка ложится на лист с честной перспективой (WebGL). Режимы:
- **Оригинал** — полупрозрачная картинка;
- **Контур** — детектор границ Кэнни, с настройкой детализации, толщины и цвета линий;
- **Тона** — 2–6 уровней яркости;
- **Ч/Б**.

Ещё у кальки есть сетка с подписями клеток (A1, B2…) и режим **«по частям»**: показывается одна клетка, листаешь ◀ ▶. Картинку можно двигать, масштабировать, поворачивать и отражать.

**Лист:** автопоиск, ручная настройка 4 углов, режим «лист закреплён» без слежения, форматы A6–A3, Letter или свой размер.

**Экран:** 👁 чистый режим без панелей (двойной тап возвращает их), поворот изображения на 90°, зеркало, экран не гаснет, фонарик и зум камеры (если телефон умеет).

## Запуск

- **Android APK:** GitHub Actions (`.github/workflows/build-reyka-android.yml`) собирает `ReykaAR.apk` при каждом изменении `reyka/**` и кладёт его в **Releases**. Веб-часть лежит внутри APK, интернет не нужен.
- **Браузер (PWA):** папка `reyka/web` — чистые HTML/JS без сборки. Для камеры на телефоне нужен **HTTPS** (GitHub Pages / Netlify / Cloudflare Pages). На ПК можно открыть `http://localhost`, а кнопка «Демо без камеры» показывает нарисованный стол с листом.

```bash
cd reyka/web
python -m http.server 8080
```

## Советы для лучшего результата

- Лучше всего — **тёмный однотонный стол** и белый лист. На светлом столе тоже работает, но хуже.
- Лист должен быть **целиком в кадре**.
- Свет ровный, без сильного блика от лампы.
- Если лист приклеен к столу, выключи «Следить за листом» (кнопка 📄). Направляющие тогда стоят намертво и не реагируют на руку.

## Файлы

| Файл | Что внутри |
|---|---|
| `web/js/tracker.js` | поиск листа (Оцу, компоненты связности, оболочка, подгонка прямых) |
| `web/js/geom.js` | матрицы, гомография, геометрия |
| `web/js/guides.js` | все типы направляющих |
| `web/js/tracing.js` | калька: Кэнни, тона, WebGL-слой |
| `web/js/camera.js` | камера, фонарик, зум, демо-сцена |
| `web/js/app.js` | интерфейс, жесты, отрисовка, сохранение |
| `android/` | Android-обёртка на Kotlin (WebView + камера + выбор файла) |
