==========================================================
 AirMouse 0.8.0 — управление компьютером жестами рук,
 мимикой и «чтением по губам»
==========================================================

ЧТО УМЕЕТ ЧИТАТЬ ПО ГУБАМ
  Это не «понимание речи», а словарь из нескольких слов: вы записываете слово
  несколько раз, приложение сравнивает движение губ (DTW) и выдаёт ближайшее.
  Запись слов:
     AirMouse-debug.exe lip record -w "стоп,дальше,назад" --reps 10
  Просмотр словаря:  AirMouse-debug.exe lip list
  Живая проверка:    AirMouse-debug.exe lip test
  Слова привязываются к действиям: lip record ... --action toggle_pause
  Непрерывную русскую речь по губам распознать нельзя — для этого нужны
  другие модели и огромные размеченные видео-корпуса.

ЧТО НУЖНО
  * Windows 10/11 (Linux и macOS тоже работают, см. README.md)
  * Python 3.10–3.12  ->  https://www.python.org/downloads/windows/
    При установке обязательно отметьте «Add python.exe to PATH».
  * Веб-камера (встроенная подойдёт)
  * Интернет — только один раз, чтобы скачать зависимости и модели (~8 МБ)

УСТАНОВКА (1 раз)
  1. Распакуйте архив в любую папку, например C:\AirMouse
  2. Двойной щелчок по  install.bat
  3. Дождитесь надписи «Готово» (2–5 минут). Скрипт сам создаст окружение
     .venv, поставит зависимости и проверит камеру.

ЗАПУСК
  * run.bat             — обычный запуск с окном предпросмотра
  * run-background.bat  — работа в фоне, иконка в трее, без окна

  В окне предпросмотра:
     Q или Esc ... выход            P ......... пауза (действия выключаются)
     H ........... «мышь головой»   M ......... сменить движок на ходу
     C ........... настройки: режимы и ползунки
     V ........... режим по кругу (рука → рука+лицо → две руки → только лицо)
     I / Tab ..... справка          Пробел .... статистика в лог

  НАСТРОЙКИ-ПОЛЗУНКИ (клавиша C)
     Прямо в окне открывается панель с ползунками — ничего не нужно править
     руками в файлах. Пока панель открыта, мышь на паузе, поэтому курсор не
     убегает из-под руки, пока вы тянете ползунок.
     Страница «Режимы»: кнопки-переключатели рука / вторая рука / две руки /
        лицо / мышь головой и готовые наборы (РУКА, РУКА + ЛИЦО, ДВЕ РУКИ,
        ТОЛЬКО ЛИЦО).
     Страница 1 «Курсор»: где рука «достаёт» до края экрана (слева, справа,
        сверху, снизу — это и есть сдвиг курсора), сглаживание, мёртвая зона
        против дрожания, предел рывка.
     Страница 2 «Щипок и клики»: порог смыкания, когда включается прицел,
        минимальное удержание (антидребезг), задержка перетаскивания, пауза
        между кликами, строгость жестов, пауза по ладони, скорость прокрутки.
     Страница 3 «Голова и две руки»: чувствительность мыши головой по
        горизонтали и вертикали, её мёртвая зона, скорость масштаба и
        прокрутки двумя руками.
     Внизу окна: СОХРАНИТЬ / СБРОС / ЗАКРЫТЬ и живая строка «сейчас: …».
     Клавиши: 1/2/3 или Tab — страницы, S — сохранить, R — сброс, Esc — закрыть.
     Изменённые от заводских параметры подсвечены зелёным.

  ЧТО ВИДНО В ОКНЕ
     Цветные полосы по пальцам ..... нейросеть видит вашу руку (21 точка)
        зелёная точка у кончиков ... положение кончика пальца
        надпись «щипок» ............ большой и указательный сведены
     Овал лица, глаза, брови, губы . лицо распознано (468 точек)
        подпись «улыбка 78%» ....... текущее выражение словами
     Слева сверху .................. каким движком работаем, кадр/с,
                                     текущий жест и включены ли действия
     Слева снизу ................... что произошло и когда (клик, прокрутка)
     Пунктирная рамка .............. зона, в которой рука двигает курсор

  КАКОЙ ДВИЖОК РАБОТАЕТ
     «движок: ИИ MediaPipe (нейросеть)» — основной режим, 21 точка кисти
        и 468 точек лица.
     «движок: классический CV (без ИИ)» — запасной режим без нейросети;
        если он включился сам, под панелью написана причина.
     Клавиша M переключает движки на ходу; можно и флагом запуска:
        AirMouse-debug.exe --backend mediapipe
        AirMouse-debug.exe --backend classical
     Проверка нейросети без камеры: AirMouse-debug.exe doctor --no-camera

ЖЕСТЫ (по умолчанию)
  указательный палец двигается ......... курсор мыши
  щипок (большой + указательный) ....... левый клик
  щипок и вести рукой .................. перетаскивание (drag & drop)
  щипок большим + средним .............. правый клик
  кулак + движение вверх/вниз .......... прокрутка
  большой палец вверх .................. двойной клик
  раскрытая ладонь, неподвижно 1 с ..... пауза / продолжить
  «ОК» (колечко + три пальца вверх) .... двойной клик
  «коза» (указательный + мизинец) ...... пауза / продолжить
  три пальца (указ., средний, безым.) .. «мышь головой» вкл/выкл

  ПРИЦЕЛ: как только большой и указательный пошли навстречу друг другу,
  курсор замирает на точке, появляется жёлтый крестик — клик попадает точно
  туда, куда целились.

  СТАБИЛЬНОСТЬ: нейросеть на быстром движении иногда на 1–2 кадра складывает
  пальцы не туда. Теперь одиночные «моргания» гасятся медианой трёх кадров,
  клик требует удержания щипка 0.08 с, а жест не мигает из-за пальца
  «на границе». Ложные клики при движении рукой убраны.

  МИМИКА (распознаётся и подписывается словами; действия по умолчанию выключены)
     улыбка ......... «улыбка 60%»        грусть ....... опущенные уголки губ
     удивление ...... брови + открытый рот
     кивок / поворот головой — тоже распознаются и пишутся в журнал
     Включить действие, например на кивок левый клик:
        AirMouse-debug.exe config set actions.mapping.head_nod=left_click
  двойное моргание ..................... левый клик
  подмигивание ......................... правый клик
  улыбка / поднятые брови .............. отображаются, но действий не вызывают
     (раньше улыбка ставила паузу, а брови включали «мышь головой» — из-за
      этого были ложные срабатывания; включается при желании командой
      AirMouse-debug.exe config set actions.mapping.smile_hold=toggle_pause)

  РЕЖИМЫ УПРАВЛЕНИЯ (кнопки на странице «Режимы», клавиша C)
     Режимы включаются независимо и работают одновременно:
        РУКА ................. одна рука: курсор, клики, жесты   (по умолчанию)
        ВТОРАЯ РУКА .......... первая ведёт курсор, вторая нажимает и жестикулирует
        ДВЕ РУКИ: МАСШТАБ .... обе ладони развести/свести = Ctrl + колесо
        ДВЕ РУКИ: ПРОКРУТКА .. два кулака вверх/вниз
        ЛИЦО ................. мимика в окне + моргание/подмигивание как клики
        МЫШЬ ГОЛОВОЙ ......... наклон головы двигает курсор (или клавиша H)
     Что можно сочетать:
        рука + лицо .......... рука ведёт курсор, лицо кликает и показывает мимику
        лицо + две руки ...... курсор первой рукой, клики второй и лицом
        только лицо .......... выключить «Рука»: руки рисуются, но не нажимают
     Кнопки готовых наборов: РУКА / РУКА + ЛИЦО / ДВЕ РУКИ / ТОЛЬКО ЛИЦО.
     Клавиша V перебирает эти наборы по кругу.
     По умолчанию работает только одна рука: вторая рука в кадре ничего не
     меняет (не двигает курсор, не масштабирует, не нажимает).
     В окне строка «режимы: рука + лицо» показывает, что включено.

  ЛАДОНЬЮ ИЛИ ТЫЛОМ — РАЗНЫЕ КОМАНДЫ
     Приложение видит, какой стороной повёрнута кисть: ладонью к камере или
     тылом. Одни и те же позы тылом делают другое:
        ОК (колечко + три пальца) ..... ладонью: двойной клик   тылом: правый клик
        КОЗА .......................... ладонью: пауза         тылом: двойной клик
        ТРИ ПАЛЬЦА .................... ладонью: мышь головой  тылом: пауза
     КАЛИБРОВКА (один раз): покажите ладонь в камеру и нажмите K
        (или кнопка «КАЛИБРОВАТЬ ЛАДОНЬ (K)» на странице «Режимы»).
     Перепутали сторону — кнопка «ИНВЕРТИРОВАТЬ» рядом.
     Не нужна «тыльная» логика — кнопка «ТЫЛОМ: ВЫКЛ» (hand.side_actions).
     Пока не калибровались, в окне написано «сторона кисти: не определена»,
     а жесты работают как ладонью. Стоит рука ребром — сторона не мигает.
     Свои команды: AirMouse-debug.exe config set actions.mapping.ok_sign_back=right_click

  ДВЕ РУКИ
     В кадре распознаются обе руки, обе рисуются цветными полосами.
     Управляет только главная рука (та, что была в кадре первой и крупнее);
     вторая подписана «вторая рука (не управляет)» — так руки не перехватывают
     управление друг у друга.
     Включили «Две руки» или «ДВЕ РУКИ» набор — вторая рука начинает нажимать,
     а подпись меняется на «вторая рука: нажатия и жесты».

  РОЛИ РУК (по желанию): одна рука только водит курсор, вторая только нажимает
        run.bat config set hand.roles=split
     Тогда щипок второй рукой кликает, а курсор при этом не сдвигается.
     В сводке написано «роли: 1 — курсор, 2 — клики». Вернуть: hand.roles=single

  МЫШЬ ГОЛОВОЙ (клавиша H): наклон головы двигает курсор заметно быстрее, чем
     раньше (26 px/с на градус по горизонтали, 20 по вертикали). Мёртвая зона
     2.5°: вернули голову в нормальное положение — курсор остался на месте, а
     следующее движение начнётся только со следующего наклона за эту зону.
     Чувствительнее:  run.bat config set face.head_gain_x=40 face.head_gain_y=30

БЕЗОПАСНОСТЬ
  * Первые 2 секунды после старта приложение только смотрит, но не нажимает.
  * Пауза: ладонь, улыбка, клавиша P или меню в трее.
  * Аварийный стоп: резко уведите мышь в ЛЕВЫЙ ВЕРХНИЙ угол экрана.
  * Хотите посмотреть, что приложение собирается делать, ничего не нажимая:
        run.bat --dry-run

ЧТЕНИЕ ПО ГУБАМ (по желанию)
  1) Запишите слова (рот перед словом закрыт, говорите беззвучно):
        run.bat lip record -w "стоп" --reps 8 --action toggle_pause
  2) Проверьте:  run.bat lip test
  3) Запускайте с включённым распознаванием:  run.bat --lip
  Словарь свой, на 5–20 слов, для вашего лица и манеры говорить.

ЗАПУСК ПРИ ВКЛЮЧЕНИИ КОМПЬЮТЕРА
  run.bat autostart install      (убрать: run.bat autostart remove)

СВОЙ EXE (необязательно)
  build-exe.bat — соберёт dist\AirMouse\AirMouse.exe (5–10 минут).
  Папку dist\AirMouse можно целиком перенести на другой компьютер:
  Python там уже не нужен.

НАСТРОЙКА
  Все пороги — в config\airmouse.json (создаётся при первом запуске).
  Пример:  run.bat config set hand.pinch_ratio=0.30
  Полный список параметров — в README.md, раздел 7.

ЕСЛИ ЧТО-ТО НЕ ТАК
  «Не удалось открыть камеру» — закройте Zoom/Teams/браузер с камерой,
      проверьте Параметры Windows -> Конфиденциальность -> Камера.
      Другая камера: run.bat --camera 1
  Рука не находится — больше света, ладонь целиком в кадре.
  Курсор дёргается — run.bat config set pointer.min_cutoff=0.7
  Клики «сами» — run.bat config set hand.pose_stable_frames=5
  Модель не скачивается — см. models\README.txt (можно положить файлы вручную).
  Подробная диагностика — run.bat doctor, лог: logs\airmouse.log

ПРОВЕРКА БЕЗ КАМЕРЫ

  run.bat demo         — синтетическая демонстрация: гифка + раскадровка + журнал
