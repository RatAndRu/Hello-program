КАК ЗАПУСТИТЬ
-------------
1. Обычный запуск: двойной клик по start.vbs (окно консоли не появляется).
2. Если что-то не работает: start_debug.bat — откроется консоль с ошибками,
   а logs\launch.log покажет, какой Python найден и с какой командой запуск.
3. Остановить: stop.vbs (завершает только процессы этого проекта).
   Из трея — «Выход».

ГДЕ ЧТО ЛЕЖИТ
-------------
app.py            — вся логика (Flask + API + трей)
start.vbs         — тихий запуск (сам находит pythonw.exe)
stop.vbs          — корректная остановка
start_debug.bat   — запуск с консолью (отладка)
data/             — изменяемые данные: notes.json, port.txt, shared/, qr.png, .bak-бэкапы
data/port.txt     — актуальный порт приложения (первая строка — число)
static/           — иконки PWA (генерируются автоматически) и файлы интерфейса
templates/        — HTML-страницы
logs/log.txt      — лог приложения (ротация: до 1 МБ, хранятся 3 файла)
logs/launch.log   — лог запусков из start.vbs
appcore/          — общая библиотека SPECIALS (вендорится в проект, менять только копированием)

ЧТО УМЕЕТ (по золотому стандарту SPECIALS)
------------------------------------------
* PWA: устанавливается на телефон, работает из системного меню «Поделиться»,
  имеет офлайн-страницу; manifest и service worker отдаются динамически.
* Трей: открыть/копировать адрес/QR/папка данных/автозапуск/перезапуск/выход,
  уведомления. Без pystray приложение продолжает работать (см. лог).
* Один экземпляр: повторный запуск не плодит процессы, а поднимает уже
  открытое окно (проверка по /api/identity, а не по занятости порта).
* Имя в диспетчере задач: {{APP_NAME}} (AppUserModelID + именованный exe).
* Автозапуск: HKCU\...\Run → wscript.exe start.vbs (без прав администратора).
* Доступ с телефона: правило брандмауэра только для домашней подсети.
* Надёжные данные: атомарная запись JSON + бэкап .bak + карантин битого файла.
* Hot-reload: сохранение app.py перезапускает приложение; есть защита от
  утечек памяти (MEMORY_LIMIT_MB).
* Все ошибки попадают в logs\log.txt — включая падения в потоках (pythonw
  больше не «молчит»).

ЧАСТЫЕ ВОПРОСЫ
--------------
«Порт занят» — приложение само возьмёт следующий порт из своего блока и запишет
   его в data\port.txt; актуальный адрес виден в трее и на странице.
«Приложение не появилось в трее» — смотрите logs\log.txt: скорее всего,
   не установлены pystray/pillow (python -m pip install pystray pillow).
«Телефон не открывает страницу» — включите «Доступ с телефона» в трее (нужны
   права администратора) и убедитесь, что телефон в той же Wi-Fi сети.
«После правок показывается старая версия» — обновите страницу; service worker
   версионируется автоматически, HTML отдаётся с no-store.
