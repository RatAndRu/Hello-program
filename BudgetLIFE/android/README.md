# BudgetLIFE — Android (Kotlin)

Нативная телефонная версия BudgetLIFE без WebView. Исходная PWA остаётся в `BudgetLIFE/src`.

## Что перенесено

- Обзор с балансом, периодом от дня начала финансового месяца, прогнозом, графиком 1/3/6/12 месяцев, ближайшими событиями и структурой расходов.
- Календарь месяца с доходами/расходами по дням, прогнозом баланса дня и быстрым добавлением операции.
- Доходы: несколько выплат в месяце, доли/фиксированные суммы, последний/предпоследний день, перенос с выходных и праздников РФ, налог, сдельная сумма, корректировки по конкретным месяцам и выплатам.
- Расходы: план/факт, повторяющиеся операции, поиск, фильтры, лимиты по категориям.
- Счета: типы, проценты и капитализация, выплата процентов на другой счёт, автопополнения, прогноз на 12 месяцев, переводы.
- Подписки: произвольный цикл, пробный период, пауза, история изменения цены, эквивалент в месяц/год.
- Кредиты: аннуитет/дифференцированные платежи, график, досрочное погашение; кредитные карты с беспроцентным периодом и стратегиями погашения.
- Конвертер и аналитика.
- Настройки, категории, JSON-импорт/экспорт в формате PWA, локальные резервные копии (до 12).

## Курсы валют API

Да, API сохранены. Android-приложение напрямую обращается к тем же источникам, что PWA:

1. ЦБ РФ: `https://www.cbr-xml-daily.ru/daily_json.js`
2. ExchangeRate API: `https://open.er-api.com/v6/latest/<BASE>`
3. Currency API через jsDelivr CDN
4. Frankfurter/ЕЦБ: `https://api.frankfurter.app/latest?from=<BASE>`
5. CoinGecko для BTC/ETH/USDT

Порядок при `auto` такой же, как в PWA; при сбое источника пробуется следующий. Ручные курсы имеют приоритет. История снимков хранится локально и используется для мини-графика пары в конвертере.

Единственная осознанная поправка: CoinGecko в PWA записывал цену криптовалюты в семантически обратную ячейку курсов. В Kotlin курсы BTC/ETH/USDT хранятся в той же системе координат, что фиат (`rates[X]` = сколько X за 1 базовую валюту), иначе конвертер считал криптовалюту наоборот.

## Данные

Состояние хранится локальным JSON в приватной папке приложения, формат совпадает с `AppState` из PWA (`accounts`, `categories`, `incomes`, ...), поэтому экспорт/импорт между версиями работает.
