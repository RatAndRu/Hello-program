# BlueLink — Bluetooth-пульт для телефона

Приложение под Android, которое подключается к **любым** Bluetooth-устройствам: наушникам, колонкам,
часам, браслетам, датчикам и умным очкам. Оно показывает, что устройство умеет, позволяет
читать и записывать его характеристики, а через «профили» — пользоваться конкретными
возможностями: например, **снять фото камерой умных очков и получить его на телефон**.

Одно приложение, без рекламы и без отправки данных на серверы.

---

## Короткий ответ: сможем ли?

**Да — для Bluetooth-обмена.** Телефон и так видит любые BLE-устройства; приложение даёт к ним
полный доступ: список сервисов, чтение значений, запись команд, подписка на уведомления.
Это работает с наушниками, часами, датчиками и очками без всяких «вендорских» SDK.

**С камерой — зависит от устройства.** BLE — узкий канал, поэтому камеру очки отдают одним из
двух способов, и BlueLink поддерживает оба:

| Как очки отдают фото | Что делает BlueLink |
| --- | --- |
| **BLE-поток**: телефон пишет команду съёмки, очки шлют JPEG уведомлениями | собирает JPEG по кускам и сохраняет |
| **Wi-Fi + HTTP**: очки поднимают свою точку доступа, фото скачивается по адресу | сам подключается к Wi-Fi очков и забирает снимок |
| **Встроенное демо** | снимок из памяти телефона — проверить весь путь без железа |

Производители закрытых очков (например, Ray-Ban Meta) держат камеру внутри своего приложения и
не отдают её по Bluetooth — это ограничение протокола, а не приложения. Зато у DIY-очков на
ESP32/nRF, у многих модулей камер и у устройств с открытой документацией всё работает: UUID
характеристик прописываются в профиле за пару минут.

## Что внутри

| Экран | Возможности |
| --- | --- |
| 🔍 **Поиск** | скан BLE, список сопряжённых устройств, RSSI, рекламные сервисы, авто-подбор профиля |
| 📱 **Устройство** | состояние связи, MTU, заряд батареи, профиль и его возможности |
| 📷 **Камера** | съёмка (демо / BLE / Wi-Fi), статус по шагам, последний снимок |
| 🧩 **GATT** | все сервисы и характеристики с расшифровкой стандартных UUID (0x2A19 и т.п.), чтение, запись, уведомления |
| ⚙️ **Профили** | встроенные профили + свои, редактор, импорт/экспорт JSON |
| 🖼 **Фото** | все снимки, просмотр, «В галерею», «Поделиться», удаление |
| ⌨️ **Консоль** | отправка hex/текста в выбранную характеристику, журнал событий |

Работает на Android 8.0+ (minSdk 26), интерфейс на русском, тёмная тема.

## Как установить

APK собирается автоматически в GitHub Actions — ничего устанавливать на компьютер не нужно.

1. Открой **Releases** (справа на главной странице репозитория) и найди последний релиз
   **«BlueLink — APK (сборка N)»**, скачай `BlueLink.apk`.
2. На телефоне разреши установку из этого источника и установи APK.
3. Если релиза ещё нет — вкладка **Actions** → workflow **«Собрать Android APK — BlueLink»**
   → **Run workflow** (или просто закоммить изменение в `bluelink/`), через 3–5 минут APK
   появится в Releases.

Тот же APK лежит и в артефактах сборки (`bluelink-apk`), но оттуда он скачивается ZIP-архивом —
в релизах удобнее.

Собрать локально:

```bash
cd bluelink/android
gradle assembleDebug        # APK: app/build/outputs/apk/debug/app-debug.apk
```

Нужны JDK 17 и Android SDK (platform 34, build-tools 34.0.0).

## Как пользоваться

**Посмотреть, что умеет устройство**

1. Включи Bluetooth и режим сопряжения на устройстве.
2. «Поиск» → «Сканировать». Через несколько секунд появится список.
3. Нажми «Подключиться» → откроется вкладка «Устройство», а в «GATT» — все сервисы.

**Снять фото демо-очками (без железа)**

1. «Поиск» → «Демо-очки» (или кнопка на экране «Устройство»).
2. Вкладка «Камера» → «📸 Снять фото (демо)».
3. Снимок появится в «Фото»; там же можно сохранить его в галерею.

**Снять фото настоящими очками**

1. Подключись к очкам и открой «GATT». Найди характеристики камеры: обычно это
   сервис производителя (например `0xFFE0`) с «триггером» на запись и «данными» на уведомления.
2. «Профили» → «Создать профиль» → режим камеры **BLE** (поток JPEG) или **Wi-Fi/HTTP**
   (фото по адресу), впиши UUID/адрес/SSID.
3. Сохрани профиль и нажми «Снять» на вкладке «Камера».

Точный формат профиля — в [docs/PROFILES.md](docs/PROFILES.md), пример прошивки DIY-очков —
в [docs/ESP32_CAMERA.md](docs/ESP32_CAMERA.md).

## Разрешения и приватность

| Разрешение | Зачем |
| --- | --- |
| `BLUETOOTH_SCAN` (Android 12+) / геолокация (Android 8–11) | поиск устройств — требование Android |
| `BLUETOOTH_CONNECT` | подключение и обмен данными |
| `NEARBY_WIFI_DEVICES` / геолокация | подключение к Wi-Fi точке доступа очков |
| `INTERNET` | запрос снимка по локальному адресу очков (не в интернет) |
| запись в хранилище (Android 8–9) | «Сохранить в галерею» |

Приложение не содержит аналитики и не отправляет данные никуда, кроме самого устройства,
к которому ты подключился. Все снимки и профили хранятся в приватной папке приложения;
в галерею снимок попадает только по кнопке.

## Ограничения (честно)

- **Закрытые протоколы.** Прошивка очков может требовать шифрования, рукопожатия или
  аккаунта производителя — тогда снимок через BlueLink не получить. Сначала стоит посмотреть
  GATT: если камера вообще не выставляет характеристики, приложение бессильно.
- **Скорость BLE.** Кадр 720p по BLE идёт несколько секунд, а иногда и десятки секунд.
  Wi-Fi-режим быстрее в разы.
- **iOS.** Приложение Android-only: на iPhone сторонние приложения не могут свободно
  работать с Bluetooth-устройствами (нет нужных API).
- **Аудио.** Наушники приложение не «проигрывает» — звук идёт через системные профили A2DP/HFP.
  Смысл в другом: посмотреть заряд, версию прошивки, служебные характеристики.
- **Энергопотребление.** Долгий скан и постоянные уведомления расходуют батарею телефона.

## Архитектура

```
bluelink/
├── android/
│   ├── app/src/main/java/com/example/bluelink/
│   │   ├── MainActivity.kt     # экраны, вкладки, диалоги, профили
│   │   ├── Ble.kt              # скан, подключение, GATT-операции, колбэки
│   │   ├── Gatt.kt             # модели сервисов/характеристик, имена UUID, hex/декодирование
│   │   ├── Profiles.kt         # профили устройств: JSON, подбор, хранение
│   │   ├── Cameras.kt          # съёмка: демо / BLE-поток / HTTP+Wi-Fi, хранилище снимков
│   │   ├── PhotoActivity.kt    # просмотр снимка, галерея, шаринг
│   │   ├── DemoDevice.kt       # виртуальные очки
│   │   └── Ui.kt               # тема и мелкие UI-хелперы
│   ├── app/src/main/assets/
│   │   ├── profiles/*.json     # встроенные профили
│   │   └── demo/               # демо-снимок
│   └── ...
├── docs/
│   ├── PROFILES.md             # схема профиля и протоколы камеры
│   └── ESP32_CAMERA.md         # прошивка DIY-очков под BlueLink
└── README.md
```

Ключевая идея: **один BLE-движок** (`BleCentral`) и **описания устройств данными** (`DeviceProfile`).
Новое устройство не требует пересборки приложения — достаточно JSON-профиля.
