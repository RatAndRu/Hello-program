# Профили устройств и протоколы камеры

Профиль — это JSON-описание того, как приложение общается с устройством. Профили бывают
встроенными (лежат в `app/src/main/assets/profiles/`) и пользовательскими (создаются в приложении,
хранятся в приватной папке `files/profiles/`). Пользовательский профиль можно скопировать и
передать другому человеку — он импортируется целиком.

## Полная схема

```jsonc
{
  "id": "my_glasses",              // уникальный идентификатор (для своих профилей можно не указывать)
  "name": "Мои очки",              // обязательное поле
  "vendor": "DIY",
  "description": "Что это за устройство",
  "match": {
    // как автоматически понять, что профиль подходит найденному устройству
    "namePrefixes": ["Glass", "RayX"],          // по имени (регистр не важен)
    "serviceUuids": ["ffe0", "180f"]            // по сервисам в рекламном пакете
  },
  "capabilities": ["camera", "battery", "device_info", "sensors", "audio", "display"],
  "battery": {
    "service": "180f",                        // UUID сервиса батареи
    "characteristic": "2a19"                  // UUID характеристики Battery Level
  },
  "camera": {
    "mode": "ble",                            // demo | ble | http
    "label": "Снять фото",                    // текст кнопки
    // режим BLE:
    "service": "ffe0",
    "triggerCharacteristic": "ffe1",           // сюда пишем команду
    "dataCharacteristic": "ffe2",              // отсюда приходят уведомления с JPEG
    "trigger": "01",                          // команда в hex
    "framing": "jpeg",                        // jpeg | sizeHeader
    // режим HTTP:
    "httpUrl": "http://192.168.4.1/capture",
    "wifiSsid": "ESP32-CAM",
    "wifiPassword": "12345678",
    "waitMs": 1500,                           // пауза между командой и скачиванием
    // режим DEMO:
    "demoAsset": "demo/glasses_photo.jpg"
  },
  "notes": ["Подсказка в интерфейсе"]
}
```

UUID можно писать коротко (`180f`, `2a19`, `ffe0` — так приложение само достроит стандартный
Bluetooth-суффикс) или полностью (`0000ffe0-0000-1000-8000-00805f9b34fb`).

## Режим `ble`: JPEG в уведомлениях

Последовательность, которую выполняет приложение:

1. Подписывается на уведомления характеристики `dataCharacteristic` (включает CCCD 0x2902).
2. Пишет `trigger` в `triggerCharacteristic`.
3. Склеивает все входящие уведомления в один буфер.
4. Определяет конец кадра:
   - `framing: "jpeg"` — ищет маркер конца JPEG `FF D9` в последних байтах;
   - `framing: "sizeHeader"` — первые 4 байта считает длиной кадра (little-endian, uint32),
     остальные — данные.
5. Вырезает JPEG (от `FF D8` до `FF D9`), сохраняет и показывает на экране.

Таймаут — 25 секунд. Если данных меньше 200 байт, кадр считается битым.

**Требования к устройству:** характеристика данных должна поддерживать Notify или Indicate,
а MTU — позволять хотя бы 20 байт полезных данных на пакет (по умолчанию так и есть;
приложение запрашивает MTU 247).

## Режим `http`: снимок по Wi-Fi

1. Если задан `wifiSsid`, телефон через `WifiNetworkSpecifier` подключается к точке доступа
   устройства (не трогая мобильный интернет — запрос идёт через привязанную сеть).
2. Если задан `triggerCharacteristic`, в него отправляется `trigger` (некоторым очкам нужно
   сначала разбудить камеру по BLE).
3. Ждёт `waitMs`.
4. Скачивает `httpUrl` и проверяет, что это картинка (> 500 байт).

После снимка приложение отключается от Wi-Fi очков и возвращается в обычную сеть.

Типичные адреса DIY-камер: `http://192.168.4.1/photo.jpg`, `http://192.168.4.1/capture`,
`http://192.168.1.1:81/stream` (для отдельного кадра обычно нужен `/capture`).

## Как быстро подобрать UUID для нового устройства

1. Подключитесь к устройству и откройте «GATT».
2. Включите на устройстве режим камеры/передачи данных.
3. Смотрите, у какой характеристики появилось значение или стоят свойства `N`/`W`:
   - характеристика с записью (`W`) без значения — кандидат на триггер;
   - характеристика с уведомлениями (`N`) — кандидат на данные.
4. Проверьте гипотезу: «Слушать» на характеристике данных, затем «Писать» `01` в триггер.
   Если в журнале побежали байты, начинающиеся с `FF D8`, — это JPEG.
5. Внесите UUID в профиль и нажмите «Снять фото».

## Импорт и экспорт

В приложении: «Профили» → «JSON» у нужного профиля → «Копировать JSON».
Импорт: «Профили» → «Импорт JSON» → вставить текст → «Импортировать».
