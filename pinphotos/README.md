# 📌 ЗакрепФото — PWA + Android-виджет

Прототип личного офлайн-приложения: важные фото из галереи всегда под рукой.

## Что уже работает (PWA, папка `pinphotos/`)

- Установка на телефон («Добавить на главный экран» / кнопка «Установить»), полностью **офлайн** (Service Worker).
- Добавление фото из галереи через системный диалог. **Самостоятельно сканировать галерею PWA не может** — таковы правила безопасности Android; копии выбранных фото лежат в IndexedDB, оригиналы не трогаются.
- Закрепление 📌, альбомы, теги, заметки, поиск, просмотр на весь экран, шаринг.
- Кнопка «📱 На виджет»: в PWA показывает превью виджета сверху главного экрана.
- Бейдж с числом закреплённых фото на иконке приложения (Badging API, где поддерживается).
- Экспорт/импорт резервной копии одним JSON-файлом. Делай бэкап: браузер вправе почистить данные PWA при нехватке места.

Запуск для проверки: `python3 -m http.server 8000` в этой папке → открыть `http://<IP-компа>:8000` с телефона (первая загрузка — по сети, дальше офлайн). Для установки на домашний экран нужен HTTPS или localhost.

## Виджет как у Duolingo: чего PWA не умеет и как мы это обходим

Чистое PWA **не может** создать виджет рабочего стола и **не может** менять свою иконку — у браузера нет такого API. Duolingo — нативное приложение, поэтому у него это есть.

Поэтому рядом лежит нативная Android-часть (`android-widget/`, Kotlin, без сторонних библиотек):

- `PinnedPhotoWidget.kt` — настоящий виджет рабочего стола: показывает закреплённое фото (`RemoteViews`), тап открывает приложение. Фото предварительно ужимается до ~720px — у виджетов жёсткий лимит на размер картинки.
- `MainActivity.kt` — выбор фото для виджета + кнопки смены иконки.
- `IconSwitcher.kt` + `activity-alias` в `AndroidManifest.xml` — смена иконки как у Duolingo: варианты иконок **заранее зашиты** в APK (обычная / 🔥 / 😴), код лишь переключает активный алиас через `setComponentEnabledSetting`. Иконку «нарисовать на лету» Android не позволит никому, даже Duolingo.

### Как собрать APK

В этой песочнице нет Android SDK, поэтому APK здесь не собран. На своём компьютере: открой папку `android-widget/` в **Android Studio** → она подтянет Gradle и SDK → ▶ Run на телефоне → долгое нажатие по рабочему столу → «Виджеты» → «Закреплённое фото».

### Как PWA и виджет подружатся в боевой версии

Путь: завернуть PWA в **Capacitor**. Тогда кнопка «На виджет» в веб-интерфейсе через маленький самописный плагин: (1) кладёт ужатое фото в общее хранилище приложения, (2) дёргает `AppWidgetManager` обновить виджет, (3) при желании переключает `activity-alias` (например, 🔥-иконка при стрике). Веб-часть при этом не меняется вообще.
