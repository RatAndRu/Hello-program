# Сгиб — устройство модели и языка

## 1. Модель детали

Деталь хранится только в плоскости. Объём вычисляется.

```ts
interface Face {
  id: string
  name: string          // «дно», «борт левый», «клапан 3»
  poly: V2[]            // замкнутый полигон в мм, обход против часовой
  kind: 'panel' | 'tab' // панель или клапан под склейку
}

interface Hinge {
  a: string; b: string  // какие панели соединяет
  p0: V2; p1: V2        // ребро сгиба в координатах листа
  angle: number         // градусы; > 0 — к лицевой стороне листа, < 0 — к изнанке
  seam?: boolean        // шов: ребра совпадают в 3D, но в развёртке не согнуты
}

interface Part {
  faces: Face[]
  hinges: Hinge[]
  up?: V3               // куда смотрит «верх» собранной детали
  nominal?: { w, h, d } // заказанные размеры — для сверки
}
```

Соседние панели в развёртке **имеют общее ребро с точностью до 0.05 мм**:
координаты не «сшиваются», а просто совпадают, поэтому лист всегда непрерывен.

## 2. Сборка (плоскость → 3D)

```
собрать(part, t):
  дерево = граф сгибов, обход в ширину от корневой панели
  поза(корень) = единичная
  для каждого сгиба (родитель → ребёнок):
      ребро3D  = поза(родитель) · [p0, p1]
      ось      = normalize(ребро3D.p1 − ребро3D.p0)
      поворот  = поворот_вокруг(ребро3D.p0, ось, angle · t)
      поза(ребёнок) = поворот · поза(родитель)
```

Ключевое свойство: в развёртке все панели лежат в одной плоскости, поэтому
ребёнок наследует позу родителя целиком и лишь поворачивается вокруг общего
ребра. Дерево, а не граф, потому что граф замкнут (обечайка) — замыкание даёт
один лишний сгиб, который проверяется на совпадение кромок.

Угол хранится со знаком, а не выводится эвристикой: это делает модель
однозначной и позволяет делать «долины» (`сгиб A B -90`).

`t ∈ [0, 1]` — коэффициент складывания для анимации.

## 3. Развёртка из оболочки (3D → плоскость)

Трубу, конус и пирамиду проще задать готовыми гранями. Тогда развёртка
считается обратным обходом:

```
развернуть(грани, сгибы):
  поза(корень) = система координат грани (нормаль → +Z)
  для каждого соседа:
      ребро в уже развёрнутой системе
      nc = нормаль соседа в этой же системе
      φ  = atan2( (nc × Z) · ось, nc · Z )     // единственный поворот,
      поза(соседа) = поворот(ось, φ) · поза(родителя)   // ставящий грань лицом вверх
```

Именно `φ`, а не `min(угол, 180°−угол)`: только поворот, совмещающий нормаль с
+Z, укладывает грань в лист, не выворачивая её. Угол сгиба при сборке —
`угол между нормалями` с обратным знаком, что даёт точное восстановление
исходной оболочки (проверяется в `npm run selftest`: габариты и совпадение
кромок).

Рёбра, у которых координаты в развёртке разъехались, — это **шов**; на него
ставится клапан склейки.

## 4. Клапаны

Клапан — обычная панель, приклеенная к резу и согнутая на 90° (в 3D
подкрашивается). Кандидат отбрасывается, если под ним уже есть материал:
проверяются не габариты, а точки внутри полигона — иначе в веерной развёртке
конуса клапаны отбраковывались бы ложно.

## 5. Проверка

* **Габарит** — по собранным вершинам, после выравнивания `up` по +Z.
* **Площадь** — сумма площадей панелей (клапаны не считаются).
* **Рез и сгибы** — по рёбрам: сгиб — ребро, общее для двух панелей; остальное
  рез. Длина реза считается по уникальным рёбрам.
* **Замкнутость** — каждое ребро реза ищет пару в 3D с допуском 0.15 мм. Если
  пара не нашлась, но середина ребра лежит на другой панели — это **склейка**
  (например, нижняя кромка клапана крышки прилегает к стенке). Иначе ребро
  открытое.

## 6. Язык запросов

Нормализация: нижний регистр, `ё→е`, `х`/`×`/`*`/`на` между числами → `x`,
десятичная запятая → точка, `см` → ×10, `мм` убирается.

Распознавание:

1. Если в тексте есть строки `полигон …` — ручной режим.
2. Иначе ищется ключевое слово типа детали (первое совпадение по таблице
   приоритетов: профили → конус → пирамида → стакан → труба → коробка →
   крышка → лоток).
3. Размеры берутся в порядке: именованные (`d=`, `высота`, `длина`, `толщина`),
   затем тройка `A x B x C`, затем свободные числа.
4. Модификаторы: `без крышки`, `без клапанов`, `с крышкой`, `N гран`.

Всё нераспознанное не игнорируется молча: непонятный тип детали даёт ошибку с
подсказкой, а расхождение собранного габарита с заказанным — предупреждение в
панели «Проверка».

### Ручной режим

```
полигон <имя> x y x y x y …
сгиб <имя> <имя> [угол]
```

Общее ребро определяется по совпадению координат (допуск 0.2 мм). Угол по
умолчанию 90°.

## 7. Числа

Всё в миллиметрах. Площадь показывается в см², длина реза — в см. Округление
только на выводе: внутри — полная точность `float64`, чтобы кромки сходились.
