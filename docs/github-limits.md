# Лимиты GitHub: сколько репозиториев и какой объём?

Короткий ответ: **репозиториев — практически неограниченно, но у каждого файла и
у каждого репозитория есть границы.** Использовать GitHub как файлохранилище
на сотни гигабайт нельзя — за это ругаются.

## 1. Количество репозиториев

| Аккаунт | Публичные | Приватные |
|---|---|---|
| Free (бесплатный) | без лимита | без лимита |
| Pro | без лимита | без лимита |
| Organization (Free) | без лимита | без лимита |

Есть только «мягкие» ограничения по нагрузке: если создавать тысячи пустых
репозиториев ботом, поддержка может попросить остановиться. Для обычного
человека лимита нет — хоть 10, хоть 1000 репозиториев.

## 2. Объём репозитория

| Ограничение | Значение | Что бывает при превышении |
|---|---|---|
| Один файл (через git) | **100 МБ** — жёсткий предел | push отклоняется с ошибкой `GH001: Large files detected` |
| Один файл (через веб-интерфейс) | 25 МБ | загрузка не проходит |
| Предупреждение о большом файле | с 50 МБ | GitHub советует Git LFS |
| Рекомендуемый размер репозитория | **до 1 ГБ** | просьба уменьшить репозиторий |
| «Мягкий» предел репозитория | ~**5 ГБ** | начинает тормозить клон, приходит письмо от поддержки |
| Один `git push` | 2 ГБ | push отклоняется |
| Максимум на репозиторий (жёстко) | 100 ГБ | push блокируется |

Важный нюанс: считается **весь репозиторий вместе с историей**. Если один раз
закоммитить видео на 90 МБ, а потом удалить — эти 90 МБ останутся в истории
навсегда (пока не перепишут историю через `git filter-repo`).

## 3. Git LFS (для больших файлов)

Git LFS хранит тяжёлые файлы отдельно, а в репозитории лежат только «указатели».

* бесплатно: **1 ГБ хранилища и 1 ГБ трафика в месяц** (по разным источникам —
  до 10 ГиБ на новый аккаунт; точную цифру смотрите в настройках Billing);
* файл в LFS — до 2 ГБ (в зависимости от плана).

```bash
git lfs install
git lfs track "*.pdf" "*.png"
git add .gitattributes
```

## 4. Прочие лимиты, о которых полезно знать

* **GitHub Pages** (бесплатный статический хостинг) — сайт до 1 ГБ, 100 ГБ трафика/мес.
* **GitHub Actions** — 2000 минут/мес бесплатно для приватных проектов, для
  публичных бесплатно и обычно без ограничений.
* **Releases** — до 2 ГБ на файл релиза; их суммарный объём не входит в лимит репозитория.
* **Длина репозитория**: репозиторий может быть сколь угодно «старым», но очень
  большая история замедляет `git clone`.

## 5. Что из этого следует для нашего проекта

Сейчас в репозитории лежит несколько десятков МБ (арт, комикс, код) — с запасом
влезает в бесплатный аккаунт:

```
art/        ~3 МБ   (PNG + JPEG)
comic/      ~9 МБ   (PDF + панели)
chess/      ~40 КБ  (код)
```

Правила, чтобы никогда не наткнуться на лимиты:

1. одиночные файлы держать **меньше 50 МБ**;
2. репозиторий держать **меньше 1 ГБ**;
3. видео, датасеты, образы дисков — не в git, а в Releases, LFS или внешнее хранилище;
4. если случайно закоммитили большой файл — удалить не только файл, но и коммит из истории.
