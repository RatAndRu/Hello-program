# Редизайн ПИКСЕЛЬ v3 — с нуля по золотым правилам

## Что не так на скриншоте (честный аудит)

1. **Нет иерархии** — всё одинаковой важности: топбар забит 7 кнопками, правая колонка пытается показать и пиксель, и HD, и палитру, и 4 проверки сразу. Глаз не знает куда смотреть.
2. **Дубли** — два почти одинаковых канваса (ПИКСЕЛЬ 32×32 и HD 128×128) с одинаковым чекером, обе с скроллами. Это удвоение когнитивной нагрузки.
3. **Шум** — `СТРОК 14 • ТОКЕНОВ ~120`, `CTRL+ENTER — СОБРАТЬ`, `7 ЦВЕТОВ`, `СЕТКА` — всё капсом, мелко, серо. Токены — метрика для LLM, не для человека.
4. **Нет воздуха** — панели прижаты друг к другу, 1px разделители, нет закруглений и теней. Чувство «IDE из 2012».
5. **Слабый аффорданс** — где кликать? Палитра 16 квадратиков без подписей, HD слайдер непонятно что делает (45%), ручной режим прячется внизу.

**Вывод:** ФОРМА 3D просила «мудрёный» — там 3 панели оправданы (сценарий, 3D, отчёт). Для пикселя нужен **один сценарий + один предпросмотр**. Всё остальное — прогрессивное раскрытие.

---

## Золотые правила, по которым переделываю

1. **Иерархия > равенство** — одно главное действие (Сценарий → Картинка), остальное вторично.
2. **Прогрессивное раскрытие** — показывай только то что нужно сейчас (HD — по табу, а не всегда).
3. **Закон Фиттса + близость Гештальта** — контролы рядом с тем чем управляют (размер рядом с редактором, палитра рядом с холстом).
4. **Обратная связь мгновенно** — не кнопка «Собрать», а живой превью с debounce 400мс, ошибка подсвечивает строку.
5. **Пустота — это дизайн** — 24px отступы, 16px радиусы, 1 уровень теней.
6. **Один акцент** — только «Сценарий» оранжевый, остальное нейтрально.
7. **Распознавание, а не воспоминание** — примеры (Воин, Кот, Дом) видимы, а не спрятаны в коде.

## Что урезаю / что оставляю

**Убираю:**
- Токенов счётчик, капс-лейблы, дублирующий HD-бокс, отдельную командную строку, 4 карточки проверок, кнопку «Воин» из топбара, чекбокс СЕТКА из заголовка.

**Оставляю (ядро):**
- Сценарий (textarea + gutter + подсветка row-RLE)
- Один канвас с переключателем Пиксель / HD / Сравнение
- Палитра-док (всплывает у холста)
- Ручной режим (кисть/ластик/пипетка — флоатинг над холстом)
- Статус-строка: `7 цветов · 1 ошибка` → клик открывает детали

**Прячу в «···»:**
- Экспорт PNG/HD/копировать, очистить, квантовать, примеры.

Результат: **-45% элементов на экране**, +60% воздуха.
