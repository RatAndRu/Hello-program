# Форма 3D — параметрический 3D-редактор, которым управляют словами

Модель описывается текстовым сценарием: одна команда на строку. Ядро строит
замкнутую геометрию, приложение показывает её в 3D, **проверяет фактические
размеры и связи** и возвращает отчёт, который можно отдать человеку или
нейросети для следующей правки. Экспорт — GLB/GLTF, OBJ, STL, PLY, 3MF, PNG.

```forma
корпус = lathe points=[[0,0],[42,0],[42,95],[0,95]] segments=144 thickness=4 open=top
ручка  = sweep path=[[40,0,28],[58,0,28],[67,0,42],[67,0,62],[58,0,76],[40,0,76]] width=9 height=13 smooth=10
кружка = union [корпус, ручка]

check кружка watertight
check кружка wall 3..5
```

## Скачать приложение

* Все сборки: **[Releases](https://github.com/RatAndRu/Hello-program/releases)**
* `Forma3D-<версия>-windows.zip` — распаковать и запустить `Forma3D.exe`
  (рядом появится папка `forma-data/` с проектами, текстурами и выгрузками).
* `Forma3D.exe` — то же самое одним файлом, без установки.
* `Forma3D-<версия>-exe.zip` — только новый `Forma3D.exe` поверх уже
  распакованной папки (обновление без потери проектов).

кружка, шестерня, автомобиль, пришелец, жилая комната, вагон поезда,
анатомический скелет человека (206 костей), настольная лампа Arte Lamp и др.

## Запуск из исходников

```bash
cd forma
pip install -r requirements.txt
python run_forma.py
```

Требуется Python 3.10+. Полная справка — [forma/README.md](forma/README.md),
рецепты и синтаксис — [forma/docs/RECIPES.md](forma/docs/RECIPES.md).
Правила именования параметров — [forma/docs/NAMING.md](forma/docs/NAMING.md),
атлас понятий (поверхность → элемент → структура корпуса) —
[forma/docs/ATLAS.md](forma/docs/ATLAS.md).

## Структура репозитория

```
forma/
  forma/            ядро и приложение (геометрия, проверки, 3D-вид, WebUI)
  examples/         проекты меню «Проекты» — 24 сцены .forma (+ скелет в assets/)
  showcase/sources/ исходники витринных моделей
  docs/             справка, рецепты, паспорта моделей, листы-каталоги
    whatsnew/       снимки истории версий и их генераторы
  tests/            регресс: геометрия, проверки, WebUI, проекты
  packaging/        PyInstaller-сборка EXE и версия
  web/              3D-вид в браузере (three.js, без сборки)
  benchmarks/       замеры ядра
  tools/            вспомогательные скрипты (дельта-ZIP, релизы)
.github/workflows/  CI: EXE для Windows, публикация релизов, онлайн-демо
```

## Сборка и публикация

| Workflow | Что делает |
|---|---|
| «Собрать Windows EXE — Форма 3D» | собирает EXE, гоняет самопроверку внутри EXE и публикует релиз с моделями GLB+Forma |
| «Deploy Forma online» | выкладывает веб-версию на Fly.io |
| «Упаковать только Forma EXE в ZIP» / «Опубликовать готовые CI-артефакты» | перевыпуск архива без пересборки |
| «Опубликовать ZIP изменённых файлов» | дельта между двумя ревизиями |

Каждый workflow запускается и вручную из вкладки **Actions** (у всех есть
`workflow_dispatch` с параметрами).
